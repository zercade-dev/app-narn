# NARN terminology — German (`de`)

Your locale's rendering of every term in the shared lexicon. **This file is yours alone** —
no other locale's file is touched by your work, and nobody else writes rows here.

Read it alongside two other files:

- [`../terminology.md`](../terminology.md) — what each term *means*, its part of speech,
  an example key, and what it must not be confused with. It is **frozen** for the duration
  of the backfill: you read it, you never edit it. See the freeze notice at its top.
- [`../style/de.md`](../style/de.md) — how German is written here: register, punctuation,
  capitalization, plural and agreement rules. That one is yours to write too, for this
  locale only.

Fill a row when you meet the term, in the same change that introduces the wording — so
this file records decisions actually taken, never predictions. Use **Notes** for anything
the next translator would otherwise have to rediscover: a declension that forced a
different word, a term you deliberately left in English, an acronym you expanded, a
candidate you rejected and why.

Terms are in the order they appear in `../terminology.md`. Do not add, remove or reorder
rows: a term the lexicon lacks goes in the additive queue in [`README.md`](README.md).

An empty Rendering means **no batch has met that term yet** — not that it was skipped.
Batch 1 (`config`) filled the rows below; the rest are for later batches.

| project | Projekt | n., neuter. Verb is *erstellen*, never *öffnen*. |
| workspace | Workspace | Loan kept on purpose: it must never share a word with *Projekt*, and every German native candidate (*Arbeitsbereich*, *Umgebung*) reads as a project-sized or environment-sized scope. Attributive as a hyphenated compound — `config:workspaceSettingsTitle`, `config:batchGroupingDefaultOption`. |
| entry | Eintrag | n., masc., pl. *Einträge*. The counting unit of the whole app. Do not reuse for a translation-memory record without a qualifier — `config:tm.clearAllSuccess_one` writes it out in full. **English *string* splits two ways and both readings were verified at the call site — do not harmonize them.** `config:routing.simpleHint` ("Every string in this project") really does mean entries and takes *Eintrag*; `config:pseudoTestHelpBody` ("hardcoded strings") means literal text baked into the game, is not an entry at all, and takes "hartcodierte Texte". The `logs` namespace's narrated *strings* are entries and take *Eintrag*, per the canonical-term rule. **House rule for this column, since this row is the first to need it:** the citation guard treats a quoted span as a checkable German citation whenever it sits *immediately* next to a backtick key, so an English gloss must be kept out of that adjacency — wrap it in parentheses, as both glosses above are, or set it in italics. Drop the parentheses and the English words get tested against the German corpus and fail. That is not hypothetical: the first draft of this sentence demonstrated the bad form inline, and the lexicon citation check failed on it. **A second trap sits next to it** — a backtick span containing a space is treated as a citation too, so a shell command in backticks fails the same way; the guard's own header calls that path unexercised, and it is not any more. Name the check in plain prose here, and keep backticks for key and file references only. |
| source text | Quelltext | n., masc. Shares the *Quell-* root with *Quellsprache*; that is fine, the heads differ. Not *Originaltext*. |
| translation | Übersetzung | n., fem. Verb *übersetzen*. |

Where English shortens the term to bare "Context" the German shortens the same way — `strings:compare.addContext`, `strings:compare.emptyContextFilter`. |

| run | Durchlauf | n., masc., pl. *Durchläufe*. Never a verb. Bare *Lauf* was rejected: on its own it reads as running/jogging, and *Durchlauf* is the ordinary German word for one execution of a process. **The compound head is `-durchlauf` / `-durchläufe`, never a shortened `-lauf`** — `config:importModeFullReplaceHint` "KI-Durchläufen", `config:batchGroupingDescription` "Übersetzungs-, Bewertungs- und Quelltext-Review-Durchläufe". A shortened compound reads as a different word from the standalone noun, which is how one term becomes two. |
| Activity | Aktivität | n., fem. The tab label `strings:tabs` (runs) and the guide topic `strings:guide.topicActivity`. The **page title expands** and must not be shortened to match: `strings:runs.title` is "Übersetzungsaktivität", mirroring English's own "Activity" / "Translation Activity" split. Not *Verlauf* or *Protokoll* — the former is the version history and the latter is the live server log. |
| batch | Batch | n., masc./neuter — treated as masc. here (*ein Batch*, pl. *Batches*). Loan, per the don't-over-Germanize rule; *Stapel* reads as a physical pile. |
| batch grouping | Batch-Gruppierung | n., fem. Distinct from *Batch-Modus* (`config:module.batchMode`), which is the other setting. |
| AI review | KI-Review | n., neuter, pl. *KI-Reviews*. Deliberately **not** built on *Prüfung*, which is reserved for the deterministic LQA checks. *Review* is ordinary German developer vocabulary (Code-Review). Attested bare at `strings:runs.judgeBadge` and `strings:guide.topicAiReview`; the two run-type labels keep English's own parenthetical shape at `strings:runs.typeTranslationAiReview` and `strings:runs.typeSourceAiReview`. | judge | bewerten / Bewertung | Verb, evaluative sense; never *richten*/*Richter*, and no noun "der Judge". **One rendering, both parts of speech: wherever English uses *judge* as a noun or an attributive naming the pass, it is the deverbal *Bewertung*** — `config:requestTimeoutDescription` and `config:maxOutputTokensDescription` list it among the AI call types, `config:batchGroupingDescription` compounds it as "Bewertungs-…-Durchläufe". It had briefly drifted to a second rendering ("KI-Review der Übersetzungen") in the third of those; that is the *surface* name of the Translation AI review tab, which batch 3 owns, and it must not double as the term. |
| source review | Quelltext-Review | n., neuter. Built from *Quelltext* + *Review* so it is visibly the same system as *KI-Review* applied to the source. This is the **term**, used wherever English writes the lowercase "source review" in prose — `config:requestTimeoutDescription`, `strings:row.ignoredTooltip`, `strings:runs.sourceReviewDetailsShow`, `strings:order.custom`. The **tab** is named "Quelltext-KI-Review" (`strings:tabs`, review-source-ai), carrying across English's own split between the prose term "source review" and the surface "Source AI review"; that is faithfulness to each key's own English, not drift. |
| finding | Befund | n., masc., pl. *Befunde*. `strings:runs.judgeAllFindingsTitle`, `strings:runs.judgeViewAll`. Elimination proof: *Beanstandung* is taken by *issue*, *Fehler* by *error*, *Meldung* by the message strings, *Hinweis* and *Anmerkung* are the lexicon's banned hint/remark readings, *Ergebnis* is the banned *result*. *Befund* survives, and it means the thing: the outcome of an examination, reported rather than adjudicated — which is exactly an AI opinion about the source text. Batch 3's five `review:sourceAi.finding*` type labels are the same term. |
| suggestion | Vorschlag | n., masc., pl. *Vorschläge*. `strings:runs.judgeSuggestionLabel`. One word across the judge panel, the glossary generator and the category generator. The action on it is *anwenden* — `strings:runs.judgeApply` — including at `strings:runs.judgeApproveAll`, which says "Approve all suggestions" in English for the same apply action; that is the known English copy bug and German does **not** mirror it with *freigeben*. The refuse action is *ablehnen*, see *discard*. |
| discard | Verwerfen / Ablehnen | **Two senses, two words, and the split is now complete.** Sense 1, the unsaved-edits button beside Save, is "Verwerfen" (`config:discard`, `strings:editor.discard`) — it destroys nothing the user made. Sense 2, refusing something the app offered, is "Ablehnen" (`strings:runs.judgeDiscard`); batch 3's `glossary:generateDiscard` and batch 6's `colorText:assistant.discard` are the same sense and take the same word. *Ablehnen* is free: the lexicon bans *cancel*, *delete*, *undo* and *clear* for this term, and none of them is *ablehnen*. `config:discardUntranslatable` is a **third** sense the frozen lexicon does not cover — omitting entries from an export, which destroys nothing — and is written as "weglassen". It is **queued** in [`README.md`](README.md) for the between-waves resolution, because thirteen other languages meet that same key in their own batch 1 and this file is not one any of them reads. |
| needs review | zu prüfen | Verb phrase, so it carries no gender. The *reviewed* counterpart is the participle "geprüft" (`config:reviewProgressCount`) and the progress heading is "Prüffortschritt" (`config:reviewProgress`). Batch 2 reused both rather than coining a third: the filter label is `strings:filters.needsReview`, the lowercase row badge `strings:compare.cellNeedsReviewBadge`, and the quoted status tokens `strings:contextMenu.clearNeedsReview` and `strings:contextMenu.clearReviewed`. **German needs no gender rule for the "reviewed" family**: "geprüft" is a predicative participle and is invariant in every one of the three roles the shared lexicon separates for es/fr, including the explicit-antecedent case `strings:compare.cellMarkReviewedAria`. |
| flag |  | Batch 2 did **not** settle this term, and the keys that look like it are not it. `strings:compare.flagAllNeedsReview` ("Flag all as needs review") sets the needs-review state, so it takes *als zu prüfen markieren* per the row above — English uses the word *flag* loosely there. The real *flag* term is the disposition that **clears** needs-review, and it lives at `review:flag` in batch 3. Whoever fills this must pick a verb that is not *markieren*, or one verb would set and unset the same state. |
| Review (the sidebar group) | Review | n., neuter, uninflected. `strings:guide.groupReview`; batch 4's `sidebar:groups.review` owes the identical word. The umbrella is deliberately the loan rather than *Prüfung* or *Bewertung*, each of which is already spent on one of the group's four members (LQA checks; the judge). The loan is as vague in German developer usage as "Review" is in English, which is exactly the property an umbrella needs here. |
