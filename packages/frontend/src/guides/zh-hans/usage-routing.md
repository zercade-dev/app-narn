# 分发标签页

## 概述

**分发**标签页决定每个条目由哪个模块和模型处理。它会打开一个单一的服务商选择器：选定一个服务商后，项目中的每个条目都会发送给它。这对大多数项目来说已经足够。

需要多于一个目的地？把标签页切换到**高级**，完整的规则编辑器就会出现，此时分发可以按目标语言、类别或条目长度而不同，还可以保留多个命名规则组。标签页会记住您上次使用的是哪一种模式。如果一个项目的分发设置比单一服务商更复杂，无论您选择哪种模式，规则编辑器都会始终显示——已有的设置绝不会对您隐藏。

无论哪种方式，这个标签页只决定条目*如何*被分发。翻译则是从**译文**或**对照**标签页开始的。

## 分发规则

规则位于**高级**视图中。它们按优先级顺序评估；第一条匹配该条目的规则生效。每条规则都可以基于以下条件匹配：

* **来源**——导入条目的来源/出处标签。
* **条目长度上限**——仅适用于字符数达到或低于某个上限的条目。
* **目标语言**和**类别**。

对于匹配的条目，规则会设置**模块**（以及可选的**模型**和**推理强度**覆盖）以及可选的提示词提示（角色、语气、性别、备注）。用**添加规则**新增规则；您所做的每次改动都会自动保存，因此无需记住任何"保存"按钮。您可以保留多个命名**规则组**并在它们之间切换（运行进行期间切换会被锁定）。

## 批次分组

分发标签页也有一个**批次分组**控件——与配置标签页中显示的项目默认值相同，并配有对应的**忽略批次大小上限**开关。它会让相关条目在翻译、评分和原文审校运行中共用同一个服务商请求。

## 开始一次翻译

1. 在**译文**或**对照**标签页中选择条目。
2. 从那里打开**翻译…**对话框——它会提供重新翻译、记忆库和按运行分组等选项，然后启动运行。
3. 在**活动**标签页中查看进度、重试和失败情况。
