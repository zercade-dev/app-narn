# 备份标签页

## 概述

**备份**标签页会把一个项目——其配置、条目和术语表——打包成一个可校验的 `.zip` 压缩包。每个文件都会计算校验和，且在恢复时写回任何内容之前都会先验证校验和。

## 创建备份

1. 选择一个项目。
2. 打开**备份**标签页。
3. 点击**创建备份**。
4. 新的压缩包会出现在**已保存的备份**中，您可以在那里**下载**它。

## 自动备份

本应用也会为您自动创建安全快照，与手动备份一起列出：

* **CSV 导入前**——导入操作开始之前的还原点。
* **重新翻译前**——条目被覆盖之前的还原点。

全局配置中设置了**每个项目的最大备份数**（默认 10）；超出该数量的旧备份会被清理。

## 恢复

1. 在**从备份恢复**中，选择一个 `.zip` 文件（或从已保存的备份中挑选一个）。
2. 本应用会验证校验和并显示预览（项目、文件、创建时间）。
3. 确认。恢复操作会覆盖项目当前的配置、条目和术语表——此操作无法撤销，如有疑虑请先创建一个新备份。

## 删除

对任意已保存的备份使用**删除**，即可将该压缩包从服务器上永久移除。
