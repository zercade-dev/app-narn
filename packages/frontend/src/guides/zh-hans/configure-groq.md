# Groq 模块

## 概述

**Groq** 模块通过 [Groq](https://groq.com) 进行翻译——它为 Llama、Qwen、GPT-OSS 等开放模型提供快速推理，其免费额度适合日常翻译工作。它需要一个 Groq API 密钥，保存在保险库中，密钥名为 `GROQ_API_KEY`。

## 将密钥添加到保险库

服务商凭据保存在经过加密的**保险库**中，而非明文配置里。您每个会话只需用密码解锁一次。

1. 从侧边栏打开**全局配置**。
2. 如果您还没有设置保险库，先创建一个：选择一个保险库密码（每次会话都要重复使用它），然后解锁。
3. 在**启用模块**下，选择 **Groq**。当缺少必需的密钥时，保险库编辑器会自动打开到对应的密钥项——否则请点击**管理凭据保险库**。
4. 在保险库编辑器中，添加一项凭据：选择密钥 `GROQ_API_KEY`，将您的密钥粘贴为值，输入您的**保险库密码**，然后点击**保存**。

如果之后某张卡片显示"保险库已锁定"，请在翻译前点击**解锁保险库**。

## 选择模型

在项目的**配置**标签页中，从实时的 Groq 目录中选择一个模型，或继承全局默认值。`llama-3.3-70b-versatile` 是翻译质量方面稳妥的默认选择；较小的模型（如 `llama-3.1-8b-instant`）以牺牲部分质量换取速度。**分发**标签页中的**分发规则**决定每种语言由哪个模块处理。

## 获取 Groq API 密钥

1. 访问 [console.groq.com](https://console.groq.com)。
2. 注册或登录。
3. 从控制台菜单打开 **API Keys**。
4. 创建一个新的 API 密钥并复制它——它以 `gsk_` 开头。
5. 将其粘贴到保险库编辑器中 `GROQ_API_KEY` 的值里。

Groq 的免费额度按模型设置每日限额（此处未给出具体数字——请到您的控制台查看当前限额），并且根据 Groq 的条款，API 数据不会被用于训练模型。添加密钥后，**NARN Freeway** 会在将翻译工作分散到您已连接服务商的免费额度中时，自动纳入 Groq 的免费方案——无需额外设置。
