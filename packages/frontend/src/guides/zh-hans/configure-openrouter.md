# OpenRouter 模块

## 概述

**OpenRouter** 模块通过 [OpenRouter](https://openrouter.ai) 进行翻译——它是一个统一 API，可以路由到众多厂商（Anthropic、OpenAI、Google、Meta 等）的模型。它需要一个 OpenRouter API 密钥，保存在保险库中，密钥名为 `OPENROUTER_API_KEY`。

## 将密钥添加到保险库

服务商凭据保存在经过加密的**保险库**中，而非明文配置里。您每个会话只需用密码解锁一次。

1. 从侧边栏打开**全局配置**。
2. 如果您还没有设置保险库，先创建一个：选择一个保险库密码（每次会话都要重复使用它），然后解锁。
3. 在**启用模块**下，选择 **OpenRouter**。当缺少必需的密钥时，保险库编辑器会自动打开到对应的密钥项——否则请点击**管理凭据保险库**。
4. 在保险库编辑器中，添加一项凭据：选择密钥 `OPENROUTER_API_KEY`，将您的密钥粘贴为值，输入您的**保险库密码**，然后点击**保存**。

如果之后某张卡片显示"保险库已锁定"，请在翻译前点击**解锁保险库**。

## 选择模型

在项目的**配置**标签页中，从实时的 OpenRouter 目录中选择一个模型——每一项都会显示其每 token 价格和上下文长度，且仅列出文本生成模型。模型 ID 带有厂商前缀（例如 `anthropic/claude-sonnet-4.5` 或 `openai/gpt-4o-mini`）；您也可以直接输入一个新的标识符。**分发**标签页中的**分发规则**决定每种语言由哪个模块处理。

## 获取 OpenRouter API 密钥

1. 访问 [openrouter.ai](https://openrouter.ai)。
2. 注册或登录。
3. 从您的账户菜单打开 **Keys**。
4. 创建一个新的 API 密钥并复制它。
5. 将其粘贴到保险库编辑器中 `OPENROUTER_API_KEY` 的值里。

注意：您的文本会被发送给 OpenRouter，并按照 OpenRouter 的条款以及您所选模型对应厂商的数据政策，被转发给该厂商。
