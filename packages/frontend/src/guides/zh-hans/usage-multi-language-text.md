# 译文标签页

## 概述

**译文**标签页是主要的条目表格：每个原文条目一行，每种目标语言一列。您可以在这里阅读、编辑、筛选、分类，并**选择**要翻译的条目。表格支持分页（每页 25/50/100/200 行）。

## 编辑

点击任意译文单元格即可就地编辑；确认后改动会自动保存。**原文列**和**状态列**会显示每个条目的原文内容与来源，以及它的类别、术语表和翻译状态。

## 筛选

使用工具栏来缩小表格范围：

* 在原文和译文中**搜索**。
* **状态**筛选：仅未翻译、仅 LQA 失败项、仅溢出项、待审校、与原文相同、占位符不一致。
* 按**语言**、**来源**标签或**类别**筛选，并可显示或隐藏列。

## 选择并翻译

用复选框选择行（或选择整个筛选后的集合）。有了选择集之后，您可以：

* 从选择栏运行**翻译所选**（分发规则会为每种语言选取对应的模块）。
* 批量**添加**或**移除类别**。
* **批准存入记忆库**——将当前译文记录为可信内容存入翻译记忆库。

## 按条目管理类别和术语表

右键点击一行（或使用其操作菜单）即可**编辑类别**，或为该条目在翻译时选择启用哪些**术语表**。类别也可以在**类别**标签页中批量生成。
