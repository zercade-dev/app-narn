# 翻译记忆库

## 概述

**翻译记忆库**（TM）是一个跨工作区共享的已知译文存储库。当某条字符串的原文与记忆库中已有的内容匹配时，系统会自动复用已存储的译文，而不再调用付费模块——从而节省时间和费用，并让相同文本在各个项目之间保持一致。从侧边栏打开**翻译记忆库**视图即可浏览和搜索已存储的片段。

> **翻译记忆库默认对每个项目都是关闭的。** 在它关闭期间，项目翻译的任何内容都不会被写入记忆库，也不会自动应用任何已存储的译文。要开启它，请打开项目的**配置**标签页，在**翻译记忆库**部分选择一个复用策略（*关闭*以外的任意值）。

## 内容如何进入记忆库

* **批准存入记忆库**——在**译文**标签页中选中若干译文并批准，它们就会被记录为可信片段。
* 已完成的翻译也会被记录，以便之后相同的原文能够复用它们。

## 复用策略

复用策略（位于项目的**配置**标签页，**翻译记忆库**部分）控制*是否*以及*何时*为相同的原文复用已存储的译文。它默认为**关闭**（TM 关闭）；其他选项——例如**严格（完全上下文匹配）**，只在周围上下文也匹配时才复用——则会开启它。收紧策略可以避免复用一条在某处正确、但在另一处并不正确的译文。

## 按运行控制复用

当您从**对照**标签页的*翻译…*对话框启动一次翻译时，系统会提示有多少条目将从记忆库中填充，您也可以选择**本次运行禁用记忆库**，强制让每个条目都重新翻译——这在您希望模型重新考虑之前已记忆的文本时会很有用。
