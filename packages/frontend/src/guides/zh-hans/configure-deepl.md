# DeepL 模块

## 概述

**DeepL** 模块提供专业的神经网络机器翻译。与 LLM 模块不同，它属于经典机器翻译，并且可以将项目术语表推送到 DeepL 以保持术语一致。它的密钥保存在保险库中，密钥名为 `DEEPL_API_KEY`。

## 将密钥添加到保险库

服务商凭据保存在经过加密的**保险库**中，而非明文配置里。您每个会话只需用密码解锁一次。

1. 从侧边栏打开**全局配置**。
2. 如果您还没有设置保险库，先创建一个：选择一个保险库密码（每次会话都要重复使用它），然后解锁。
3. 在**启用模块**下，选择 **DeepL**。当缺少必需的密钥时，保险库编辑器会自动打开到对应的密钥项——否则请点击**管理凭据保险库**。
4. 在保险库编辑器中，添加一项凭据：选择密钥 `DEEPL_API_KEY`，将您的身份验证密钥粘贴为值，输入您的**保险库密码**，然后点击**保存**。

DeepL 不支持命名实例——只有一个 DeepL 模块。

## 使用术语表

DeepL 可以在翻译时应用术语表。在**术语表**标签页中创建术语，然后使用**推送到 DeepL** 上传它们。如果术语表在推送后又发生变动，该标签页会显示"需要重新推送"——请再次推送以更新 DeepL。

## 获取 DeepL API 密钥

1. 访问 [deepl.com/account](https://www.deepl.com/account)。
2. 注册一个 Free 或 Pro API 账户。
3. 打开 **Account Settings**，找到 **API Key** 部分。
4. 复制您的身份验证密钥。
5. 将其粘贴到保险库编辑器中 `DEEPL_API_KEY` 的值里。
