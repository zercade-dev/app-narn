# 质量标签页

## 概述

**质量**标签页是一个仪表盘，汇总了每次条目翻译后产生的 LQA（语言质量保证）结果。它会显示您的总体通过率，以及问题集中出现的位置，方便您快速定位问题区域。它会随着您的翻译逐渐填充——如果它是空的，请先运行一次翻译。

## 它显示什么

* 覆盖全部 LQA 结果及其涉及条目的**总体通过率**。
* **按语言划分的通过率**——每种目标语言各自的质量情况。
* **按来源划分的问题**——按来源标签分组的问题类型数量。
* **按模块划分的质量**——按产出每条译文的模块分组的通过率和问题数。

## 深入查看

点击任意单元格即可跳转到相应条目——仪表盘会把**译文**表格筛选到受影响的条目，方便您逐一修复。

## 检查项的来源

每条译文都会经过 LQA 质量门禁，运行您在**配置**标签页的*LQA 检查*面板中启用的检查项（内联标记一致性、长度上限、长度溢出、术语表遵循、禁用词、正则断言等）。**阻断**级检查会导致质量门禁不通过，并可能触发一次自动重试；**警告**级检查只会在这里报告，不会阻断。可在配置中调整运行哪些检查项及其严重级别。
