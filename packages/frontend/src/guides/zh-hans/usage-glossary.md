# 术语表标签页

## 概述

**术语表**标签页用于保持术语一致。一个项目可以拥有多个术语表；每个术语表都是一份原文术语列表，每种目标语言各有一条译文。术语表会自动与条目进行匹配，匹配到的术语会在翻译时传递给模型。

## 术语表与术语

* 用**新建术语表**创建一个术语表；之后可以重命名或删除。
* **启用**或**停用**某个术语表——已停用的术语表在导入和翻译时都会被忽略。
* 添加术语时填写**原文**、**每种语言的译文**，以及可选的**备注**。
* 当某个术语绝不能被翻译时（品牌名、代码等），将其标记为**常量**。常量术语在翻译时会被掩码处理，从而原样通过。

部分术语表是**只读**的（由全局管理），它们提供术语，但不能在这里编辑。

## 导入和导出

从 **CSV** 或 **TBX** 导入术语——应用前会先显示预览，说明有多少术语会被新增、更新或产生冲突。也可以将术语表导出回 **CSV** 或 **TBX**。

## 用 AI 生成

* **生成术语表**会扫描原文，针对反复出现的名称和自定义术语提出术语表建议。它会在后台运行——可在**活动**标签页中跟踪，并在创建之前先审校建议。您可以把已有的术语表作为"已知内容"传入，这样模型就不会重复它们。
* **生成译文**会为仍缺少目标语言译文的术语补全译文。

## DeepL

如果您使用 DeepL 翻译，请使用**推送到 DeepL** 上传术语表内容。编辑一个已推送的术语表后，该标签页会显示"需要重新推送"——请再次推送以更新 DeepL。

## 按条目控制

在译文标签页中，您可以为单个条目选择启用哪些术语表。
