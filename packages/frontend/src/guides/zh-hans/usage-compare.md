# 对照标签页

## 概述

**对照**标签页是一个专注于单一语言的工作台，用于逐一审校和填补译文。它会并排显示**原文**、可选的**参考**语言以及**目标**语言——当您希望参照一种已经信任的语言而不是仅参照原文进行翻译时，这非常有用。

## 设置视图

* 选择要处理的**目标**语言。
* 可选择一个**参考**语言，作为额外的一列显示，并用作翻译上下文。
* **搜索**并筛选：仅未翻译、**LQA** 问题，或**待审校**。

## 处理译文

* 点击任意目标单元格即可就地编辑；保存后会提供**撤销**选项。
* 按需对单行执行**重新翻译**。
* **+ 上下文**可以为条目附加译者上下文（角色、语气、情境备注），模块会在下一次翻译时接收到这些信息。

## 批量翻译

点击**翻译…**打开当前视图的批量翻译对话框：

* 翻译当前视图中**已选**的条目或**全部**条目。
* **仅填充未翻译**的条目，或**重新翻译**已有译文。
* 选定参考语言后可**将参考语言用作上下文**。
* 为本次运行设置**批次分组**，也可以选择**禁用翻译记忆库**，让每个条目都重新翻译。

## 审校辅助

使用**全部标记为待审校**或**全部标记为已审校**，一次性将当前整个视图推进到您的审校流程中。
