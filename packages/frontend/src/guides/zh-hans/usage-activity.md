# 活动标签页

## 概述

**活动**标签页是后台任务的控制中心。每一个长时间运行的任务都会在这里显示：**翻译**运行、**AI 审校**（译文和原文）、**术语表生成**和**类别生成**。运行会按项目排队并串行执行，因此您可以一次排好几个，逐个查看它们的进度。

## 阅读一次运行

每次运行都会显示其**类型**、**状态**（已排队、运行中、已暂停、已完成、已失败或已取消）、进度，以及估算**费用**。费用是模块上报的估算值，根据各模型每百万 token 的价格得出，因此思考型模型的 token 总数相对字符数可能会显得偏高。使用**显示明细**可以准确查看本次运行翻译了什么、有哪些重试，以及字符/token 用量。您可以复制运行 ID 以供参考。

## 管理队列

* **暂停** / **继续**一次运行，或使用**立即开始**让排队中的运行提前执行。
* **在队列中上移** / **在队列中下移**来调整队列顺序。
* **取消**一次正在排队或进行中的运行。

## 恢复与审校

* 如果部分文本失败，**重试失败项**只会重新运行这些条目。
* 在一次已完成的翻译运行上，可以直接从该运行开始一次 **AI 审校**——选择模块和模型（默认沿用翻译时所用的模块和模型），然后在**译文 AI 审校**标签页中打开判定结果。
