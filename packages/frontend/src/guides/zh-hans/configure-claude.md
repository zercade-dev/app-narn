# Anthropic (Claude) 模块

## 概述

**Claude** 模块使用 Anthropic 的 Claude 模型进行翻译。它需要一个 Anthropic API 密钥，保存在保险库中，密钥名为 `ANTHROPIC_API_KEY`。

## 将密钥添加到保险库

服务商凭据保存在经过加密的**保险库**中，而非明文配置里。您每个会话只需用密码解锁一次。

1. 从侧边栏打开**全局配置**。
2. 如果您还没有设置保险库，先创建一个：选择一个保险库密码（每次会话都要重复使用它），然后解锁。
3. 在**启用模块**下，选择 **Anthropic (Claude)**。当缺少必需的密钥时，保险库编辑器会自动打开到对应的密钥项——否则请点击**管理凭据保险库**。
4. 在保险库编辑器中，添加一项凭据：选择密钥 `ANTHROPIC_API_KEY`，将您的密钥粘贴为值，输入您的**保险库密码**，然后点击**保存**。保存会重新加密保险库。

如果之后某张卡片显示"保险库已锁定"，请在翻译前点击**解锁保险库**。

## 选择模型

在项目的**配置**标签页中，选择一个 Claude 模型（以及可选的推理强度），或让它继承全局默认值。**分发**标签页中的**分发规则**决定每种语言由哪个模块处理。

## 获取 Anthropic API 密钥

1. 访问 [console.anthropic.com](https://console.anthropic.com)。
2. 注册或登录。
3. 打开 **API keys** 部分。
4. 点击 **Create Key** 并复制它。
5. 将其粘贴到保险库编辑器中 `ANTHROPIC_API_KEY` 的值里。
