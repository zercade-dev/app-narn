# 伪翻译测试

## 概述

**伪翻译测试**不是一门真实的语言。它是一种免费的离线 QA 语言，会把您的原文改写成一个刻意变形的版本，让您可以把它加载进游戏，看看哪些字符串会破坏界面——而这一切都发生在任何一次真实翻译产生之前。

它不花一分钱，不需要 API 密钥，也绝不会把任何内容发送给服务商。

## 它会产出什么

`Save changes` 会变成类似 `⟦Şàvé çhàñgéş~~~~⟧` 的内容。这里同时发生了三件事，每一件都能暴露出不同类型的问题：

* **重音字母。** 每个字母都被替换成带重音符号的形似字符。任何在游戏中仍显示为纯英文的文本，都说明它从未被纳入字符串表——它是硬编码的，任何译者都永远无法触及它。
* **填充。** 文本会用 `~` 字符拉长到大约原长度的 1.4 倍，模拟德语这类偏长的语言。任何超出按钮边界、换行错乱，或把布局挤乱的标签都会立刻显现出来。
* **括号。** 结果会用 `⟦…⟧` 包裹起来。如果屏幕上缺了任意一侧括号，说明该字符串正在被截断。

您文本中的占位符和标记标签会原样通过，不受影响，所以如果其中任何一个出现变形，那是值得报告的 bug，而不是布局问题。

## 使用方法

1. 在**数据**标签页中，在*目标语言*下勾选**伪翻译测试**并保存。
2. 照常运行一次翻译。伪翻译测试条目始终由内置的伪翻译生成器处理——不需要启用任何东西，不需要编写分发规则，也不产生任何费用。您的付费服务商永远不会看到这些字符串。
3. 您的真实译文是安全的：伪翻译测试文本存储在自己独立的一列中，绝不会覆盖其他语言。

## 导入您的游戏

在导出卡片中，将**将伪翻译文本导出为**设为一种您当前尚未上线的语言——比如说德语——然后下载文件，并在游戏中选择该语言加载它。所选语言那一列，仅在这一次下载中会被填入伪翻译测试文本；不会有任何存储内容发生改变，下次导出时真实译文依然都在。

测试完成后，请把替换项重新设回**不替换**再导出一次。正常导出永远不会包含伪翻译测试列——伪翻译文本只会通过上述替换方式进入您的游戏——因此让伪翻译测试保持开启状态，并不会影响您实际发布的文件。

## 何时使用它

请在委托任何翻译之前尽早运行一次伪翻译测试。它发现的每一个布局问题，您只需修一次，而不是等十五种语言都到齐之后再修十五次。
