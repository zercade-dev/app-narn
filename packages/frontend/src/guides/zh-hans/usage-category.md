# 类别标签页

## 概述

**类别**将相关的字符串（例如界面标签、对白、物品名称）归为一组。它们能帮助您整理项目、筛选字符串表，并且重要的是——驱动**分发规则**和**批次分组**，让归类后的内容可以被发送到正确的模块，并在有上下文的情况下一起翻译。

## 浏览类别

**类别**标签页会列出您当前的类别，并标注每个类别的条目数。选择一个类别即可查看其条目，并编辑它的**描述**——一段简短说明该类别归纳内容的备注。

## 分配类别

* 从**译文**标签页为单个条目分配类别（右键点击某行 → *编辑类别*），或在该标签页中选中多行进行批量分配。
* 或者自动生成（见下文）。

## 用 AI 生成

点击**用 AI 生成**，让模型阅读您的原文字符串，提出类别建议并分配条目。

1. 选择**模块**和**模型**。
2. 可选择让它同时把条目分配到您**已有**的类别中。
3. 点击**生成**——它会在后台运行，因此您可以离开这个标签页，之后再回来查看。
4. **审校建议**：取消勾选不需要的项，然后**应用所选**。

在您应用之前不会有任何改动，因此 AI 建议始终由您先确认。
