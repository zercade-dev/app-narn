# 孤立条目标签页

## 概述

**孤立条目**标签页列出了在最近一次导入的 CSV 中已不存在的条目。它们通常出现在重新导入之后——某一行被删除、重命名，或其原文被改动——旧的译文会保留在这里，以免您丢失已完成的工作。

## 您可以做什么

* **删除**一个孤立条目，永久移除该记录及其译文（此操作无法撤销）。
* **重新关联**一个孤立条目，将其译文移到另一个条目上。按原文搜索目标条目；目标条目上已有的译文会被保留，只会填充其空缺的语言。
* 选中多个孤立条目并批量**删除所选**，或**刷新**列表。

## 工作流程

1. 在**数据**标签页中重新导入您的原文 CSV。
2. 打开**孤立条目**，查看哪些内容已消失。
3. 对 ID 或原文发生了变化、但译文仍然有效的条目执行**重新关联**。
4. **删除**确实已经不存在的条目。

当列表为空时，说明导入的每个条目都与当前项目一致——没有任何条目处于孤立状态。
