# 配置标签页

## 概述

**配置**标签页保存所选项目的翻译策略：各模块的模型选择、翻译记忆库复用方式、批次分组、质量（LQA）检查，以及项目管理。它的**语言**和 **CSV 导入/导出**功能现已移至独立的**数据**标签页。服务商凭据不在这里设置——它们保存在**保险库**中（参见《配置模块》系列指南和**全局配置**）。

## 语言（在数据标签页中）

在**数据**标签页中设置**源语言**和要翻译成的**目标语言**。当前生效的目标语言集合会驱动其他每个标签页——条目列、分发规则和质量检查都以它为准。

## 导入和导出 CSV（在数据标签页中）

CSV 导入和导出功能同样位于**数据**标签页：

* **导入 CSV** 会加载原文条目及其已有的译文。每次导入前都会自动创建一份安全快照，因此您可以从**备份**标签页回滚。
* 无法被正确解析的行（引号后紧跟逗号）会被丢弃并报告，而不会被当作列错位的数据写入。
* **导出 CSV** 会下载项目内容；您可以选择语言，以及是否包含译者上下文列。

## 模块与模型

在**全局配置**中一次性启用服务商。在这里的配置标签页中，您可以按项目为每个已启用的模块选择**模型**和**推理强度**——或保持为"*继承全局配置*"。具体某个条目实际由哪个模块处理，则由**分发规则**决定（参见《分发》指南）。

## LQA 检查

**LQA 检查**面板配置每次翻译都会运行的质量门禁：切换各项检查（内联标记一致性、长度上限、长度溢出、术语表遵循、禁用词、正则断言等）的开关，并将每项设为**阻断**或**警告**。阻断级问题会导致质量门禁不通过，并可能触发一次自动重试；警告级问题仅作提示。

## 批次分组

**批次分组**会把相关条目（按类别和/或术语表）保留在同一请求中，让模型能在上下文中看到它们。您可以设置一个项目默认值，也可以按运行覆盖它。

## 项目管理

**危险操作区**可让您**复制**项目（配置和条目，但绝不包含密钥）或永久**删除**它。
