# Generic AI 模块

## 概述

**Generic AI** 模块可以连接任何兼容 OpenAI 格式的 API——无论是托管服务商，还是本地运行的服务器（例如 Ollama、LM Studio、vLLM）。它的密钥保存在保险库中，密钥名为 `GENERIC_API_KEY`。

**API 密钥是可选的。** 它只对需要身份验证的端点（大多数付费云服务商）有意义。像 Ollama 或 LM Studio 这样的本地服务器不需要真实密钥——但保险库仍要求 `GENERIC_API_KEY` 字段非空，因此请存入任意占位值（例如 `local`）来满足这一要求。

## 将密钥添加到保险库

服务商凭据保存在经过加密的**保险库**中，而非明文配置里。您每个会话只需用密码解锁一次。

1. 从侧边栏打开**全局配置**。
2. 如果您还没有设置保险库，先创建一个：选择一个保险库密码（每次会话都要重复使用它），然后解锁。
3. 在**启用模块**下，选择 **Generic AI**。当缺少必需的密钥时，保险库编辑器会自动打开到对应的密钥项——否则请点击**管理凭据保险库**。
4. 在保险库编辑器中，添加一项凭据：选择密钥 `GENERIC_API_KEY`，输入您的**保险库密码**，然后点击**保存**。对于付费端点，请将真实 API 密钥粘贴为值。对于不需要身份验证的本地服务器，密钥可留空对应的真实值——只需存入任意非空的占位值（例如 `local`）即可。

## 用实例运行多个端点

Generic AI 支持**命名实例**，因此您可以并排注册多个端点（例如一个云服务商和一个本地服务器）。在全局配置中使用**再添加一个 Generic AI 实例**。每个实例都有自己派生出的保险库密钥——例如 `GENERIC_API_KEY__MY-OLLAMA`——在同一个保险库编辑器中填写即可。

## 选择端点和模型

在其全局配置设置中为该模块（或每个实例）设置基础 URL 和模型，然后在**配置**标签页中为每个项目选择模型。**分发**标签页中的**分发规则**决定每种语言由哪个模块或实例处理。

## 获取凭据

对于**本地服务器**（Ollama、LM Studio、vLLM），不需要账户或密钥——只需要基础 URL（例如 `http://localhost:11434/v1`）以及 `GENERIC_API_KEY` 字段中的一个占位值。

对于**付费服务商**，具体步骤因服务商而异：创建账户，获取 API 基础 URL 和密钥，并在将密钥填入保险库之前确认该端点支持 OpenAI 的对话补全（chat-completions）格式。
