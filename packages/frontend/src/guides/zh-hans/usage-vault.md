# 凭据保险库

## 概述

服务商 API 密钥绝不会以明文保存在配置文件或环境变量中。它们保存在**保险库**中——一个经过加密的存储区，必须先解锁才能在任何翻译或 AI 审校中使用其中的凭据。每个浏览器会话只需解锁一次；凭据仅在内存中解密。

<!-- local-only -->
## 密码保险库（自托管）

在自托管安装中，保险库是一个经过加密的本地文件。首次解锁会创建它：您选择的密码就成为保险库密码，此后每次保存凭据都会重新加密该文件。密码本身绝不会被存储——没有它，该文件就无法解密。可以从**全局配置**，或从任何显示"保险库已锁定"的卡片处解锁。
<!-- /local-only -->

## 设备绑定保险库（云端）

在云端版本中，保险库被**加密保存在服务器上**，解密它需要两个因素：

- 您的**密码**——无论在服务器还是设备上都绝不会被存储。
- 一个**每台设备专属的密钥**——在您登记设备时于浏览器中生成，只保留在该设备上。

当您解锁时，这两个因素都会通过加密连接传输，并在服务端组合，以推导出解密密钥——**仅存在于内存中，且仅限本次会话**。这两个因素本身，以及推导出的密钥，都绝不会写入服务器存储——被存储的只有加密后的保险库本身。因此仅凭服务器存储的数据无法还原您的凭据，仅凭泄露的密码同样不够：解锁还需要您已登记的设备之一。

如果全局配置显示的是**前往保险库页面**按钮，而不是密码输入框，说明您使用的是设备绑定保险库——保险库页面负责处理设置、设备登记、解锁、凭据编辑和密码更改。

## 须知

- 从未使用过的设备必须先在保险库页面**登记**，才能解锁保险库。
- 如果您丢失了密码（在云端版本中，或丢失了全部已登记的设备），保险库中的内容将无法恢复——您必须重新设置保险库，并重新录入您的服务商密钥。
- 本应用记录的任何日志都会经过脱敏处理，因此凭据的值绝不会出现在日志中。
