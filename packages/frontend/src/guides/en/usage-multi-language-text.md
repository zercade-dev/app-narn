# Translations Tab

## Overview

The **Translations** tab is the main entry grid: every source entry with a column per target language. It is where you read, edit, filter, categorize, and **select** entries to translate. The table is paginated (25/50/100/200 rows per page).

## Editing

Click any translation cell to edit it inline; the change saves when you confirm. The **SOURCE** and **STATUS** columns show each entry's source text and origin alongside its category, glossary, and translation status.

## Filtering

Use the toolbar to narrow the table:

* **Search** across source and translated text.
* **Status** filters: untranslated only, LQA failures only, overflow only, needs review, same as source, placeholder mismatch.
* Filter by **language**, **source** label, or **category**, and show or hide columns.

## Selecting and translating

Select rows with the checkboxes (or select an entire filtered set). With a selection you can:

* Run **Translate Selected** from the selection bar (the routing rules pick the module per language).
* **Add** or **remove a category** in bulk.
* **Approve to memory** — record the current translations in translation memory as trusted.

## Categories and glossaries per entry

Right-click a row (or use its actions) to **edit categories** or choose which **glossaries** are enabled for that entry during translation. Categories can also be generated in bulk from the **Category** tab.
