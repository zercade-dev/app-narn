## v1.31.0 — 2026-07-15

Describe your stage and translate it everywhere: new Stage details tab with an AI assistant chat.

- A new Stage details tab lets project owners write a stage name, gameplay details, and a stage description, then translate them into every project language with one click.
- Character counters keep you within each field's limits as you type.
- Stale badges flag any language whose translation has fallen behind the latest source edit, so nothing gets missed.
- One-click copy buttons make it easy to grab a translation for pasting elsewhere.
- A new AI assistant chat panel can suggest wording changes right in context — review each suggestion and apply it with a single click.
