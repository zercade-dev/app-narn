## v1.30.0 — 2026-07-15

Search the web without leaving narn.

- Press Ctrl+K (Cmd+K on Mac) anywhere to look something up on the web — handy for checking terminology while reviewing a translation. If you have text selected it's filled in for you; Enter opens the search in a new browser tab.
- Sturdier run queue: if saving a finished run's status briefly fails behind the scenes, the next queued run for that project now starts as it should.
