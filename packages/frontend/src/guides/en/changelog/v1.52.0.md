## v1.52.0 — 2026-07-21

A wide polish pass, driven by your feedback. The interface now talks about your "text" and "entries" instead of the more technical "strings" — in search boxes, empty states, dialogs, the glossary, backups, and the AI review tab. The Pixel theme's icons were redrawn on a cleaner grid so they render crisp rather than fuzzy, including the Compare tab's action buttons, and every theme now has scrollbars that match its look instead of a plain grey default. Dropdown menus are readable in dark themes, badges and labels no longer overlap or show a stray white box, and every button — including file pickers like "Select zip file" — shows a pointer cursor so it's clear it can be clicked. In the glossary, the "generate" text no longer overflows, the create button is easier to spot, and edit/delete/add stay reachable instead of hiding behind a scroll on smaller screens; quality dashboard bars also stretch to use the space they have. The AI review tab's button is now clearly labelled "Review last run" and shows live progress while a review is running. Finally, the Settings theme preview became an interactive gallery — sample buttons, inputs, a dropdown, a checkbox, badges, icons, and a themed scrollbar — and you can now type in its text field to try things out before choosing a theme.
