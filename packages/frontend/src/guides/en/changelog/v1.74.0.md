## v1.74.0 — 2026-10-31

Import client script files alongside your main text, each kept in its own collection.

- Files with a Text Mapping ID column are recognised as client script text and imported separately from main text.
- The same English can appear in both collections, or under different keys, without being merged.
- Importing one collection never changes, removes or reorders the other.
- If the English for a key changes, relink the old translations from the Orphans tab, where the row with the same key is suggested first.
- Export either collection from the Data tab once a project has client strings.

CSV exports now go back into the Miliastra editor without stray apostrophes.

- Cells starting with + = - or @ export exactly as written, so "+{count} Slime Essence" stays that way in the editor.
- A new "Export for" choice on the Data tab picks Game editor or Excel or Sheets. Excel or Sheets adds the apostrophe, names the file with -spreadsheet, and resets after each export.
- Importing a file now tells you about leading apostrophes: removed from main text, kept in client script text so you can check them.
- Translation runs skip rows marked as not needing translation, and leave any text they already have alone.

You can now see when a model keeps failing, even if your run still finishes.

- A run warns you once, and keeps a line on its card in the Activity tab, when a model keeps failing with the same error.
- The line names the model, how many failures there have been, what the provider said, and whether those requests moved to another model or will be retried.
- Warnings in the console now appear in amber, with their own unread count next to the red error count.

NARN Freeway now retries a provider's brief outage after a minute or two instead of waiting 15 minutes.

- When a provider reports it is busy or briefly down, Freeway tries the same model again after a minute or two.
- If the failures continue, it waits longer each time, up to the next daily reset. A long outage costs one more attempt than before.
- Requests that time out still wait 15 minutes, as they did before.
- The Activity tab now says when a run is waiting for a provider, rather than for free quota.

Translations routed to Google's Gemma models no longer fail and fall back to another model.

- Gemma requests now leave out a thinking setting these models don't support, so they run the first time.
- Gemma models no longer show a reasoning effort choice that they can't use.
- Translation error logs now name the model involved.

Creating a project no longer fails when another project with the same name is created at the same moment.

- Duplicating a project gets the same protection.

AI reviews now use the model of the module you choose and show the run you just started.

- Choosing a different module for a review or stage details no longer reuses the model saved for the previous module.
- Starting a source text review now moves the details to the new run, even if you were viewing an older one.
