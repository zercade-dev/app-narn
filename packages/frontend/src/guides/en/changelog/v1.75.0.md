## v1.75.0 — 2026-11-01

Freeway retries less wastefully and asks before using lower-quality models.

- Runs show which strings are waiting and let you choose whether to continue.
- A Freeway setting can continue automatically while marking affected strings for review.
- Filter the string table to find translations made below their target quality.
- Run details show requests, splits, model changes, and saved strings.
