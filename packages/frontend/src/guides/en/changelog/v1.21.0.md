## v1.21.0 — 2026-07-12

Glossary matches now default to showing all terms the moment you open a glossary.

- **Glossary matches** now default to showing **all terms** the moment you open a glossary, so the match view is never empty and you can start assigning right away.
- On hosted deployments, **Sharing** gains a **Select all / Unselect all** shortcut for a collaborator's languages, so granting or clearing every language is one click instead of many.
