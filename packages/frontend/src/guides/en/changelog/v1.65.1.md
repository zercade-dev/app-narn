## v1.65.1 — 2026-08-08

Text you type into a suggestion dropdown stays put after you close the list.

- Custom values such as your own model name or category no longer vanish a moment after the suggestion list closes, as long as nothing was picked from the list.
- Picking a suggestion from the list still fills the field exactly as before.

Stage details translations now show up straight away, even when a run finishes in an instant.

- A very fast stage details translation used to leave the page looking unchanged until you switched tabs or reloaded.
- The results now appear on their own as soon as the run is done.
