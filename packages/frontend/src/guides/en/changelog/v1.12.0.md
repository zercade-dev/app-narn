## v1.12.0 — 2026-07-08

New on hosted deployments: share projects with other people — invite collaborators and grant them editable languages.

* **New: share projects with other people.** Claim a nickname, generate a one-time invite code from the new Sharing tab, and collaborators can join from the Join Project page.
* Collaborators see the languages you grant them as editable; everything else stays readable for context and comparison.
* Collaborators bring their own AI setup: their runs use their own API keys, model instances, and a personal routing configuration shared across every project they collaborate on.
* The Activity tab now shows who triggered each run once a project is shared.
