## v1.31.1 — 2026-07-15

On hosted deployments, Stage details now works for your collaborators too.

- Collaborators can open the Stage details tab and see every field, translation, stale badge, and attribution.
- They can edit and translate the languages they've been granted, while everything else stays read-only.
- The AI assistant chat is available to collaborators, and its Apply buttons light up only for the languages they can edit.
- Source text stays owner-only, so the original wording is never changed by a collaborator.
