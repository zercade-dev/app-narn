## v1.35.0 — 2026-07-17

The Translations table got a big usability upgrade.

- The table now fills your whole screen — no more huge empty area below the rows.
- Each row is half as tall, with its status, category, and visibility shown on one line.
- The filter bar arranges itself neatly on smaller screens.
- Screens without a selected project now offer a button to pick one.
- Several accessibility improvements landed across the app, including clearer contrast for the vault-locked indicator.
