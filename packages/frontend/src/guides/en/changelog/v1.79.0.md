## v1.79.0 — 2026-11-04

Free usage is now labelled in the Activity tab and no longer counted toward your cost totals.

- Usage sent through Freeway, or on a free model, shows a "Freeway" or "Free model" badge on its line.
- Each of those lines still shows what it would have cost at paid rates, but that amount is left out of the run cost and the project total.
- A run that used only free usage shows "Free" as its cost.

NARN Freeway is now the default for projects without routing rules, recovers faster from provider limits, and fixes failed strings together at the end of a run.

- Projects without any routing rule no longer fail with "no route" and instead use NARN Freeway until you choose a provider.
- The Routing tab shows Freeway as the current provider, with a note, until you pick one; picking any provider still saves a rule as before.
- Projects that already have rules are unchanged, and a language no rule covers is still refused.
- AI review, source review, glossary generation and category generation start on your last choice, or on NARN Freeway when you have none and it is available.
- Strings that were waiting on free quota restart as soon as their own wait is over, even while the rest of the run is still going.
- The "resumes at" time shown for a waiting run is always the next real restart time, never one that has already passed.
- Short per-minute limits now wait only as long as the provider asks, so work resumes in seconds rather than a full minute or more.
- Requests to small-allowance models are spread across the minute instead of being sent all at once.
- Work moved to another model now waits its turn there and is split to that model's batch size.
- For every AI provider, strings that fail a quality check are fixed together in a few grouped requests at the end of the run, instead of one request each as they come up.
- While those fixes run, the Activity tab shows how many strings are being fixed.
- The activity log shows one summary line per batch for strings that came out longer than allowed, instead of one line per string.
