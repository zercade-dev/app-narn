## v1.31.2 — 2026-07-17

Fixes from your feedback: a working Text Styler assistant, fresher stage details, and a tidier interface.

- The Text Styler assistant now tells you when it still needs a provider and model picked, with a one-click shortcut to its settings — no more silent Send button.
- Stage details translations now appear as soon as their run finishes, even if you had switched to another tab in the meantime — no page refresh needed.
- The Quality tab shows one color legend for the whole page, and each language and source now appears in a single table with its pass-rate bar built in.
- Older changelog entries are grouped by release day again.
- The model reload button no longer overflows narrow panels, and the stage-details translate options got their missing padding.
