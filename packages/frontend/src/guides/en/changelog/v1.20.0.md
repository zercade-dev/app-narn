## v1.20.0 — 2026-07-12

The Color Text tool is now Text Styler, adding bold, italic, and font size alongside colours.

- The **Color Text** tool is now **Text Styler**. Alongside colours, you can now make selected text **bold**, *italic*, or set a specific font **size** using simple tags — in both the raw and visual editors — with a live preview of the result.
- New **AI writing assistant**: a collapsible side panel where you can ask an AI (using your own configured provider and model) to suggest improvements to your styled text, then apply any suggested rewrite back into the editor with a single click.
