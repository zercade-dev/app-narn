## v1.19.0 — 2026-07-11

CSV import got a cleaner look, defaulting to Full replace.

- CSV import: the import popup got a cleaner look with a proper mode switch, and now defaults to Full replace. "Add & update" imports no longer hide entries that are missing from your file.
- Quality dashboard: clicking a cell now opens the Multi-language text tab with exactly that filter — previous filters no longer stack into empty results.
- AI review: pick languages faster with Select all / Deselect all and a compact grid, applying a suggestion jumps straight to the next item, reviews now include a suggested fix whenever an issue is found, and re-requesting a suggestion respects verbose logging.
- Push to DeepL: pushing one glossary no longer removes terms previously pushed from another.
