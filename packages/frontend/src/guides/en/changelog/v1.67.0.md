## v1.67.0 — 2026-08-14

The page now tells your browser which language the interface is in, so screen readers, spell-check and hyphenation all behave correctly when you switch away from English.

- Previously the page always identified itself as English, whichever interface language you had chosen.
- Screen readers announced Spanish and French text with English pronunciation.
- Text that the design shows in capitals is also capitalised correctly now — some languages have their own rules for it, and browsers only apply them when the page says what language it is.

The interface is now available in Indonesian, Italian, Korean, Brazilian Portuguese, Thai, Vietnamese, Simplified Chinese and Traditional Chinese — pick yours under Settings.

- Every screen is translated, not just the common ones: the whole app, including logs, the credential vault, collaboration and the legal pages.
- Each language was reviewed by a second pair of eyes and then checked again across the finished translation, so the wording stays consistent from one screen to the next.
- Your choice is remembered, and you can also share a link that opens in a particular language.
- Imported "Source" tags now also display correctly in these languages instead of falling back to English.

NARN Freeway routes smarter: the free-model catalog was re-benchmarked for translation quality and shared provider quotas are now tracked as one budget.

- Every bundled free model was scored on a multi-language translation benchmark; rankings now reflect measured quality, with retired or unreliable models removed and stronger ones added.
- OpenRouter's account-wide free allowance is treated as a single shared pool, so Freeway no longer over-plans against it, and a rate limit on one model briefly cools the whole pool instead of burning retries.
- DeepL's measured quality earned it a big promotion in the routing order, and its monthly character allowance is saved for when daily free quotas run out; per-minute rate limits now pause a provider briefly instead of for the rest of the day.
- Freeway now decides per model whether to request structured output from the provider, based on tested support — no configuration needed, and one model's quirks never break another's run.

Freeway now taps six more free Google models — led by Gemma 4, which adds thousands of free translations per day at top-tier quality.

- Added Gemma 4 31B and 26B: both scored 99.8–100 in our translation benchmark and bring by far the largest free daily allowances.
- Added four Gemini fallback models (3.6 Flash, 3.5 Flash, 3 Flash, 3.1 Flash Lite), each with its own separate free quota.
- Refreshed Google's free-tier limits to the current, much lower Gemini values so Freeway plans runs against real quotas.
- Each model now uses the JSON output mode it actually supports, managed automatically per model.

The interface is now available in German, Japanese and Turkish — pick yours under Settings, alongside English, Spanish, French and Russian.

- Every screen is translated, not just the common ones: the whole app, including logs, the credential vault, collaboration and the legal pages.
- Each language was reviewed by a second pair of eyes and then checked again across the finished translation, so the wording stays consistent from one screen to the next.
- Your choice is remembered, and you can also share a link that opens in a particular language.

Groq's free-plan routing now runs on measured data — we benchmarked its free models and kept the two that translate best.

- GPT-OSS 120B scored highest in our translation benchmark and becomes Groq's strong general model.
- Llama 3.3 70B stays as a fast second option; weaker models were excluded after failing parts of the benchmark.
- Model quotas, context sizes, and JSON-output behavior are now recorded per model from live measurements.
- Reasoning-capable Groq models now honor the reasoning effort setting, and the model picker shows Groq's per-model pricing.

Groq is now a first-class translation provider — add your Groq API key and its fast, low-cost models are available everywhere, including free-plan routing.

- New Groq module with live model catalog, translations, AI review, chat, and glossary/category generation.
- NARN Freeway can now route free-plan work through Groq on cloud as well as local installs.
- The cloud subprocessor list and privacy pages now cover Groq; you'll be asked to re-accept the updated policies.

The AI review button that applies every suggested translation now says "Apply all suggestions", not "Approve all suggestions".

- The button was writing suggestions straight into your translations, not sending anything to translation memory, so "Approve" was the wrong word for what it does.
- Its own confirmation message already said "Applied" — the button now agrees with it.
- Fixed in English, Spanish, and French; every other supported language already used the correct word.

NARN Freeway automatically spreads your translation work across the free plans of your connected AI providers, so you can translate for free before spending a cent.

- Freeway picks the best free model for each batch across Gemini, OpenRouter, DeepL, and — when you run NARN yourself — Groq, Mistral, and Cerebras, failing over to the next provider when one runs low.
- When every free source is out of quota, a run pauses itself and resumes automatically once quota refills, with a "resume now with…" option if you'd rather not wait.
- A new Freeway section in Global Config shows how much free quota each provider has left, plus one-click setup for the providers available when you run NARN yourself.
- AI review (judge and source review) can also use the free pool.

Imported "Source" tags — Tab, Achievement, Item and the rest — now display in German, Japanese, Russian and Turkish instead of falling back to English.

- These tags come from your imported file and are stored exactly as imported; only how they are shown changes, so exports are unaffected.
- Previously only English, Spanish and French had translated forms, so anyone reading the app in another language saw them in English.
- The wording comes from the reference files themselves, so a tag imported in one language reads correctly whichever interface language you use.
