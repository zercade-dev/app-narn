## v1.9.5 — 2026-07-03

The Compare tab now keeps a short history for each translated cell, with undo and restore.

* The Compare tab now keeps a short history for each translated cell: a new undo button shows the previous versions with a diff, and lets you restore any of them (or undo the undo).
* Relink AI retranslation now updates every language for a string in a single AI request, giving more consistent results across languages.
* Relink retranslation runs now show up in Activity with the same details as regular translation runs — see what changed per language, and revert the whole run if needed.
