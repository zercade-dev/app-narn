## v1.61.0 — 2026-08-02

Bold and italic tags are now treated like colour and size tags everywhere.

- They are hidden from the translation provider so it can't rewrite or lose them.
- The quality check now flags a translation that drops or duplicates a `<b>` or `<i>` pair, instead of quietly letting it through.
- The Compare view renders them as real bold and italic text rather than showing the raw tags.
- Every build of the app now produces a `LICENSES.txt` file alongside it, listing each of the open-source libraries, interface components and typefaces the app is built from, together with the full licence text each of their authors published. Until now those notices were stripped out when the interface code was packaged for release, so they did not travel with the part of the app your browser downloads. The file travels with the app: it is part of the download, it is inside the container image, and a running instance serves it. Nothing about using the app changes.
- Anyone setting up NARN from source can now leave out GitHub's Copilot command-line tool, which the Copilot provider depends on and which is proprietary software rather than open source. Until now it was unavoidable: skipping it broke the build for everyone, whether or not they translate with Copilot. Installing without optional dependencies now works, and the app builds and runs normally without it. A standard install is unchanged and still includes the tool, and the Copilot provider appears in the provider list either way — if you leave the tool out and then pick Copilot, it tells you what to install.
- The six typefaces NARN's interface and themes are built from are now listed as production dependencies rather than development ones, which is what they always were in practice: their font files are part of every build the app serves. Nothing about the app changes — it looks and behaves exactly the same — but anyone installing NARN from source, or checking what it redistributes, now gets an accurate answer from the standard tooling instead of having to read the fine print.
- When you run NARN yourself, the Text Styler and Stage details AI assistants can now use a Generic AI (OpenAI-compatible) provider — including local models like Ollama or LM Studio — as their chat backend, in addition to the providers that call a remote API.
- The project's own documentation now reads correctly for anyone who picks up the NARN source on its own: the setup notes no longer refer to a companion repository they can't see, they say up front what needs to be in place before the app will start, and the list of built-in translation providers is complete.
- The Docker instructions now describe the folder you actually run them from and which published image you get, and the sample configuration file now covers the settings that were missing from it, including backups, log retention and deployment labels.
- The contact address shown on the account page and in error messages is now set by whoever runs your NARN instance, instead of being fixed. Self-hosted instances that haven't set one simply won't show a contact link, rather than pointing you at an address that can't help you.
- The Glossary and Orphans tabs now tell you what to do when no project is selected, the same way every other tab does, instead of showing a leftover development note. Fixed in English, Spanish and French.
