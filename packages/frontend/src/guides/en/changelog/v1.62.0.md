## v1.62.0 — 2026-08-02

Running your own copy of NARN no longer needs a source checkout or a build. The
project's README now has a Docker quick start: one published image serves the app and
its interface together, and either recipe — Docker Compose or plain Docker — brings up
NARN and its database with a single command. The Compose recipe is the recommended one,
because it also keeps the database off your network and runs the app with the
restrictions a self-hosted instance should have. The notes that follow cover where your
data lives, which parts must be kept when you replace the container, and how to pin a
specific version instead of tracking the newest one.
