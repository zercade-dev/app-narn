## v1.65.0 — 2026-08-07

AI runs and assistant chats now show inline Cancel buttons and failure notifications.
- Cancel a translation, source review, category generation, or translation review run right from its own tab — no need to open Activity.
- If a background run or an assistant chat request fails, you'll get a notification immediately instead of only finding out later.

The Changelog page reads properly again.

- The newest release's entry showed raw formatting marks above its summary; it now renders the way it was meant to.
- Entries from v1.33.0 onward now lead with a one-line summary and put the detail in bullets, matching the entries before them.
- The collapsed "Show older releases" list is one line per release again, rather than a full paragraph for each.

Choose light or dark when you first open NARN, alongside your theme.

- The first-run appearance screen now offers Light and Dark next to the theme cards.
- Picking one previews it straight away, so you can see the mode and the theme together before you commit.
- Previously light or dark simply followed your system setting, and changing it meant a separate trip to Settings.
- You can still change either one at any time in Settings.

Added a warning in module settings for a known issue with OpenAI's GPT-5.6 Luna model.
- When Luna is selected with structured output enabled, you'll now see a warning that it frequently refuses to translate instead of completing the request.
- If you run into this, try disabling structured output for Luna or switching to a different model.

The Stage Details AI assistant now answers plain questions directly instead of always proposing a rewrite.
- Ask something like "is this translation correct?" and get a straight answer, not a forced suggestion.
