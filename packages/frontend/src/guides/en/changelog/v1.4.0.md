## v1.4.0 — 2026-07-01

A reorganized navigation splits Project/Config from Data, and translation runs can now be reverted from the Activity tab.

* New navigation: a Page tab group, a clearer Project / Config + Data split, and the Batch tab is now Routing.
* Translation runs save the previous values, so you can revert a run from the Activity tab.
* Orphan relinking suggests the closest matches and asks for confirmation before AI retranslation.
* Entries added by a CSV import are flagged as new.
* Read-only glossaries automatically ignore incomplete terms.
* You can name your credential vault.
* Reasoning effort starts disabled when you first enable a module.
* Run progress updates as each translation completes.
