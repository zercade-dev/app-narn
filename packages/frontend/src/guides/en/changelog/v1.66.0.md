## v1.66.0 — 2026-08-11

A pass over the English wording: buttons and dialog titles now use sentence case, and several labels finally say what they mean.

- The Default theme is now called Classic, matching the description underneath it, in Spanish and French too.
- Strings that still pointed you at the "Multi-language text tab" now name the Translations tab, which is what that tab is called.
- The routing rules' "Entry lenght limit" typo is fixed, and its confidence note no longer says "entries exceeds".
- "Prev" in the source review is now "Previous", the category page's "Select none" is now "Deselect all", and restoring a backup reports "Backup restored."
- About fifteen button and dialog labels across Backup, Batch, Routing, Templates and the Translations tab moved from Title Case to sentence case, so controls read the same way everywhere.

Counts in a few import and export messages now read correctly for plural amounts.

- Import used to report "5 glossary disabled" and "3 malformed row dropped"; both now match the number they show, in English, Spanish and French.
- The export round-trip warning now says "cells" when it means more than one, and points at the single cell when there is only one.

The console now explains what happened in plain language instead of printing internal event names, and offers a shortcut to the screen where you can fix it.

- Repeated messages are grouped into a single line with a count, so a large run no longer floods the panel.
- Expand a line's chevron to see the full technical detail behind it.
- Exported logs are unchanged and still contain everything, for sharing with support.
- Error messages elsewhere in the app lead with a plain explanation, keeping the technical reason as a secondary line.

Creating a glossary by hand is now an obvious button in the Glossary tab, sitting above the AI generation option.

- "New glossary" used to be a small unlabelled plus icon in the sidebar header, so it was easy to miss next to the labelled AI button.
- It is now a full-width labelled button, listed first, so hand-made and AI-generated glossaries are both easy to find.

The glossary matches panel is now fully translated in Spanish and French, and a handful of English labels now match the wording used elsewhere in the app.

- Eleven strings in the glossary matches panel were still showing in English for Spanish and French users; they now appear in your language.
- The glossary action buttons and confirm dialogs now read "Assign glossary", "Unassign glossary", "Delete glossary" and "Delete term", matching the sentence case every other control uses.
- The Sharing tab's language shortcut now says "Deselect all", the same wording as the identical control on the other tabs.
- Relinking an orphan with AI now says "re-translate" and "re-translation" in the relink options, its toasts and its Activity row, spelled the same way as everywhere else in the app.

Adding another provider instance no longer asks you to invent an id — the form arrives filled in and ready to create.

- The instance id and display name are suggested for you, and the id is numbered automatically when one already exists.
- The id field now explains that it is only a label to tell your instances apart, and that it cannot be changed later.

Keyboard shortcuts now name the key as it is printed on your own keyboard, and the legal links match the pages they open.

- The Spanish interface says Intro, and the French one says Entrée and Échap, instead of the English key names.
- Russian keeps the Latin key names, because that is what a Russian keyboard is engraved with.
- Three legal link labels did not match the title of the page they opened.

Language names in logs and quality checks now appear in the language you are using the app in.

- A Spanish or French interface previously printed language names in English mid-sentence.

You can now sign out from your phone — the Account page opens on a small screen instead of showing the desktop-only message.

- The page shows your nickname and the Sign out button; security, data and notification settings still need a larger screen.
- Claiming a nickname for the first time remains a desktop step, since it can only be done once.

Exports no longer carry a Pseudo Test column, so a file exported while pseudo testing loads in your game as usual.

- Turning on Pseudo Test used to add a Pseudo Test column to every export, which your game could not load.
- Pseudo Test is never exported as its own column, so leaving it switched on cannot affect the files you ship.
- Exporting pseudo text as a real language is unchanged: the chosen language's column carries the pseudo text, and nothing stored changes.

Pseudo Test now explains itself, with a new guide covering what it does and how to get it into your game.

- The Pseudo Test entry in your target languages has a help icon: hover for a short explanation, click to open the guide.
- The new guide walks through what the mangled text tells you — hardcoded strings, layout overflow and truncation — and how to export it under another language so your game will load it.

Routing rules now start simple: pick one provider to translate everything, and switch to the full rule editor only when you need it.

- The Routing tab opens on a single provider selector instead of the full rule builder.
- Switch to Advanced for rule groups, per-language and per-category rules, model overrides, and import/export.
- Your choice of Simple or Advanced is remembered by your browser, so you only set it once.
- Projects that already use several routing rules keep opening in the full editor, untouched.

NARN's interface is now available in Russian.

- Every screen, message and label has been translated, including plural forms for counts.
- Counts read correctly at every number, not just at one and many.
- Terminology matches across tabs, so the same thing is called the same thing everywhere.

The Comparison view's keyboard-shortcut help, its per-cell tooltips and its status chips now appear in your language.

- The shortcuts popover was still English-only; it is now translated along with the rest of the interface.
- The re-translate, mark-reviewed, clear and edit buttons on each translation cell now have translated tooltips and screen-reader labels too, worded to match the shortcuts popover exactly.
- The "translated", "reviewed" and "needs review" chips in each cell are translated as well, using the same wording as the matching filter.
- The key names themselves (T, R, C, Enter, Esc and the arrows) stay as they are — those are the keys on your keyboard, not words.
