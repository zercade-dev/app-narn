## v1.71.0 — 2026-08-27

NARN Freeway now reviews translations with the same routing care it brings to translating them.

- Review batches are now sized to the model actually serving them instead of a fixed size, preventing oversized requests on long text.
- Review scores now feed back into how free models are ranked, so NARN Freeway learns which model translates each language well, and it leaves out a model's score for its own translations wherever it can tell.
- When a free model hits its per-minute limit mid-review, NARN Freeway now waits briefly for the limit to reset, or moves the review to another free model, instead of failing the run.
- Your remaining free requests for the day now count every request a model really makes, including retries behind a single translation or review, so the number runs down faster than before but matches what the provider counts.

The Guide button in the sidebar is gently highlighted until your first translation is done.

- On a new install the sidebar is full of tabs that only make sense once you have entries and a provider set up, so the help is now the one thing that stands out.
- The highlight clears itself as soon as you have a translation, whether an AI run produced it or you typed it in yourself, and it does not come back.
- It follows whichever theme you use, in both light and dark.

The Guide has a new Questions & Answers topic, a page on NARN Freeway, and links you can click to jump between topics.

- Questions & Answers sits right after Quick Setup and covers the doubts that come up most: which entries a run actually translates and which it skips, where the three places to change the model are, why an entry can come back unchanged, and what to do when a run says there is no routing rule.
- A new NARN Freeway topic explains the free model pool end to end — turning it on, which providers feed it, what each status in the panel means, what happens when the free quota runs out, and how to use quality tiers to pay only for the entries a weaker model handled.
- References to other topics are now links: clicking one takes you straight there instead of leaving you to find it in the sidebar.
- Both new topics are available in all fifteen interface languages.
- Fixed: the Credential Vault page showed a stray `<!-- local-only -->` marker in the middle of the text on self-hosted installs.

Starting a translation with no routing rule for the language now tells you straight away, instead of running and failing.

- A run whose target language has no routing rule is stopped before it starts, so nothing is queued and no time is wasted.
- The message names the languages that have no rule and takes you to the Routing tab in one click.
- This applies everywhere you can start a translation: the multi-language text view, the Compare tab, and the Review tab.
- Runs where only some strings are unmatched are untouched — those still run, and report what they skipped afterwards.

The vault key picker no longer offers keys you have already set, and replacing one is now a deliberate click.

- Keys already stored in your vault are hidden from the "add a key" dropdown, so the list only shows what is still missing.
- Each stored key gets its own Replace button, which opens a row for that key ready for the new value.
- An existing key's value box stays locked until you press Replace, so a stray keystroke can no longer overwrite a working credential.
