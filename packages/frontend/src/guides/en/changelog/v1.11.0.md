## v1.11.0 — 2026-07-07

Added OpenRouter as a translation provider, giving access to models from many vendors with one API key.

* Added **OpenRouter** as a translation provider. Connect your own OpenRouter API key and pick from the full live model catalog — one key gives access to models from many vendors (Anthropic, OpenAI, Google, Meta, and more), with each model's pricing and context size shown right in the model picker. Only models that generate text are listed, so image and audio models never clutter the list.
