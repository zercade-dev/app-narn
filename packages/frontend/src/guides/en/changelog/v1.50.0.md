## v1.50.0 — 2026-07-19

The Translation AI review tab can now review every translation in your project in one go.

- Reviews are no longer limited to the output of your last translate run — handy if some or all of your strings arrived through a CSV import rather than a run through the app.
- A new "Review all translations" button sits next to "Run review", and works even when there's no completed run to point at.
