## v1.77.0 — 2026-11-02

Freeway now keeps the translations it already finished from an incomplete batch, and a new fast free Google model joins the lineup.

- When a batch comes back with some strings missing, Freeway keeps the finished ones and only asks again for the missing ones.
- Added Gemini 3.5 Flash Lite, a fast free Google model, to the Freeway free tier.

Fixed a bug where editing two Stage Details fields in quick succession could silently erase the first edit.

- Saving the stage name and then another field right after no longer loses the name.
- Edits made while a Stage Details translation run is saving are now kept too.
