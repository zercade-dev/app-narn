## v1.56.0 — 2026-07-28

Reloading the page while on the Stage details tab now keeps you there instead of bouncing you back to Config. A translation run that fails partway through (for example, a provider hiccup) is now correctly shown as failed rather than looking like it succeeded when nothing was actually translated. The Text Styler AI assistant now responds properly — a bug had it silently doing nothing when you clicked send. Fixed the "Clarity" quality-check tag being unreadable in the Pixel dark theme, and a stale quality-check warning that could linger on an achievement entry after it was retranslated or relinked. Selecting a row in the Compare tab now shows a clear highlight. In the string table, the achievement Group Key field is now internal-only, and its Link button reads "Linked" once an entry is linked (you can still click it to change the link).
