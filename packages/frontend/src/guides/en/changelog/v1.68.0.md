## v1.68.0 — 2026-08-21

Run dialogs now show a "Modified" badge next to Advanced options when the collapsed section is holding settings you changed.

- Applies to the translate, AI review, source review, glossary generation and category generation dialogs.
- The badge stays visible while the section is collapsed, covering the dialog's remembered settings so most non-default tuning no longer applies invisibly.
- Nothing about how the settings behave has changed — only whether you can see that they are set.

Run dialogs are simpler by default, and NARN Freeway can now be pointed at a specific provider setup instead of always picking automatically.

- Translation, review, and generation dialogs now show just the choice that matters, with the tuning options tucked behind an "Advanced options" tick that NARN remembers between runs.
- Anything you set while Advanced options is open keeps applying even after you collapse it back down.
- NARN Freeway can now be pointed at a specific one of a provider's setups, chosen by name, instead of always picking automatically; leaving it on Automatic keeps today's behavior.

Fixed: choosing "Tone" for batch grouping in a project's Config tab now actually saves.

- The Tone option was visible in the dropdown, but saving it failed with an error because the server didn't recognize the value yet.
- Tone grouping now works everywhere batch grouping is offered — project settings, workspace defaults, and per-run overrides.

The console can now capture every log entry of a long run for download and analysis.

- Turn on "Capture all logs" in the console to keep the full log server-side, beyond the usual console limits.
- Download the capture as an NDJSON file at any time, during or after the run.
- Capture is opt-in and bounded, and it shows how many entries were dropped if a cap is ever hit.

The console log now keeps each account's own errors and tells you when older entries are no longer available.

- On the hosted version, one busy account's activity no longer pushes another account's earliest errors out of the log.
- The log now also counts anything the server had already dropped before you opened the page, so an exported log never looks complete when it is not.
- The "earlier entries dropped" note now reads correctly when only one entry was dropped.

AI glossary and category generation can now run on NARN Freeway's free model pool, and background AI runs recover from rate limits instead of failing.

- Both the "Generate Glossary" and "Generate Categories" panels now offer NARN Freeway as a provider, spending free-tier quota the same way translation and review runs already do.
- A background run that hits a provider rate limit now moves to another free model once instead of failing the run.
- Free-pool selection now accounts for how much work a run will actually send, picking a bucket with room for it.

The Freeway panel now names exactly which connection has bad credentials, and clears the warning automatically once it's fixed, or with one click if it doesn't.

- Saving a working key now clears the bad-credentials warning for every connection to that provider, not just some of them.
- Connections whose keys you didn't touch are unaffected.
- A bad-credentials warning now shows which connection is affected and which vault entry to fix, so two keys for the same provider are no longer indistinguishable.
- A new "Try again" button clears the warning directly from the panel once you've saved the right key, so you don't have to re-save it just to check.
- If a "Try again" click arrives after the warning has already stopped applying, the panel now explains that plainly instead of showing a raw error.

The NARN Freeway instance picker's open dropdown no longer clips long instance names.

- Instance names that share a starting prefix (for example two keys for the same provider) are now fully visible in the list, so you can tell them apart.
- The collapsed selector still shows a short name to keep provider rows aligned, but hovering it now reveals the full name.

NARN Freeway now paces requests to each free provider's per-minute limit, so large runs no longer fail partway through with rate-limit errors.

- Free models that only allow a handful of requests per minute are no longer overwhelmed by a large multi-language run — one earlier run lost 142 entries this way.
- When a model's allowance for the current minute runs out, NARN sets it aside and comes back to it seconds later, instead of treating it as unavailable for the rest of the day.
- Other available models keep working in the meantime, so a run keeps making progress instead of stalling.

The Freeway status table no longer makes a shared free-tier allowance look bigger than it is.

- Free-tier models that actually share one daily allowance (like OpenRouter's free models) now show that allowance once, under a single "Shared pool" row.
- Each model underneath still shows its own state and pass rate — only the repeated daily total is gone.
- Providers with their own separate allowance per model are unchanged.

NARN Freeway spreads work across your free providers by how much quota a job would use, but quality always comes first.

- A model with a weak track record for a language is pushed behind healthier models, even when it has a much larger free allowance.
- Among equally healthy models, the one with the roomiest remaining allowance goes first, so small allowances are worked down last and last longer.
- This accounts for known trouble spots as well as recent results, so a model can be deprioritized for a hard language before it has ever been tried.
- Runs are less likely to end up "Waiting for free quota" while another provider still has plenty of its allowance left.
- Nothing is taken out of rotation: a struggling model is still used when it is the best available option for a language.
- A single bad result no longer writes a model off: NARN Freeway weighs how much it has actually seen, so one unlucky string barely moves the needle while a consistent pattern does.
- Judgements fade while a model goes unused, so one that struggled weeks ago gets a fresh chance instead of staying sidelined for good.

Parked runs on the Activity tab now say why they're waiting, not just that they are.
- A run paused because a free provider kept failing shows a distinct message instead of the generic "waiting for quota" text.
- Runs paused because the shared free quota simply ran out are unaffected.
- Purely informational — parked pairs still resume automatically either way.

Freeway free-tier translation recovers better from provider outages, restarts, and quota edge cases.

- Runs parked on free-tier quota now resume automatically after a server restart, once the credential vault is unlocked.
- Providers that keep failing back off progressively instead of retrying every 15 minutes forever.
- Google per-minute rate limits are no longer mistaken for daily quotas, so brief waits stay brief.
- Harder texts served by a relaxed quality tier are now always visible in the run's activity detail.
- Entries with empty source text no longer re-enter every run's totals.

Selected rows can now be re-translated in one click when a NARN Freeway model served them below a quality tier you choose.

- The bulk action bar's new "Re-translate below tier" control picks a threshold and re-translates only the matching translations in your selection.
- It targets exactly the weak translations — a good translation in another language of the same entry is never overwritten.
- The re-translation is asked for at least the chosen tier, so it doesn't just land on the same free model again.

NARN Freeway now recovers from dead models and provider outages instead of failing entries.
- A batch that fails wholesale on a retired or unavailable model is retried on another free provider automatically, and the dead model is sidelined until its quota day resets.
- Providers whose daily quota is exhausted are set aside until the quota returns, instead of being retried every minute.
- A translation that hits a temporary provider hiccup ("high demand", timeouts) is retried once before ever being marked failed.
- Freeway spends fewer free-tier requests on failing providers — one attempt per call instead of three.
- A demanding entry that would otherwise wait a long time for its preferred quality tier is translated on the next tier down instead, so it never stalls for the rest of the day.

Translations from NARN Freeway now show which quality tier served them, right on the cell.

- A small badge on any Freeway-produced translation names the free model's quality tier, with a tooltip explaining it.
- A new "Served below tier" filter finds translations produced by weaker free models, so you can spot-check or retranslate them.
- Non-Freeway translations are unaffected — the badge only appears when a translation actually came from NARN Freeway.

The Freeway status table's per-language pass rates no longer get stuck at a stale reading, including a permanent 0%, once the underlying results have moved on.

- Percentages shown in the panel now recompute on every read the same way NARN's routing already accounts for older results fading, so the display catches up instead of freezing.
- A model that struggled weeks ago and has since recovered now shows that recovery in the panel, not a permanently stuck 0%.

Errors and warnings in the log now stay put during a busy run instead of scrolling away before you notice them.

- A large translation run no longer pushes error and warning lines out of the log just because a lot of ordinary activity is happening at the same time.
- The log keeps the earliest problems as well as the most recent, so the very first thing that went wrong is still there to explain the rest.
- NARN Freeway's status table now says "Bad credentials" instead of "Module disabled" when a provider's key was rejected, so an enabled provider no longer looks switched off.
