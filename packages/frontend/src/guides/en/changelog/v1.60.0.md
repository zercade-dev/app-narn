## v1.60.0 — 2026-07-30

The Quick Setup guide now folds its optional steps away. Everything you actually need to get a first translation out stays open in front of you, and each step you can safely skip on a first pass — reviewing your source text, enabling glossaries, building glossaries from your own content, iterating in Compare — sits behind a heading you can click open when you want it.

The guide's provider pages are now named the way the providers name themselves, so the entry in the guide list matches what you see when you enable the module in Global Config: Anthropic (Claude), OpenAI (GPT), Google AI (Gemini) and GitHub Copilot.
