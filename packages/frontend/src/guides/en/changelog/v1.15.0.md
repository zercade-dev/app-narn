## v1.15.0 — 2026-07-09

CSV import now asks how to apply the file: Add & update or Full replace.

* CSV import now asks how to apply the file: **Add & update** (the default — entries missing from the file are always kept) or **Full replace**, which marks missing entries as orphaned so you can relink or delete them from the Relink tab whenever you're ready.
* Re-importing a CSV no longer erases an entry's context when the file's Context column is empty.
