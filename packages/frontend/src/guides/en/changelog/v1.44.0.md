## v1.44.0 — 2026-07-17

The instructions narn sends to AI models were rebuilt end to end and stress-tested against three different model tiers at real batch sizes. Translations now explain protected placeholders explicitly, name languages instead of using bare codes (so regional variants translate better), and let glossary terms bend naturally to grammar instead of being forced in word-for-word. AI review verdicts are more consistent between models, review suggestions now settle wording inconsistencies toward the batch majority, and re-translation after a source edit tells the model exactly what changed.
