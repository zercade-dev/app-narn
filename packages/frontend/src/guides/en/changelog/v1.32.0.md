## v1.32.0 — 2026-07-17

Watch your translations progress live, with a real progress bar.

- Translation and review runs now show a progress bar everywhere run progress appears — the Activity tab, mobile run cards, bulk actions, and stage details — with failed items tinted so you can spot problems at a glance.
- Progress updates arrive the moment each batch of translations comes back, instead of waiting for the next refresh cycle.
- Runs with an unknown size show an animated bar while they get going.
