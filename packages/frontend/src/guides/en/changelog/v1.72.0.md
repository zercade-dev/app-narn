## v1.72.0 — 2026-08-28

NARN Freeway runs are much faster: it now sends many translation requests at once instead of three, paced to each provider's limits.

- Freeway keeps several providers busy in parallel, staying within what each one allows per minute rather than leaving most of that allowance unused.
- Providers that limit by tokens rather than by request count are now paced correctly too.
- Retries, split batches and provider switchovers all count towards pacing, so a run that hits trouble no longer speeds up and runs into rate limits.

NARN Freeway now packs more strings into each translation request on larger runs, so those runs finish sooner.

- Smaller runs keep the more cautious request size that helps translations come back cleanly.

NARN Freeway now picks better models for long runs, and pauses for quota far less often.

- Previously a strong model with a low per-minute limit was skipped almost entirely on a long run, even when it had plenty of daily quota left.
- Daily and shared limits are unchanged — only the way the per-minute allowance is planned.
