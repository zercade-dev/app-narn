## v1.9.18 — 2026-07-04

Fixed the "Enabled Glossaries" row menu to correctly show and let you unset that entry's own glossaries.

* Fixed: the "Enabled Glossaries" menu on a row (Multi-language Text and Compare tabs) now correctly shows and lets you unset that entry's own glossaries, instead of an unrelated project-wide list.
* The Glossary tab now has an "Unassign" action when filtering to entries that already have a glossary.
* Clearer labels in the glossary-generation dialog for the two translation-related options, plus a "Select all" toggle for language pickers in generation dialogs.
* Fixed: a failed glossary-generation run could get stuck — you can now discard it and try again without reloading the page.
* Compare tab: the runs filter is wider and easier to read, and now shows only the most recent 20 runs.
* Compare tab: approving a translation now moves focus to the next row automatically.
* You can now ignore/unignore an entry directly from its row on the Multi-language Text and Compare tabs.
* The AI review dialog now lets you choose which languages to review (defaults to all active languages).
