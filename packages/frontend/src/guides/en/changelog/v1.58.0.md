## v1.58.0 — 2026-07-29

Assistant chats now show up in the Activity tab straight away.

- Chats appear as soon as they start, instead of only appearing once the reply had finished — so a slow answer no longer looks like nothing is happening.
- Each turn is also recorded properly when it fails or when you navigate away mid-reply, rather than quietly disappearing.
- Both assistants gained a "Verbose logs" setting, off by default: switch it on and the live log panel reports how long each reply took, how long it waited before the first word arrived, and how large the request was, which makes a slow reply much easier to explain.
- Those details stay in your own log view and are never written to the server's shared logs.
