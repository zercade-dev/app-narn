Freeway now balances translation quality and speed by default.

- Balanced is the new default, so routing changes for existing users: slow models are avoided when a good faster model is available.
- A new Prioritize setting in the Freeway panel lets you favor Quality, Balanced or Speed.
- The Freeway status table shows Translation, Speed and Overall scores for each model, and marks models that are Too slow.
- When a run pauses below target quality, the confirmation now lists any slow models it would use.
