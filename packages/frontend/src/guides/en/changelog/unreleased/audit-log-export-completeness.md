Exporting your audit log now includes the events recorded today, not just the archived files.

- The export used to read only the archived log files, so everything recorded since the last archive was left out — after a restart, that was the whole retained window.
- The current log is now merged in, and an event that appears in both places is counted once rather than twice.
- Narrowing an export by event type or time range now applies to the file entries too, so the exported count means what it says.
