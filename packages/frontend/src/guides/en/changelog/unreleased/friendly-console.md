The console now explains what happened in plain language instead of printing internal event names, and offers a shortcut to the screen where you can fix it.

- Repeated messages are grouped into a single line with a count, so a large run no longer floods the panel.
- Expand a line's chevron to see the full technical detail behind it.
- Exported logs are unchanged and still contain everything, for sharing with support.
- Error messages elsewhere in the app no longer show raw server text.
