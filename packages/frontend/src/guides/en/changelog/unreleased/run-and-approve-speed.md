Big translation runs and bulk approvals now repeat far less work behind the scenes, so they finish sooner and leave the app responsive.

- The automatic quality check on each finished translation used to re-read the whole project first, once for every string and language a run produced.
- Approving a large selection re-read your glossaries once per approved translation; it now reads them once per language, exactly as a translation run does.
- The checks and the approvals themselves are unchanged: same verdicts, same terms, same results.
- Quality-check settings you change while a run is under way now take effect on the next run, or when a paused run resumes, rather than part-way through the one already going.
