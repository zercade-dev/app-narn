Guided tours now keep the keyboard on the step they show, and never leave you without a way forward.

- While a tour dims the page, Tab and Enter reach only the tour's message and the control it points at, as the mouse does.
- A control a tour only shows can no longer be used from the keyboard either.
- When a step's control is not on screen, the step says so and shows Next.
- Clicking Next quickly several times moves on each time; only a double click counts as one.
- On a phone-sized screen, tours are listed in the Guide but start only on a wider screen.
