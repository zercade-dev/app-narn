New users are now walked through setup, from creating a vault password to exporting their first translation.

- New users with no projects start in Simple mode, which shows only the tabs needed for a first translation.
- A five-step guided setup covers the vault password, one free key, creating a project and importing it, translating, and exporting.
- You can skip the guided setup and resume it any time from the sidebar, or restart it from the Guide.
- A Simple/Advanced switch in the top bar and in Settings lets you change modes whenever you like.
- In Advanced mode, Routing, Glossary, Quality, Compare and Translation AI review each offer a short tour the first time you open them.
- Tours can be started again from the Guide, and a setting turns the offers off.
- The Quick Setup guide now leads with the short path, with the optional steps after it.
