NARN Freeway now recovers on its own when you fix a provider key, and uses the provider setup you actually see in Global Config.

- A rejected API key no longer switches a free provider off for good — updating the key in the vault brings it straight back.
- A bad key on one provider setup no longer takes down your other setups for the same provider.
- Freeway now runs through the provider instance shown in Global Config, and names which one served each model.
