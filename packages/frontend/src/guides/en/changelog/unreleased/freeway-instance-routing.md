NARN Freeway now works with the providers you set up as named instances, and its panel starts collapsed.

- Freeway routes through the provider instance you configured (for example your default Groq or Google setup) instead of only the bare base module, so free-tier routing works on the web app.
- The "Enable it" shortcut now scrolls to the control that actually turns a module back on.
- Mistral and Cerebras were removed from the free-provider list — they were never available outside a local one-click setup.
- The NARN Freeway panel is collapsed until you open it, and only loads its status then.
