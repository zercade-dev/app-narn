The guide can now test-translate a file that is already fully translated, and put your translations back afterwards.

- When your file already has every translation, the guide walks you through retranslating 3 entries yourself, so you can see a translation happen.
- After that test, the guide walks you to the restore point saved just before it, or you can keep the new translations.
- Simple mode now has a short Backups page for making, restoring and downloading backups.
- The guide's key step opens one provider list, with free-tier providers first and a Get a key link beside each one.
- The guide stays on screen while the provider list or the provider panel is open, and says what to do there.
- The import review is shorter: one line per warning, with the language list for raw line breaks one click away.
- The Translations list now shows every entry by default, not only the untranslated ones.
- The Glossaries tour moves on as soon as you create a glossary, even when the project already has one.
- Tours stand out in the Guide menu.
