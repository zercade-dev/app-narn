Routing rules now start simple: pick one provider to translate everything, and switch to the full rule editor only when you need it.

- The Routing tab opens on a single provider selector instead of the full rule builder.
- Switch to Advanced for rule groups, per-language and per-category rules, model overrides, and import/export.
- Your choice of Simple or Advanced is remembered by your browser, so you only set it once.
- Projects that already use several routing rules keep opening in the full editor, untouched.
