You can now see when a model keeps failing, even if your run still finishes.

- A run warns you once, and keeps a line on its card in the Activity tab, when a model keeps rejecting requests with the same error.
- The line names the model, how many strings were affected, what the provider said, and whether those requests moved to another model.
- Warnings in the console now appear in amber, with their own unread count next to the red error count.
