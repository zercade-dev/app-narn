The model picker's list can now be used from the keyboard alone.

- Choosing a model used to need a mouse — the rows in the model dialog could not be reached or activated with the keyboard at all.
- Press the down arrow from the search box to step into the list, move with the arrow keys or Home and End, then press Enter or Space to choose the highlighted model.
- The row the keyboard is on is now outlined, and screen readers announce which model is currently selected.
