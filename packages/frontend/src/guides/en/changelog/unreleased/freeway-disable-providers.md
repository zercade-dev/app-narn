You can now turn off a provider for NARN Freeway without touching your routing rules.

- Every free provider's Freeway selector now offers a "Disabled" option alongside Automatic and any named instances.
- Freeway skips a disabled provider for every new run until you turn it back on; a run that is already in progress may finish on the model it started with.
- DeepL now gets its own selector too, so it can be included or excluded from Freeway the same way as every other provider.
