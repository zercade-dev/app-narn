NARN Freeway is now the default: a project with no routing rules translates through it, and AI review and generation popups open on it.

- Projects without any routing rule no longer fail with "no route" and instead use NARN Freeway until you choose a provider.
- The Routing tab shows Freeway as the current provider, with a note, until you pick one; picking any provider still saves a rule as before.
- Projects that already have rules are unchanged, and a language no rule covers is still refused.
- AI review, source review, glossary generation and category generation now start on your last choice, or NARN Freeway when you have none.
