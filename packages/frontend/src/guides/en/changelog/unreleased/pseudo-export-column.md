Exports no longer carry a Pseudo Test column, so a file exported while pseudo testing loads in your game as usual.

- Turning on Pseudo Test used to add a Pseudo Test column to every export, which your game could not load.
- Pseudo Test is never exported as its own column, so leaving it switched on cannot affect the files you ship.
- Exporting pseudo text as a real language is unchanged: the chosen language's column carries the pseudo text, and nothing stored changes.
