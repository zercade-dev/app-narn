Errors and warnings in the log now stay put during a busy run instead of scrolling away before you notice them.

- A large translation run no longer pushes error and warning lines out of the log just because a lot of ordinary activity is happening at the same time.
- The log keeps the earliest problems as well as the most recent, so the very first thing that went wrong is still there to explain the rest.
- NARN Freeway's status table now says "Bad credentials" instead of "Module disabled" when a provider's key was rejected, so an enabled provider no longer looks switched off.
