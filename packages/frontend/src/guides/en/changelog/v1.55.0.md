## v1.55.0 — 2026-07-27

The AI assistants now let you dial in how much the model "thinks" before it answers.

- A new control sits right next to the model picker in each assistant's settings, for both Stage details and the Text Styler.
- Both also show a clear "thinking" indicator with a live elapsed-time counter while waiting on that first response, so a slower, more thoughtful model no longer looks like it's just hung.
- When the Stage details assistant proposes an edit, the preview card now includes a short note on why the change is an improvement, not just the change itself.
