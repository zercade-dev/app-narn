## v1.49.0 — 2026-07-18

More theme polish, driven by your feedback. Theme fonts now reach even further into the interface — labels, tooltips, dropdown options, search boxes, table headers, the console, and run details all pick up the active theme's typeface, while source and translation text deliberately stay on the regular font so they remain easy to read. The Pixel theme gained a full set of hand-drawn icons for row actions, game-like row-action buttons, a three-state pass/warning/failure indicator for quality checks, chunky square checkboxes, and hard-edged tooltips and dropdowns; the Techno theme picked up a matching neon command-deck treatment of its own. A batch of text-clipping problems is fixed too — long module names, instance labels, batch-grouping options, the string ordering selector, and routing group names no longer get cut off mid-word, and the routing group buttons line up cleanly with the controls beside them.
