## v1.18.0 — 2026-07-10

New "Creation factions" glossary joins the built-in Creations glossary of specific creatures.

- **New "Creation factions" glossary** — a built-in read-only glossary of creature family names (Slime, Abyss Mage, Hilichurl, and more), complementing the existing Creations glossary of specific creatures.
- **Glossary generation** — the "Extract translations into glossary terms" option now sits directly under the "Send existing translations as context" languages it depends on, and generation results can be discarded from the result view to start over.
- **Runs dropdowns** — run pickers now widen to fit long run labels instead of clipping them.
