# Compare Tab

## Overview

The **Compare** tab is a focused, one-language-at-a-time workspace for reviewing and filling translations. It shows the **source**, an optional **reference** language, and the **target** language side by side — useful for translating against a language you already trust rather than against the source alone.

## Set up the view

* Choose the **Target** language to work on.
* Optionally pick a **Reference** language to show as an extra column and use as translation context.
* **Search** and filter: untranslated only, **LQA** issues, or **Needs review**.

## Work on translations

* Edit any target cell inline; **Undo** is offered after a save.
* **Re-translate** a single row on demand.
* **+ Context** attaches translator context to an entry (character, tone, situational notes) that modules receive on the next translation.

## Translate in bulk

Click **Translate…** to open the batch-translate dialog for the current view:

* Translate the **selected** entries or **all** entries in the current view.
* **Only fill untranslated** entries, or **re-translate** existing ones.
* **Use the reference language as context** when one is selected.
* Set **batch grouping** for the run, and optionally **disable translation memory** so every entry is freshly translated.

## Review helpers

Use **Flag all as needs review** or **Mark all as reviewed** to move the whole current view through your review workflow at once.
