# About NARN

**NARN** stands for **Not A Relevant Name**.

The name is deliberately a placeholder — the tool is what matters, not the
branding. NARN is an AI-assisted localization workspace: import your strings,
route them to the translation providers you choose, review and grade the
results, and keep a translation memory across projects.

## What it's built for

NARN is built for **Miliastra Wonderland** Craftspeople. It reads the CSV the
game exports — including the game's own non-standard quoting, which ordinary
spreadsheet importers mangle — and ships 12 read-only glossaries (332 terms in
14 languages) covering the game's characters, elements, reactions, stats,
nations, ranks and Miliastra's own vocabulary, so every provider renders those
terms the way the game does instead of inventing a new word each run.

None of that locks you in: any CSV of text will import, and every feature works
the same on it. Miliastra is simply the workflow NARN is designed around.

NARN is an independent, fan-made tool, not affiliated with or endorsed by
HoYoverse / COGNOSPHERE PTE. LTD. The bundled glossaries are unofficial,
fan-made terminology aids.

So when you see "NARN" in the title bar, the login page, or anywhere else: it's
**Not A Relevant Name**. Now you know.
