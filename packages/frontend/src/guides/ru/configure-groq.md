# Модуль Groq

## Обзор

Модуль **Groq** переводит через [Groq](https://groq.com) — быстрый инференс для открытых моделей, таких как Llama, Qwen и GPT-OSS, с бесплатным тарифом, который подходит для повседневной работы по переводу. Ему нужен API-ключ Groq, который хранится в хранилище учетных данных под ключом `GROQ_API_KEY`.

## Добавление ключа в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **Groq**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `GROQ_API_KEY`, вставьте свой ключ в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**.

Если позже карточка модуля показывает *Хранилище заблокировано*, нажмите **Разблокировать хранилище** перед переводом.

## Выбор модели

На вкладке **Конфигурация** проекта выберите модель из живого каталога Groq либо унаследуйте глобальное значение по умолчанию. `llama-3.3-70b-versatile` — надежный выбор по умолчанию для качества перевода; модели меньшего размера, такие как `llama-3.1-8b-instant`, жертвуют частью качества ради скорости. **Правила маршрутизации** на вкладке «Маршрутизация» решают, какой модуль обрабатывает каждый язык.

## Получение API-ключа Groq

1. Перейдите на [console.groq.com](https://console.groq.com).
2. Зарегистрируйтесь или войдите.
3. Откройте **API Keys** в меню консоли.
4. Создайте новый API-ключ и скопируйте его — он начинается с `gsk_`.
5. Вставьте его в значение `GROQ_API_KEY` в редакторе хранилища.

Бесплатный тариф Groq применяет дневные лимиты для каждой модели (здесь нет фиксированных цифр — актуальные лимиты уточняйте в своей консоли), и, согласно условиям Groq, данные API не используются для обучения моделей. После добавления ключа **NARN Freeway** автоматически подключает бесплатный план Groq при распределении работы по переводу между бесплатными квотами ваших подключенных поставщиков — без дополнительной настройки.
