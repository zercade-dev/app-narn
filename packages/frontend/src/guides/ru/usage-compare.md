# Вкладка «Сравнение»

## Обзор

Вкладка **Сравнение** — это сфокусированное рабочее пространство для проверки и заполнения переводов, по одному языку за раз. Она показывает рядом **исходный текст**, необязательный **справочный** язык и **целевой** язык — это удобно, когда вы переводите, ориентируясь на уже проверенный язык, а не только на исходный текст.

## Настройка представления

* Выберите **целевой** язык, с которым будете работать.
* При желании выберите **справочный** язык — он отобразится дополнительным столбцом и будет использоваться как контекст для перевода.
* **Поиск** и фильтры: только непереведенные, проблемы **LQA** или **На вычитку**.

## Работа с переводами

* Редактируйте любую целевую ячейку прямо в таблице; после сохранения предлагается **Отменить**.
* **Перевести заново** отдельную строку по запросу.
* **+ Контекст** добавляет к записи контекст для переводчика (персонаж, тональность, ситуативные заметки), который модули получат при следующем переводе.

## Массовый перевод

Нажмите **Перевести…**, чтобы открыть диалог пакетного перевода для текущего представления:

* Переведите **выбранные** записи или **все** записи в текущем представлении.
* **Заполнить только непереведенные** записи или **перевести заново** уже существующие.
* **Использовать справочный язык как контекст**, если он выбран.
* Задайте **группировку пакетов** для прогона и при необходимости **отключите память переводов**, чтобы каждая запись переводилась заново.

## Помощники проверки

Используйте **Отметить всё на вычитку** или **Отметить всё как вычитанное**, чтобы за раз провести все текущее представление через ваш рабочий процесс проверки.
