# Память переводов

## Обзор

**Память переводов** (TM) — это общее для всей рабочей области хранилище известных переводов. Когда исходный текст строки совпадает с уже сохраненным в памяти, сохраненный перевод используется автоматически вместо обращения к платному модулю — это экономит время и деньги и сохраняет единообразие одинакового текста между проектами. Откройте раздел **Память переводов** в боковой панели, чтобы просматривать и искать сохраненные сегменты.

> **Память переводов по умолчанию отключена** для каждого проекта. Пока она отключена, ничего из переведенного проектом не записывается в память, и ни один сохраненный перевод не применяется автоматически. Чтобы включить ее, откройте вкладку **Конфигурация** проекта и выберите политику повторного использования в разделе **Память переводов** (любое значение, кроме *Отключена*).

## Как переводы попадают в память

* **Утвердить в память** — на вкладке **Переводы** выберите переводы и утвердите их; они записываются как проверенные сегменты.
* Завершенные переводы также записываются, чтобы такой же исходный текст мог позже их повторно использовать.

## Политика повторного использования

Политика повторного использования (на вкладке **Конфигурация** проекта, раздел **Память переводов**) определяет, *будет ли* и *когда* сохраненный перевод повторно использован для идентичного исходного текста. По умолчанию установлено значение **Отключена** (TM выключена); другие варианты — например, **Строгая (полное совпадение контекста)**, при которой повторное использование происходит, только если совпадает и окружающий контекст, — включают ее. Ужесточение политики позволяет избежать повторного использования перевода, который был верным в одном месте, но не в другом.

## Управление повторным использованием для отдельного прогона

Когда вы запускаете перевод из диалога *Перевести…* на вкладке **Сравнение**, уведомление сообщает, сколько записей будет заполнено из памяти, и вы можете **отключить память переводов для этого прогона**, чтобы заставить каждую запись перевестись заново, — это полезно, когда вы хотите, чтобы модель заново рассмотрела ранее запомненный текст.
