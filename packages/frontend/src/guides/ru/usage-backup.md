# Вкладка «Резервные копии»

## Обзор

Вкладка **Резервные копии** упаковывает проект — его конфигурацию, записи и глоссарий — в проверяемый архив `.zip`. Для каждого файла рассчитывается контрольная сумма, и при восстановлении контрольные суммы проверяются до записи чего-либо обратно.

## Создание резервной копии

1. Выберите проект.
2. Откройте вкладку **Резервные копии**.
3. Нажмите **Создать резервную копию**.
4. Новый архив появится в разделе **Сохраненные резервные копии**, откуда его можно **скачать**.

## Автоматические резервные копии

Приложение также самостоятельно создает страховочные снимки, которые отображаются рядом с ручными резервными копиями:

* **Перед импортом CSV** — точка восстановления прямо перед импортом.
* **Перед повторным переводом** — точка восстановления прямо перед тем, как записи будут перезаписаны.

В глобальной конфигурации задается параметр **Макс. резервных копий на проект** (по умолчанию 10); более старые резервные копии сверх этого числа удаляются.

## Восстановление

1. В разделе **Восстановление из резервной копии** выберите файл `.zip` (или одну из сохраненных резервных копий).
2. Приложение проверяет контрольные суммы и показывает предпросмотр (проект, файлы, время создания).
3. Подтвердите. Восстановление перезаписывает текущую конфигурацию, записи и глоссарий проекта — это действие нельзя отменить, поэтому при сомнениях сначала создайте свежую резервную копию.

## Удаление

Используйте **Удалить** на любой сохраненной резервной копии, чтобы навсегда удалить этот архив с сервера.
