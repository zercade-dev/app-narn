# Вкладка «Переводы»

## Обзор

Вкладка **Переводы** — это основная таблица записей: каждая исходная запись со столбцом для каждого целевого языка. Здесь вы читаете, редактируете, фильтруете, категоризируете записи и **выбираете** их для перевода. Таблица разбита на страницы (25/50/100/200 строк на странице).

## Редактирование

Нажмите на любую ячейку с переводом, чтобы отредактировать ее прямо в таблице; изменение сохраняется после подтверждения. Столбцы **исходного текста** и **СТАТУС** показывают исходный текст и происхождение каждой записи вместе с ее категорией, глоссарием и статусом перевода.

## Фильтрация

Используйте панель инструментов, чтобы сузить таблицу:

* **Поиск** по исходному и переведенному тексту.
* Фильтры по **статусу**: только непереведенные, только с ошибками LQA, только переполнение, на вычитку, совпадает с исходным текстом, несовпадение подстановок.
* Фильтр по **языку**, метке **источника** или **категории**, а также показ или скрытие столбцов.

## Выбор и перевод

Выбирайте строки флажками (или выберите весь отфильтрованный набор). С выделением можно:

* Запустить **Перевести выбранное** из панели выделения (правила маршрутизации выберут модуль для каждого языка).
* **Добавить** или **убрать категорию** массово.
* **Утвердить в память** — зафиксировать текущие переводы в памяти переводов как проверенные.

## Категории и глоссарии для отдельной записи

Правый клик по строке (или ее действия) открывает **изменение категорий** или выбор, какие **глоссарии** включены для этой записи при переводе. Категории также можно сгенерировать массово на вкладке **Категория**.
