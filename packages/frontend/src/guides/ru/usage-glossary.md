# Вкладка «Глоссарий»

## Обзор

Вкладка **Глоссарий** сохраняет терминологию единообразной. В проекте может быть несколько глоссариев; каждый — это список исходных терминов с переводом на каждый целевой язык. Глоссарии автоматически сопоставляются с записями, и найденные термины передаются модели при переводе.

## Глоссарии и термины

* Создайте глоссарий кнопкой **Новый глоссарий**; позже его можно переименовать или удалить.
* **Включайте** или **отключайте** глоссарий — отключенный глоссарий игнорируется при импорте и переводе.
* Добавляйте термины с **источником**, **переводом на каждый язык** и необязательными **заметками**.
* Отмечайте термин как **константу**, если его нельзя переводить ни при каких условиях (названия брендов, коды). Термины-константы маскируются при переводе, чтобы проходить через модуль без изменений.

Некоторые глоссарии **доступны только для чтения** (управляются глобально) и добавляют термины, но не редактируются здесь.

## Импорт и экспорт

Импортируйте термины из **CSV** или **TBX** — предпросмотр покажет, сколько терминов будет добавлено, обновлено или окажется в конфликте, прежде чем вы примените изменения. Экспортируйте глоссарий обратно в **CSV** или **TBX**.

## Генерация с помощью ИИ

* **Сгенерировать глоссарии** сканирует исходный текст и предлагает глоссарии из повторяющихся имен и специальных терминов. Процесс выполняется в фоне — отслеживайте его на вкладке **Активность** и просмотрите предложения перед созданием. Существующие глоссарии можно передать как «уже известные», чтобы модель их не повторяла.
* **Сгенерировать переводы** заполняет недостающие переводы для терминов, у которых их еще нет.

## DeepL

Если вы переводите с помощью DeepL, используйте **Отправить в DeepL**, чтобы загрузить термины глоссария. После редактирования отправленного глоссария вкладка показывает *Нужна повторная отправка* — отправьте его снова, чтобы обновить DeepL.

## Управление по отдельным записям

На вкладке «Переводы» можно выбрать, какие глоссарии **включены** для отдельной записи.
