# ИИ-рецензия

## Обзор

Помимо автоматических проверок LQA, приложение может использовать модель ИИ для рецензирования вашего контента. Есть две вкладки ИИ-рецензии и очередь ручной вычитки. Для любой ИИ-рецензии нужен включенный модуль LLM в **Глобальной конфигурации** и разблокированное хранилище учетных данных.

## ИИ-рецензия переводов

На вкладке **ИИ-рецензия переводов** ИИ-рецензент оценивает завершенные переводы по **точности, беглости, терминологии и тональности**.

* Нажмите **Рецензировать последний прогон**, чтобы оценить последний завершенный прогон перевода (или запустите рецензию из конкретного прогона на вкладке **Активность**).
* Пройдите по отмеченным результатам; каждый вердикт показывает исходный текст, перевод, **оценку** и часто **предложение**.
* **Применить** предложение, чтобы заменить перевод, или **Применить все предложения**, чтобы применить их за один раз. Если предложение приведет к потере тегов, подстановок или переносов строк, появится предупреждение.

## ИИ-рецензия исходного текста

Вкладка **ИИ-рецензия исходного текста** проверяет **сам исходный текст** — она только сообщает результаты и никогда не меняет переводы.

1. Выберите проверки для запуска: **опечатки**, **грамматика**, **терминология**, **ясность** и **небезопасное** содержимое.
2. Выберите **модуль** и **модель**, а также, при желании, **язык ответа** для замечаний.
3. Нажмите **Запустить рецензию**. Она выполняется в фоне — следите за прогрессом на вкладке **Активность**.
4. Просмотрите каждое замечание и нажмите **Принять** или **Игнорировать**; предлагаемую переработку исходного текста можно скопировать.

## Ручная вычитка

Вкладка **Ручная вычитка** — это очередь ручной проверки. Здесь появляются переводы, отмеченные **На вычитку** (или **Отложенные**); их можно **Утвердить**, **Изменить**, **Отложить**, **Перевести заново** или запросить **обратный перевод** на исходный язык как справочный материал. Сочетания клавиш ускоряют работу: `↑`/`↓` — перемещение, `a` — утвердить, `e` — изменить.
