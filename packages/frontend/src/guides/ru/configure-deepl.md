# Модуль DeepL

## Обзор

Модуль **DeepL** обеспечивает профессиональный нейронный машинный перевод. В отличие от модулей на базе LLM это классический MT, и он умеет отправлять глоссарии проекта в DeepL для единообразной терминологии. Его ключ хранится в хранилище учетных данных под `DEEPL_API_KEY`.

## Добавление ключа в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **DeepL**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `DEEPL_API_KEY`, вставьте свой ключ аутентификации в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**.

DeepL не поддерживает именованные экземпляры — существует только один модуль DeepL.

## Использование глоссариев

DeepL умеет применять глоссарий при переводе. Создайте термины на вкладке **Глоссарий**, затем нажмите **Отправить в DeepL**, чтобы загрузить их. Если глоссарий изменился после отправки, вкладка показывает *Нужна повторная отправка* — отправьте его снова, чтобы обновить DeepL.

## Получение API-ключа DeepL

1. Перейдите на [deepl.com/account](https://www.deepl.com/account).
2. Зарегистрируйте бесплатную или платную учетную запись API.
3. Откройте **Account Settings** и найдите раздел **API Key**.
4. Скопируйте свой ключ аутентификации.
5. Вставьте его в значение `DEEPL_API_KEY` в редакторе хранилища.
