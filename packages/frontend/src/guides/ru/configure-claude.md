# Модуль Anthropic (Claude)

## Обзор

Модуль **Claude** переводит с помощью моделей Claude от Anthropic. Ему нужен API-ключ Anthropic, который хранится в хранилище учетных данных под ключом `ANTHROPIC_API_KEY`.

## Добавление ключа в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **Anthropic (Claude)**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `ANTHROPIC_API_KEY`, вставьте свой ключ в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**. При сохранении хранилище шифруется заново.

Если позже карточка модуля показывает *Хранилище заблокировано*, нажмите **Разблокировать хранилище** перед переводом.

## Выбор модели

На вкладке **Конфигурация** проекта выберите модель Claude (и, при желании, уровень рассуждений) или оставьте наследование глобального значения по умолчанию. **Правила маршрутизации** на вкладке «Маршрутизация» решают, какой модуль обрабатывает каждый язык.

## Получение API-ключа Anthropic

1. Перейдите на [console.anthropic.com](https://console.anthropic.com).
2. Зарегистрируйтесь или войдите.
3. Откройте раздел **API keys**.
4. Нажмите **Create Key** и скопируйте ключ.
5. Вставьте его в значение `ANTHROPIC_API_KEY` в редакторе хранилища.
