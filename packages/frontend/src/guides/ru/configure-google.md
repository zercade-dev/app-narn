# Модуль Google AI (Gemini)

## Обзор

Модуль **Google AI** переводит с помощью моделей Gemini от Google. Ему нужен API-ключ Google AI Studio, который хранится в хранилище учетных данных под ключом `GOOGLE_API_KEY`.

## Добавление ключа в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **Google AI (Gemini)**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `GOOGLE_API_KEY`, вставьте свой ключ в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**.

Если позже карточка модуля показывает *Хранилище заблокировано*, нажмите **Разблокировать хранилище** перед переводом.

## Выбор модели

На вкладке **Конфигурация** проекта выберите модель Gemini (и, при желании, уровень рассуждений) или унаследуйте глобальное значение по умолчанию. **Правила маршрутизации** на вкладке «Маршрутизация» решают, какой модуль обрабатывает каждый язык. Модели с «размышлением» сообщают большое число токенов относительно количества символов, поэтому оценка стоимости может выглядеть завышенной.

## Получение API-ключа Google

1. Перейдите на [ai.google.dev](https://ai.google.dev) и нажмите **Get API key**, либо перейдите напрямую на [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).
2. Нажмите **Create API key** и выберите свой проект.
3. Скопируйте сгенерированный ключ.
4. Вставьте его в значение `GOOGLE_API_KEY` в редакторе хранилища.
