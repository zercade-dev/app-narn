# Модуль GitHub Copilot

## Обзор

Модуль **Copilot** переводит через GitHub Copilot. Он проходит аутентификацию с помощью токена GitHub от учетной записи с **активной подпиской Copilot**, который хранится в хранилище учетных данных под ключом `GITHUB_TOKEN`.

## Добавление токена в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **GitHub Copilot**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `GITHUB_TOKEN`, вставьте свой токен в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**.

Если список моделей показывает *Нет доступных моделей*, значит токен отсутствует, недействителен или хранилище заблокировано — разблокируйте хранилище или проверьте токен GitHub, затем откройте карточку заново.

## Получение токена GitHub

Используйте **гранулярный** личный токен доступа (fine-grained), чтобы он предоставлял доступ только к Copilot и ничего больше.

1. Перейдите на [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens).
2. Нажмите **Generate new token** (гранулярные токены выбраны по умолчанию).
3. Дайте токену имя (например, «Translator-Copilot») и укажите **Expiration**.
4. В разделе **Permissions → Account permissions** найдите **Copilot Requests** и установите значение **Read-only**. Другие разрешения не нужны.
5. Нажмите **Generate token** и сразу же скопируйте токен — GitHub показывает его только один раз.
6. Вставьте его в значение `GITHUB_TOKEN` в редакторе хранилища.

У учетной записи, стоящей за токеном, должна быть активная подписка Copilot, чтобы переводы выполнялись успешно.
