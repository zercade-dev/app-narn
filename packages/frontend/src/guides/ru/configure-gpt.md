# Модуль OpenAI (GPT)

## Обзор

Модуль **GPT** переводит с помощью моделей OpenAI. Ему нужен API-ключ OpenAI, который хранится в хранилище учетных данных под ключом `OPENAI_API_KEY`.

## Добавление ключа в хранилище учетных данных

Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных**, а не в открытой конфигурации. Хранилище разблокируется паролем один раз за сеанс.

1. Откройте **Глобальную конфигурацию** в боковой панели.
2. Если хранилище еще не настроено, создайте его: выберите пароль хранилища (вы будете вводить его в каждом сеансе) и разблокируйте хранилище.
3. В разделе **Включить модуль** выберите **OpenAI (GPT)**. Если нужный ключ отсутствует, редактор хранилища автоматически откроется на нужном ключе — в противном случае нажмите **Управление хранилищем учетных данных**.
4. В редакторе хранилища добавьте учетные данные: выберите ключ `OPENAI_API_KEY`, вставьте свой ключ в качестве значения, введите **пароль хранилища** и нажмите **Сохранить**.

Если позже карточка модуля показывает *Хранилище заблокировано*, нажмите **Разблокировать хранилище** перед переводом.

## Выбор модели

На вкладке **Конфигурация** проекта выберите модель GPT (и, при желании, уровень рассуждений) или унаследуйте глобальное значение по умолчанию. **Правила маршрутизации** на вкладке «Маршрутизация» решают, какой модуль обрабатывает каждый язык.

## Получение API-ключа OpenAI

1. Перейдите на [platform.openai.com/account/api-keys](https://platform.openai.com/account/api-keys).
2. Зарегистрируйтесь или войдите.
3. Нажмите **Create new secret key**.
4. Скопируйте ключ (он показывается только один раз).
5. Вставьте его в значение `OPENAI_API_KEY` в редакторе хранилища.
