# Быстрая настройка

## Обзор

Полный путь для нового проекта: включите поставщиков, импортируйте свои записи, настройте глоссарии и маршрутизацию, переведите и проверьте результат. Шаги, отмеченные *(Optional)*, повышают качество, но не обязательны для первого перевода — на первом проходе их можно пропустить и вернуться к ним позже.

## 1. Включите поставщиков и сохраните учетные данные

1. Откройте **Глобальную конфигурацию** и **включите модуль** для каждого нужного поставщика (Anthropic, OpenAI, DeepL и так далее). У модуля может быть несколько **именованных экземпляров** — это полезно для двух конфигураций одного поставщика с разными ключами или значениями по умолчанию.
2. Учетные данные поставщиков хранятся в зашифрованном **хранилище учетных данных** — настройте его при первом использовании и разблокируйте один раз за сеанс. О том, как это работает, см. руководство *Хранилище учетных данных*.
3. Выберите **модель** (и, при желании, **уровень рассуждений**) для каждого модуля или экземпляра. Более дешевые модели переводят хуже, так что придется методом проб и ошибок найти свой оптимум. Следите за **уровнем рассуждений** — на моделях с «размышлением» он может быстро умножить расходы.

## 2. Создайте проект и импортируйте записи

Создайте проект, задайте его **исходный язык**, затем используйте **Импорт CSV** на вкладке **Данные**, чтобы загрузить исходные записи (и любые переводы, которые уже есть в файле).

## 3. *(Optional)* Сначала проверьте свой исходный текст

Запустите **ИИ-рецензию исходного текста** для исходного языка перед переводом — исправление опечаток и неясных формулировок здесь принесет пользу каждому переводу, сделанному впоследствии. Если исправление меняет запись, у которой уже были переводы, старые переводы попадают на вкладку **Сироты** — **перепривяжите** их, при необходимости с повторным переводом.

## 4. *(Optional)* Включите глоссарии

На вкладке **Глоссарий** включите глоссарии, которые подходят вашему проекту. Автоприменение сопоставляет термины как **целые слова, без учета регистра** — словоформы (множественное число, спряжения) не распознаются. Переводите с помощью **DeepL**? Отправьте в него глоссарии кнопкой **Отправить в DeepL** (в правом верхнем углу) и отправляйте их заново после редактирования.

## 5. Настройте маршрутизацию

Откройте вкладку **Маршрутизация** и выберите своего поставщика в селекторе, на котором она открывается, — это отправит ему каждую запись проекта, а больше однопоставщиковой настройке ничего и не нужно. Нужны разные поставщики для разных языков, категорий или длины записи? Переключитесь в режим **Расширенный** и добавляйте **правила маршрутизации** там. В любом случае ваш выбор сохраняется автоматически. Этот шаг обязателен: если для записи не находится подходящее правило, ее перевод завершается ошибкой «нет маршрута».

## 6. *(Optional)* Пополните глоссарии своим контентом

Развивайте глоссарии перед массовым переводом: добавляйте термины вручную, запустите **Сгенерировать глоссарии** по всему исходному тексту или, точечнее, выберите хорошие записи-кандидаты на вкладке **Переводы** и используйте **Сгенерировать глоссарий из выбранного** (с включением существующих переводов). Используйте здесь мощную модель — качество глоссария сказывается на всем, что будет переведено впоследствии.

## 7. *(Optional)* Сначала отладьте качество на вкладке «Сравнение»

Перед полным прогоном перевода используйте вкладку **Сравнение**, чтобы довести до нужного качества один язык, который вы можете лично оценить:

- Дорабатывайте **контекст** каждой записи (персонаж, тональность, заметки) и глоссарии, пока перевод не станет звучать правильно. Контекст хранится для каждой записи, а не для каждого языка, поэтому проделанная работа автоматически переносится на все остальные языки.
- Поскольку вы работаете запись за записью, здесь подойдет дешевая или бесплатная модель — например, бесплатный ключ Gemini (см. руководство *Google AI (Gemini)*), добавленный как отдельный **экземпляр модуля** с маршрутизацией, временно направленной на него. У бесплатного уровня есть суточный лимит, поэтому предпочитайте сгруппированные запросы.
- Довольны результатом? Переведите весь пакет с теми же настройками, чтобы убедиться, что качество держится и в массовом режиме.

## 8. Переведите

Есть два способа запустить настоящий перевод:

- **Переводы** — выберите записи и нажмите **Перевести выбранное**, чтобы охватить сразу все целевые языки.
- **Сравнение** — по одному языку за раз, при желании с уже проверенным языком в качестве **справочного** контекста.

Для целого проекта обычно лучше работает вариант «по одному языку за раз с проверенным справочным языком»: последующая ИИ-рецензия остается сосредоточенной на одном языке. Следите за прогрессом на вкладке **Активность**.

По умолчанию пакетирование автоматическое; для небольшого проекта с большим числом коротких записей свой размер пакета **0** (весь язык одним запросом) может сработать лучше с мощной моделью.

## 9. Проверьте прогон

Выберите один из вариантов:

- Запустите **ИИ-рецензию** для завершенного прогона на вкладке **Активность**.
- Проверьте вручную в разделе **Ручная вычитка** или на вкладке **Сравнение**.
- Утвердите все как есть и проверьте позже.
