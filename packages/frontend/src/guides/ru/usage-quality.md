# Вкладка «Качество»

## Обзор

Вкладка **Качество** — это панель, объединяющая результаты LQA (Linguistic Quality Assurance, лингвистическая проверка качества), которые появляются при каждом переводе записей. Она показывает общую долю прохождения и места, где скапливаются проблемы, чтобы вы могли быстро находить проблемные зоны. Панель заполняется по мере перевода — если она пуста, сначала выполните перевод.

## Что она показывает

* **Общая доля прохождения** по всем результатам LQA и охваченным ими записям.
* **Доля прохождения по языкам** — качество по каждому целевому языку.
* **Проблемы по источникам** — количество проблем по типам, сгруппированное по меткам источника.
* **Качество по модулям** — доля прохождения и проблемы, сгруппированные по модулю, выполнившему каждый перевод.

## Переход к деталям

Нажмите на любую ячейку, чтобы перейти к соответствующим записям — панель отфильтрует таблицу **Переводы** до затронутых записей, чтобы вы могли их исправить.

## Откуда берутся проверки

Каждый перевод проходит через контроль качества LQA, который выполняет проверки, включенные вами на панели *Проверки LQA* вкладки **Конфигурация** (идентичность встроенных тегов, ограничение длины, переполнение по длине, соблюдение глоссария, запрещенные термины, утверждения регулярных выражений и другие). **Блокирующие** проверки не дают пройти контроль качества и могут вызвать один автоматический повтор; **предупреждающие** проверки сообщаются здесь, но не блокируют. Настроить, какие проверки выполняются, и их серьезность можно в разделе «Конфигурация».
