# Вкладка «Конфигурация»

## Обзор

Вкладка **Конфигурация** хранит политику перевода выбранного проекта: выбор модели для каждого модуля, повторное использование памяти переводов, группировку пакетов, проверки качества (LQA) и управление проектом. Ее **языки** и **импорт/экспорт CSV** теперь находятся на отдельной вкладке **Данные**. Учетные данные поставщиков здесь не задаются — они хранятся в **хранилище учетных данных** (см. руководства *Настройка модуля* и **Глобальную конфигурацию**).

## Языки (на вкладке «Данные»)

Задайте **исходный язык** и **целевые языки** для перевода на вкладке **Данные**. Активный набор целевых языков определяет все остальные вкладки — от него зависят столбцы записей, правила маршрутизации и проверки качества.

## Импорт и экспорт CSV (на вкладке «Данные»)

Импорт и экспорт CSV также находятся на вкладке **Данные**:

* **Импорт CSV** загружает исходные записи и любые уже имеющиеся переводы. Перед каждым импортом автоматически создается страховочный снимок, поэтому откатиться назад можно на вкладке **Резервные копии**.
* Строки, которые не удается разобрать корректно (кавычка сразу за которой следует запятая), отбрасываются и сообщаются, а не записываются как данные со сдвинутыми столбцами.
* **Экспорт CSV** скачивает проект; можно выбрать языки и включить ли столбец контекста для переводчика.

### Файлы клиентского скрипта

CSV со столбцом **Text Mapping ID** — это файл клиентского скрипта. Он импортируется в отдельную коллекцию, **Текст клиентского скрипта**, отдельно от **Основного текста**; панель импорта показывает, какая коллекция определена.

* Каждая клиентская строка определяется по своему Text Mapping ID, поэтому один и тот же английский текст может быть в обеих коллекциях и в нескольких клиентских строках, и они не объединяются.
* Импорт клиентского файла никогда не меняет основной текст, а импорт основного файла никогда не меняет клиентский текст.
* Когда английский текст существующего ключа меняется, в любом режиме импорта старая строка переходит на вкладку **Сироты**, а новая сохраняет переводы из файла; без перевода остаются только её пустые ячейки. Чтобы перенести переводы, используйте **Перепривязать**: сначала предлагается строка с тем же ключом, а режим перезаписи определяет, сохранятся заполненные ячейки или будут заменены.
* Когда в проекте есть клиентские строки, **Экспорт CSV** позволяет выбрать коллекцию для загрузки, а клиентский экспорт сохраняет столбец Text Mapping ID.
* Экспорт записывает текст в сохранённом виде, не добавляя апостроф перед ячейками, начинающимися с = + - или @. Включайте **Защитить для электронных таблиц** только для файлов, которые откроете в электронной таблице: редактор Miliastra сохраняет этот апостроф как текст. Запуски перевода пропускают строки со значением Need translation? равным FALSE.

## Модули и модели

Включайте поставщиков один раз в **Глобальной конфигурации**. Здесь, на вкладке «Конфигурация», для каждого проекта выбираются **модель** и **уровень рассуждений** для каждого включенного модуля — или оставьте значение *Наследовать из глобальной конфигурации*. Какой модуль в итоге будет применен к конкретной записи, решают **правила маршрутизации** (см. руководство *Маршрутизация*).

## Проверки LQA

Панель **Проверки LQA** настраивает контроль качества, выполняемый для каждого перевода: включайте отдельные проверки (идентичность встроенных тегов, ограничение длины, переполнение по длине, соблюдение глоссария, запрещенные термины, утверждения регулярных выражений и другие) и задавайте для каждой значение **Блокировка** или **Предупреждение**. Блокирующие проблемы не дают пройти контроль качества и могут вызвать один автоматический повтор; предупреждения только фиксируются.

## Группировка пакетов

**Группировка пакетов** удерживает связанные записи (по категории и/или глоссарию) в одном запросе, чтобы модель видела их в контексте. Можно задать значение по умолчанию для проекта и переопределить его для отдельного прогона.

## Управление проектом

**Опасная зона** позволяет **дублировать** проект (конфигурацию и записи, но никогда секреты) или **удалить** его безвозвратно.
