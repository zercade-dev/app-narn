# 活動分頁

## 總覽

**活動** 分頁是背景工作的控制中心。每個長時間執行的工作都會顯示在這裡：**翻譯**執行、**AI 審閱**（譯文與原文）、**術語表生成**，以及**類別生成**。執行會依專案排入佇列並依序處理，因此您可以一次排好幾個，然後看著它們逐一完成。

## 讀懂一次執行

每次執行都會顯示其**類型**、**狀態**（已排入佇列、執行中、已暫停、已完成、已失敗，或已取消）、進度，以及估計**成本**。成本是模組回報的估計值，依各模型每百萬 token 的價格推算，因此思考模型相對於字元數，可能顯示很大的 token 總量。使用**顯示詳情**可以確切查看某次執行翻譯了什麼、有哪些重試，以及字元／token 使用量。您可以複製執行的 ID 以供參考。

## 管理佇列

* **暫停**／**繼續**一次執行，或**立即開始**讓某個排隊中的執行提前處理。
* **上移**／**下移**來調整佇列順序。
* **取消**排隊中或進行中的執行。

## 復原與審閱

* 如果有些字串失敗了，**重試失敗項目**只會重新執行那些失敗的部分。
* 對於已完成的翻譯執行，可以直接從該次執行開始**AI 審閱**——選擇模組與模型（預設會使用翻譯時所用的模組與模型），然後在**譯文 AI 審閱**分頁中查看評分結果。
