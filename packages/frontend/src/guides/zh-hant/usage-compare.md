# 對照分頁

## 總覽

**對照** 分頁是一個專注於單一語言的工作區，用來審閱並補齊譯文。它會並排顯示**原文**、選填的**參考**語言，以及**目標**語言——適合用來對照一個您已經信任的語言來翻譯，而不是只對照原文。

## 設定檢視畫面

* 選擇要處理的**目標**語言。
* 可以選擇一個**參考**語言，顯示為額外欄位並作為翻譯情境使用。
* **搜尋**與篩選：只顯示未翻譯、有 **LQA** 問題，或**待審校**的條目。

## 處理譯文

* 直接在任何目標儲存格中編輯；儲存後會提供**復原**選項。
* 針對單一資料列隨時**重新翻譯**。
* **+ 情境** 可以為條目附加譯者情境（角色、語氣、情境備註），模組會在下一次翻譯時取得這些資訊。

## 批次翻譯

按一下**翻譯…**開啟目前檢視畫面的批次翻譯對話框：

* 翻譯目前檢視畫面中**選取的**條目，或**全部**條目。
* **只填入未翻譯**的條目，或**重新翻譯**既有的條目。
* 選定參考語言時，可以**使用參考語言作為情境**。
* 為這次執行設定**批次分組**，並可選擇**停用翻譯記憶庫**，讓每個條目都重新翻譯。

## 審閱輔助工具

使用**全部標記為待審校**或**全部標記為已審校**，一次將目前檢視畫面中的所有內容推進審閱流程。
