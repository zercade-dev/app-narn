# 孤立條目分頁

## 總覽

**孤立條目** 分頁列出最近一次匯入的 CSV 中已不存在的條目。它們通常會在重新匯入後出現——某一列被刪除、重新命名，或原文內容被改變——舊的譯文會保留在這裡，讓您不會失去先前的成果。

## 可以做的事

* **刪除**孤立條目，會永久移除該筆記錄及其譯文（此動作無法復原）。
* **重新連結**孤立條目，把它的譯文移到另一個條目上。以原文搜尋目標條目；目標條目上既有的譯文會保留，只有它空白的語言會被填入。
* 選取多筆孤立條目，批次**刪除所選**，或**重新整理**清單。

## 工作流程

1. 從 **資料** 分頁重新匯入您的原文 CSV。
2. 開啟**孤立條目**，檢視有哪些條目被移出。
3. 對於 ID 或原文變更了、但譯文仍然有效的條目，執行**重新連結**。
4. 對於確實不再存在的條目，執行**刪除**。

當清單是空的，代表所有匯入的條目都與目前的專案相符——沒有任何孤立條目。
