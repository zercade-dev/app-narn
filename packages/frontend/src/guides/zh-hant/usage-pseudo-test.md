# 偽翻譯測試

## 總覽

**偽翻譯測試**不是真正的語言。它是一種免費、離線的 QA 語言，會把您的原文改寫成刻意弄亂的版本，讓您可以把它載入遊戲中，在真正的翻譯出現之前，先看看哪些字串會讓介面出問題。

它完全免費，不需要 API 金鑰，也絕不會把任何內容傳送給供應商。

## 它會產生什麼

`Save changes` 會變成類似 `⟦Şàvé çhàñgéş~~~~⟧` 的內容。同時發生了三件事，各自暴露出不同類型的問題：

* **重音字母。** 每個字母都會換成加上重音符號、外觀相似的字母。如果您的遊戲中還有純英文字顯示出來，代表那段文字從未被納入字串表——它是寫死在程式裡的，任何翻譯人員都永遠碰不到它。
* **補足長度。** 文字會用 `~` 字元拉長到大約原長度的 1.4 倍，模擬像德文這類偏長的語言。按鈕文字溢出、換行不佳，或版面被撐開等情況會立刻顯現出來。
* **括號。** 結果會被包在 `⟦…⟧` 之中。如果畫面上少了任一邊的括號，就代表那個字串被截斷了。

您文字中的佔位符與內嵌標記會原封不動地通過，所以如果其中有任何一個被弄亂了，那是值得回報的錯誤，而不是版面問題。

## 使用方式

1. 在**資料**分頁中，於「目標語言」底下勾選**偽翻譯測試**並儲存。
2. 照常執行翻譯。偽翻譯測試的條目一律由內建的偽翻譯產生器處理——不需要啟用任何東西，不需要撰寫分派規則，也不需要任何費用。您的付費供應商絕不會看到這些字串。
3. 您真正的譯文是安全的：偽翻譯測試文字儲存在自己的欄位中，絕不會覆寫任何其他語言。

## 把它載入您的遊戲

在匯出卡片中，把**將偽翻譯文字匯出為**設定成一個您目前沒有在使用的語言——例如德文——然後下載檔案，並在遊戲中選擇該語言載入。所選語言的欄位只會在這一次下載中填入偽翻譯測試文字；沒有任何已儲存的內容會改變，下次匯出時真正的譯文仍然都在。

測試完畢後，請把替代設定改回**不替換**再匯出一次。一般的匯出結果絕不會包含偽翻譯測試欄——偽翻譯文字只會透過上述替代設定進入您的遊戲——所以讓偽翻譯測試保持開啟，並不會影響您實際發行的檔案。

## 使用時機

建議在委託任何翻譯之前，先執行一次偽翻譯測試。它找出的每一個版面問題，都是您只需要修一次的問題，而不是等十五種語言都到齊之後再修十五次。
