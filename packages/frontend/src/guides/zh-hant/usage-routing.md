# 分派分頁

## 總覽

**分派** 分頁決定哪個模組與模型會處理每個條目。它一開始會顯示單一供應商選擇器：選好供應商後，專案中的每個條目都會送到它那裡。大多數專案只需要這樣就夠了。

需要不只一個目的地嗎？把分頁切換到 **進階**，就會出現完整的規則建立工具，讓分派可以依目標語言、類別或條目長度而有所不同，並且可以保留多組具名的規則群組。分頁會記住您上次使用的是哪一種模式。如果某個專案的分派設定比單一供應商更複雜，無論您選了哪種模式，畫面都一定會顯示規則建立工具——既有的設定永遠不會被隱藏。

不論哪種方式，這個分頁只決定條目**如何**被分派。翻譯要從 **譯文** 或 **對照** 分頁開始執行。

## 分派規則

規則存在於 **進階** 檢視中。它們依優先順序評估；第一條與條目相符的規則勝出。每條規則可以比對：

* **來源**——匯入條目的來源標籤。
* **條目長度上限**——只套用於字數在此上限以內的條目。
* **目標語言** 與 **類別**。

對於相符的條目，規則會設定**模組**（以及選填的**模型**與**推理強度**覆寫），還有選填的提示內容（角色、語氣、性別、備註）。用 **新增規則** 新增規則；您做的每項變更都會自動儲存，因此不需要記住任何 **儲存** 按鈕。您可以保留多組具名的**規則群組**，並在其間切換（有執行進行中時，切換會被鎖定）。

## 批次分組

分派分頁也有一個 **批次分組** 控制項——與設定分頁上顯示的是同一個專案預設值，並搭配對應的 **忽略批次大小上限** 切換開關。它會在翻譯、評分與原文審閱的執行過程中，把相關的條目保留在同一個供應商請求裡。

## 開始翻譯

1. 在 **譯文** 或 **對照** 分頁選取條目。
2. 從那裡開啟 **翻譯…** 對話框——其中提供重新翻譯、記憶庫與每次執行的分組選項，然後開始執行。
3. 在 **活動** 分頁觀察進度、重試與失敗情況。
