# 設定分頁

## 總覽

**設定** 分頁保存所選專案的翻譯政策：各模組的模型選擇、翻譯記憶庫的重用方式、批次分組、品質（LQA）檢查，以及專案管理。它的**語言**與 **CSV 匯入／匯出**現在改由獨立的 **資料** 分頁提供。供應商憑證不在這裡設定——它們存放在**憑證保險庫**中（參見各「設定模組」指南與「全域設定」）。

## 語言（在資料分頁）

在 **資料** 分頁設定**原文語言**與要翻譯成的**目標語言**。目前使用中的目標語言集會影響其他每個分頁——條目欄位、分派規則與品質檢查都會隨之調整。

## CSV 匯入與匯出（在資料分頁）

CSV 匯入與匯出也在 **資料** 分頁：

* **CSV 匯入** 會載入原文條目與任何既有譯文。每次匯入前都會自動建立安全快照，之後可以在 **備份** 分頁還原。
* 無法乾淨解析的資料列（引號後面緊接著逗號）會被捨棄並回報，而不會寫成欄位錯位的資料。
* **CSV 匯出** 會下載整個專案；您可以選擇語言，以及是否包含譯者情境欄。

### 用戶端指令碼檔案

含有 **Text Mapping ID** 欄的 CSV 是用戶端指令碼檔案。它會匯入自己的集合**用戶端指令碼文字**，與**主要文字**分開存放；匯入面板會顯示偵測到的是哪一種。

* 每個用戶端字串都以其 Text Mapping ID 識別，因此相同的英文可以出現在兩個集合及多個用戶端列中，而不會被合併。
* 匯入用戶端檔案絕不會變更主要文字，匯入主要檔案也絕不會變更用戶端文字。
* 當既有鍵的英文變更時，無論使用哪種匯入模式，舊列都會移至**孤立條目**分頁，新列則保留檔案中的譯文；只有其空白儲存格才處於未翻譯狀態。使用**重新連結**可轉移譯文：系統會優先建議鍵相同的列，並由覆寫模式決定保留或取代已填寫的儲存格。
* 專案含有用戶端字串後，可在 **CSV 匯出** 時選擇要下載的集合，用戶端匯出會保留 Text Mapping ID 欄。

## 模組與模型

在 **全域設定** 中一次啟用供應商。在這裡的設定分頁中，您可以為每個已啟用的模組，依專案分別選擇**模型**與**推理強度**——或保持**繼承自全域設定**。實際上哪個模組會處理某個條目，是由**分派規則**決定的（參見「分派」指南）。

## LQA 檢查

**LQA 檢查**面板可以設定每次翻譯都會執行的品質把關：切換個別檢查項目（內嵌標記一致性、長度上限、溢出、術語表遵循、禁用術語、正規式斷言等等），並將每項設為**阻斷**或**警告**。阻斷性的問題會讓品質把關失敗，並可能觸發一次自動重試；警告只會被回報。

## 批次分組

**批次分組**會把相關的條目（依類別及／或術語表）保留在同一個請求中，讓模型能在情境中一起看到它們。您可以設定專案的預設值，並針對每次執行覆寫它。

## 專案管理

**危險區域**可以讓您**複製**專案（設定與條目，絕不含機密資料）或永久**刪除**它。
