# 翻譯記憶庫

## 總覽

**翻譯記憶庫**（TM）是一個工作區層級、儲存已知譯文的資料庫。當某個字串的原文與記憶庫中已有的內容相符時，系統會自動重用已儲存的譯文，而不會呼叫付費模組——藉此節省時間與成本，並讓相同文字在各專案間保持一致。從側邊欄開啟**翻譯記憶庫**檢視，即可瀏覽並搜尋已儲存的片段。

> **翻譯記憶庫預設為停用**，每個專案皆然。停用期間，專案翻譯出來的內容都不會寫入記憶庫，也不會自動套用任何已儲存的譯文。若要開啟，請到專案的 **設定** 分頁，在**翻譯記憶庫**區段選擇一種重用政策（除了**已停用**以外的任何值）。

## 譯文如何進入記憶庫

* **核准存入記憶庫**——在 **譯文** 分頁中選取譯文並核准，它們就會被記錄為可信任的片段。
* 完成的翻譯也會被記錄下來，以便之後相同的原文能重用它們。

## 重用政策

重用政策（在專案的 **設定** 分頁、**翻譯記憶庫**區段）控制相同原文**是否**及**何時**重用已儲存的譯文。它預設為**已停用**（翻譯記憶庫關閉）；其他選項——例如**嚴格（完整情境相符）**，只有在周圍情境也相符時才重用——則會開啟這項功能。收緊政策可以避免重用一個在某處正確、但在別處未必正確的譯文。

## 逐次執行控制重用

當您從 **對照** 分頁的「翻譯…」對話框開始翻譯時，系統會提示有多少條目會從記憶庫填入，您也可以**為這次執行停用記憶庫**，強制每個條目都重新翻譯——當您希望模型重新考慮先前已記憶的文字時，這個功能就很有用。
