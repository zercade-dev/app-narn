# 譯文分頁

## 總覽

**譯文** 分頁是主要的條目表格：每個原文條目都有一欄對應每種目標語言。您可以在這裡讀取、編輯、篩選、分類，以及**選取**要翻譯的條目。表格支援分頁顯示（每頁 25／50／100／200 列）。

## 編輯

按一下任何譯文儲存格即可直接編輯；確認後變更就會儲存。**原文**欄與**狀態**欄會顯示每個條目的原文與來源，以及它的類別、術語表與翻譯狀態。

## 篩選

使用工具列縮小表格範圍：

* **搜尋**原文與譯文文字。
* **狀態**篩選：只顯示未翻譯、只顯示 LQA 失敗、只顯示溢出、待審校、與原文相同，或佔位符不符。
* 依**語言**、**來源**標籤或**類別**篩選，並顯示或隱藏欄位。

## 選取與翻譯

用核取方塊選取資料列（或選取整個篩選結果集）。有選取內容時，您可以：

* 從選取工具列執行**翻譯所選**（分派規則會依語言決定使用的模組）。
* 批次**新增**或**移除類別**。
* **核准存入記憶庫**——把目前的譯文記錄為可信任的翻譯記憶庫內容。

## 逐條目的類別與術語表

在資料列上按右鍵（或使用其動作選單）可以**編輯類別**，或選擇該條目翻譯時要**啟用**哪些術語表。類別也可以從**類別**分頁批次生成。
