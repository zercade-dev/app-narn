# DeepSeek 模組

## 總覽

**DeepSeek** 模組使用 DeepSeek API 翻譯。它需要一組 DeepSeek API 金鑰，儲存在憑證保險庫中，金鑰名稱為 `DEEPSEEK_API_KEY`。

## 把金鑰加入憑證保險庫

供應商憑證存放在加密的**憑證保險庫**中，而不是明文設定檔。您每個工作階段只需用密碼解鎖保險庫一次。

1. 從側邊欄開啟**全域設定**。
2. 如果您還沒設定過保險庫，先建立它：選擇一組保險庫密碼（之後每個工作階段都會重複使用），然後解鎖。
3. 在**啟用模組**底下，選取 **DeepSeek**。如果缺少必要的金鑰，保險庫編輯器會自動開啟到對應的欄位——否則請按一下**管理憑證保險庫**。
4. 在保險庫編輯器中新增憑證：選擇金鑰 `DEEPSEEK_API_KEY`，貼上您的金鑰作為值，輸入您的**保險庫密碼**，然後按一下**儲存**。

如果之後某張卡片顯示「保險庫已鎖定」，請在翻譯前先按一下**解鎖保險庫**。

## 選擇模型

在專案的**設定**分頁中，選擇一個 DeepSeek 模型（以及選填的推理強度），或繼承全域預設值。**分派**分頁中的**分派規則**會決定哪個模組處理各種語言。

## 取得 DeepSeek API 金鑰

1. 前往 [platform.deepseek.com](https://platform.deepseek.com)。
2. 註冊或登入。
3. 開啟您的 **API keys** 區段。
4. 建立新的 API 金鑰並複製它。
5. 貼到保險庫編輯器的 `DEEPSEEK_API_KEY` 值欄位中。
