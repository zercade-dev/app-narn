# OpenRouter 模組

## 總覽

**OpenRouter** 模組透過 [OpenRouter](https://openrouter.ai) 翻譯——它是一個統一的 API，能路由到許多供應商的模型（Anthropic、OpenAI、Google、Meta 等等）。它需要一組 OpenRouter API 金鑰，儲存在憑證保險庫中，金鑰名稱為 `OPENROUTER_API_KEY`。

## 把金鑰加入憑證保險庫

供應商憑證存放在加密的**憑證保險庫**中，而不是明文設定檔。您每個工作階段只需用密碼解鎖保險庫一次。

1. 從側邊欄開啟**全域設定**。
2. 如果您還沒設定過保險庫，先建立它：選擇一組保險庫密碼（之後每個工作階段都會重複使用），然後解鎖。
3. 在**啟用模組**底下，選取 **OpenRouter**。如果缺少必要的金鑰，保險庫編輯器會自動開啟到對應的欄位——否則請按一下**管理憑證保險庫**。
4. 在保險庫編輯器中新增憑證：選擇金鑰 `OPENROUTER_API_KEY`，貼上您的金鑰作為值，輸入您的**保險庫密碼**，然後按一下**儲存**。

如果之後某張卡片顯示「保險庫已鎖定」，請在翻譯前先按一下**解鎖保險庫**。

## 選擇模型

在專案的**設定**分頁中，從即時的 OpenRouter 目錄中選擇一個模型——每個項目都會顯示其每 token 的價格與上下文長度，且只會列出文字生成模型。模型 ID 會帶有供應商前綴（例如 `anthropic/claude-sonnet-4.5` 或 `openai/gpt-4o-mini`）；您也可以直接輸入新的識別碼。**分派**分頁中的**分派規則**會決定哪個模組處理各種語言。

## 取得 OpenRouter API 金鑰

1. 前往 [openrouter.ai](https://openrouter.ai)。
2. 註冊或登入。
3. 從您的帳號選單開啟 **Keys**。
4. 建立新的 API 金鑰並複製它。
5. 貼到保險庫編輯器的 `OPENROUTER_API_KEY` 值欄位中。

注意：您的文字內容會傳送到 OpenRouter，再依您選擇的模型轉送給對應的供應商，並受 OpenRouter 的條款與該供應商的資料政策約束。
