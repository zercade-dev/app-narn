# DeepL 模組

## 總覽

**DeepL** 模組提供專業的神經機器翻譯。與 LLM 模組不同，它是傳統的機器翻譯，並且可以把專案術語表推送到 DeepL 以維持術語一致。它的金鑰儲存在憑證保險庫中，金鑰名稱為 `DEEPL_API_KEY`。

## 把金鑰加入憑證保險庫

供應商憑證存放在加密的**憑證保險庫**中，而不是明文設定檔。您每個工作階段只需用密碼解鎖保險庫一次。

1. 從側邊欄開啟**全域設定**。
2. 如果您還沒設定過保險庫，先建立它：選擇一組保險庫密碼（之後每個工作階段都會重複使用），然後解鎖。
3. 在**啟用模組**底下，選取 **DeepL**。如果缺少必要的金鑰，保險庫編輯器會自動開啟到對應的欄位——否則請按一下**管理憑證保險庫**。
4. 在保險庫編輯器中新增憑證：選擇金鑰 `DEEPL_API_KEY`，貼上您的驗證金鑰作為值，輸入您的**保險庫密碼**，然後按一下**儲存**。

DeepL 不支援具名實例——只有單一一個 DeepL 模組。

## 使用術語表

DeepL 可以在翻譯時套用術語表。先在**術語表**分頁中建立術語，然後用**推送至 DeepL** 上傳它們。如果術語表在推送後又有變更，分頁會顯示「需要重新推送」——請再次推送以更新 DeepL。

## 取得 DeepL API 金鑰

1. 前往 [deepl.com/account](https://www.deepl.com/account)。
2. 註冊 Free 或 Pro API 帳號。
3. 開啟 **Account Settings** 並找到 **API Key** 區段。
4. 複製您的驗證金鑰。
5. 貼到保險庫編輯器的 `DEEPL_API_KEY` 值欄位中。
