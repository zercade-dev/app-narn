# 術語表分頁

## 總覽

**術語表** 分頁用來維持術語的一致性。一個專案可以持有多個術語表；每個術語表都是一份原文術語清單，並附有每種目標語言的譯文。術語表會自動與條目比對，比對到的術語會在翻譯時傳給模型。

## 術語表與術語

* 用 **新增術語表** 建立術語表；之後可以重新命名或刪除。
* **啟用**或**停用**某個術語表——停用的術語表在匯入與翻譯時都會被忽略。
* 新增術語時可以填入**原文**、**每種語言的譯文**，以及選填的**備註**。
* 當某個術語必須完全照術語表中的寫法輸出時（例如角色名稱或品牌名稱），將它標記為**常數**。詳見下方的*常數術語*。
* 術語表有兩個分頁：**術語**列出它的術語，**符合項**列出包含這些術語的條目，你可以在那裡為條目指派或移除術語表。

有些術語表是**唯讀**的（全域管理），只提供術語，無法在這裡編輯。

## 常數術語

* 常數術語**永遠不會傳送給翻譯引擎**。NARN 在翻譯前以預留位置取代它，翻譯後再於原位放入術語表中的譯法，因此像 *Diluc* 這樣的角色名稱總會和術語表中寫的完全一致。
* **區分大小寫。**只有與術語寫法完全相同的文字才受保護：*Razor*（角色）受保護，*a razor* 不受保護。其他寫法會以一般術語提示傳送給引擎，並標記為名稱，讓引擎區分名稱與一般詞語。
* **引擎無法變動這個詞。**由於引擎看不到該術語，它無法加以變格，也無法讓其他詞與之一致：在俄語、韓語或土耳其語等語言中，常數名稱一律以原形出現。請只將常數用於必須保持不變的名稱和代碼。
* 同時也是一般詞語的名稱最好保留為一般術語，因為標題和標籤常將其首字母大寫（*Gaming Settings*）。在內建的 **Genshin Characters** 術語表中，除了 Gaming、Amber、Razor、Sucrose 和 Prune，所有名稱都是常數。

## 匯入與匯出

從 **CSV** 或 **TBX** 匯入術語——套用前會先顯示預覽，說明新增、更新或衝突的術語各有多少筆。也可以把術語表匯出回 **CSV** 或 **TBX**。

## 用 AI 生成

* **生成術語表** 會掃描原文，提出經常出現的名稱與自訂術語構成的術語表建議。它會在背景執行——可以在 **活動** 分頁追蹤進度，並在建立前先審閱建議內容。您可以把既有的術語表當作「已知術語」傳入，讓模型不會重複提出。
* **生成譯文** 會為尚未填入目標語言譯文的術語補上譯文。

## DeepL

如果您用 DeepL 翻譯，使用 **推送至 DeepL** 上傳術語表的術語。編輯已推送過的術語表後，分頁會顯示「需要重新推送」——請再次推送以更新 DeepL。

## 逐條目控制

在譯文分頁中，您可以選擇個別條目要**啟用**哪些術語表。
