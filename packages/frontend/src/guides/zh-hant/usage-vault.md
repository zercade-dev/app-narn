# 憑證保險庫

## 總覽

供應商的 API 金鑰絕不會以明文存放在設定檔或環境變數中。它們存放在**憑證保險庫**中——這是一個加密的儲存區，必須先解鎖才能讓任何翻譯或 AI 審閱使用其中的憑證。您每個瀏覽器工作階段只需解鎖一次；憑證只會在記憶體中解密。

<!-- local-only -->
## 密碼保險庫（自架版）

在自架安裝中，保險庫是一個加密的本機檔案。第一次解鎖時就會建立它：您選擇的密碼會成為保險庫密碼，之後每次儲存憑證都會重新加密這個檔案。密碼本身絕不會被儲存——沒有它，這個檔案就無法解密。可以從 **全域設定**，或任何顯示「保險庫已鎖定」的卡片處解鎖。
<!-- /local-only -->

## 裝置綁定保險庫（雲端版）

在雲端版本中，保險庫會**加密後存放在伺服器上**，解密時需要兩項要素：

- 您的**密碼**——不論在伺服器或裝置上都絕不會被儲存。
- **裝置專屬金鑰**——在您註冊某台裝置時由瀏覽器產生，只保存在那台裝置上。

解鎖時，這兩項要素都會經由加密連線傳送，並在伺服器端組合，**只在記憶體中、僅供這次工作階段**推導出解密金鑰。無論是這兩項要素本身，還是推導出的金鑰，都絕不會寫入伺服器儲存空間——伺服器只儲存加密後的保險庫本身。因此單憑伺服器上儲存的資料，無法還原您的憑證；單憑外洩的密碼也不夠：解鎖還需要您已註冊的其中一台裝置。

如果全域設定顯示的是 **前往保險庫頁面** 按鈕而不是密碼輸入框，代表您使用的是裝置綁定保險庫——保險庫頁面會處理設定、裝置註冊、解鎖、憑證編輯與密碼變更。

## 須知事項

- 從未使用過的裝置，必須先在保險庫頁面完成**註冊**，才能用來解鎖。
- 如果您忘記密碼（在雲端版本中，或是遺失所有已註冊的裝置），保險庫的內容將無法復原——您必須重新設定保險庫，並重新輸入供應商金鑰。
- 應用程式所記錄的任何內容都會先經過遮蔽處理，因此憑證的值絕不會出現在日誌中。
