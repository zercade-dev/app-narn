# Generic AI 模組

## 總覽

**Generic AI** 模組可以連接任何相容 OpenAI 格式的 API——不論是代管供應商，還是本機執行的伺服器（例如 Ollama、LM Studio、vLLM）。它的金鑰儲存在憑證保險庫中，金鑰名稱為 `GENERIC_API_KEY`。

**API 金鑰是選填的。** 只有在端點需要驗證時才會用到（大多數付費雲端供應商都需要）。像 Ollama 或 LM Studio 這樣的本機伺服器不需要真正的金鑰——但保險庫仍要求 `GENERIC_API_KEY` 欄位不能是空的，所以請填入任意佔位值（例如 `local`）來滿足這個要求。

## 把金鑰加入憑證保險庫

供應商憑證存放在加密的**憑證保險庫**中，而不是明文設定檔。您每個工作階段只需用密碼解鎖保險庫一次。

1. 從側邊欄開啟**全域設定**。
2. 如果您還沒設定過保險庫，先建立它：選擇一組保險庫密碼（之後每個工作階段都會重複使用），然後解鎖。
3. 在**啟用模組**底下，選取 **Generic AI**。如果缺少必要的金鑰，保險庫編輯器會自動開啟到對應的欄位——否則請按一下**管理憑證保險庫**。
4. 在保險庫編輯器中新增憑證：選擇金鑰 `GENERIC_API_KEY`，輸入您的**保險庫密碼**，然後按一下**儲存**。若是付費端點，請貼上真正的 API 金鑰作為值。若是不需要驗證的本機伺服器，這個金鑰是選填的——只要填入任意非空的佔位值即可（例如 `local`）。

## 用實例執行多個端點

Generic AI 支援**具名實例**，讓您可以同時註冊多個端點（例如一個雲端供應商加一個本機伺服器）。在全域設定中使用**新增另一個 Generic AI 實例**。每個實例都會有自己衍生出的保險庫金鑰——例如 `GENERIC_API_KEY__MY-OLLAMA`——可以在同一個保險庫編輯器中填寫。

## 選擇端點與模型

在全域設定中，為這個模組（或各個實例）設定基礎 URL 與模型，然後在**設定**分頁中依專案選擇模型。**分派**分頁中的**分派規則**會決定哪個模組或實例處理各種語言。

## 取得憑證

對於**本機伺服器**（Ollama、LM Studio、vLLM），不需要任何帳號或金鑰——只需要基礎 URL（例如 `http://localhost:11434/v1`）以及 `GENERIC_API_KEY` 欄位中的佔位值。

對於**付費供應商**，步驟依供應商而異：建立帳號、取得 API 基礎 URL 與金鑰，並確認該端點使用相容 OpenAI 聊天補全格式，然後再把金鑰輸入保險庫。
