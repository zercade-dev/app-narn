# Groq 模組

## 總覽

**Groq** 模組透過 [Groq](https://groq.com) 翻譯——它為 Llama、Qwen、GPT-OSS 等開放模型提供快速推論，並有適合日常翻譯工作的免費方案。它需要一組 Groq API 金鑰，儲存在憑證保險庫中，金鑰名稱為 `GROQ_API_KEY`。

## 把金鑰加入憑證保險庫

供應商憑證存放在加密的**憑證保險庫**中，而不是明文設定檔。您每個工作階段只需用密碼解鎖保險庫一次。

1. 從側邊欄開啟**全域設定**。
2. 如果您還沒設定過保險庫，先建立它：選擇一組保險庫密碼（之後每個工作階段都會重複使用），然後解鎖。
3. 在**啟用模組**底下，選取 **Groq**。如果缺少必要的金鑰，保險庫編輯器會自動開啟到對應的欄位——否則請按一下**管理憑證保險庫**。
4. 在保險庫編輯器中新增憑證：選擇金鑰 `GROQ_API_KEY`，貼上您的金鑰作為值，輸入您的**保險庫密碼**，然後按一下**儲存**。

如果之後某張卡片顯示「保險庫已鎖定」，請在翻譯前先按一下**解鎖保險庫**。

## 選擇模型

在專案的**設定**分頁中，從即時的 Groq 目錄中選擇一個模型，或繼承全域預設值。`llama-3.3-70b-versatile` 是翻譯品質方面穩健的預設選擇；較小的模型（例如 `llama-3.1-8b-instant`）會犧牲一些品質來換取速度。**分派**分頁中的**分派規則**會決定哪個模組處理各種語言。

## 取得 Groq API 金鑰

1. 前往 [console.groq.com](https://console.groq.com)。
2. 註冊或登入。
3. 從主控台選單開啟 **API Keys**。
4. 建立新的 API 金鑰並複製它——金鑰以 `gsk_` 開頭。
5. 貼到保險庫編輯器的 `GROQ_API_KEY` 值欄位中。

Groq 的免費方案針對各模型設有每日上限（此處未列出確切數字——請至您的主控台查看目前的上限），且依 Groq 的條款，API 資料不會用於訓練模型。加入您的金鑰後，**NARN Freeway** 會在將翻譯工作分散到您已連接的各供應商免費額度時，自動納入 Groq 的免費方案——不需要額外設定。
