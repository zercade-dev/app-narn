# 備份分頁

## 總覽

**備份** 分頁會把一個專案——其設定、條目與術語表——打包成可驗證的 `.zip` 封存檔。每個檔案都會計算總和檢查碼，還原時會先驗證檢查碼，才會寫回任何內容。

## 建立備份

1. 選擇一個專案。
2. 開啟**備份**分頁。
3. 按一下**建立備份**。
4. 新的封存檔會出現在**已儲存的備份**中，您可以在那裡**下載**它。

## 自動備份

應用程式也會自動為您建立安全快照，與手動備份並列顯示：

* **CSV 匯入前**——匯入前一刻的還原點。
* **重新翻譯前**——條目被覆寫前一刻的還原點。

全域設定可以設定**每個專案的備份數量上限**（預設 10）；超過上限的較舊備份會被清除。

## 還原

1. 在**從備份還原**中，選擇一個 `.zip` 檔（或從已儲存的備份中選一個）。
2. 應用程式會驗證檢查碼並顯示預覽（專案、檔案、建立時間）。
3. 確認還原。還原會覆寫專案目前的設定、條目與術語表——此動作無法復原，如有疑慮請先建立一份新的備份。

## 刪除

在任何已儲存的備份上使用**刪除**，即可從伺服器永久移除該封存檔。
