# 빠른 설정

## 개요

새 프로젝트의 전체 경로예요: 제공업체 활성화, 항목 가져오기, 용어집과 배정 구성, 번역, 검토. *(Optional)*으로 표시된 단계는 품질을 높여 주지만 첫 번역에 꼭 필요하지는 않아요 — 처음에는 건너뛰고 나중에 돌아와도 돼요.

## 1. 제공업체를 활성화하고 자격 증명 저장하기

1. **글로벌 설정**을 열고 원하는 제공업체마다(Anthropic, OpenAI, DeepL 등) **모듈을 활성화**하세요. 모듈 하나가 여러 **이름 붙은 인스턴스**를 가질 수 있어요 — 같은 제공업체를 다른 키나 기본값으로 두 벌 구성할 때 유용해요.
2. 제공업체 자격 증명은 암호화된 **자격 증명 보관함**에 저장돼요 — 처음 쓸 때 설정하고, 세션마다 한 번 잠금을 해제하세요. 작동 방식은 *자격 증명 보관함* 가이드를 참고하세요.
3. 모듈이나 인스턴스마다 **모델**(및 선택적인 **추론 강도**)을 고르세요. 저렴한 모델은 번역 품질이 떨어지므로, 알맞은 지점을 찾기까지 시행착오를 각오하세요. **추론 강도**를 주의하세요 — 사고(thinking) 모델에서는 비용이 빠르게 불어날 수 있어요.

## 2. 프로젝트를 만들고 항목 가져오기

프로젝트를 만들고 **원본 언어**를 설정한 다음, **데이터** 탭의 **CSV 가져오기**로 원문 항목(과 파일에 이미 있는 번역)을 불러오세요.

## 3. *(Optional)* 원문을 먼저 검토하기

번역하기 전에 원본 언어에 **원문 AI 검토**를 실행하세요 — 여기서 오타와 불명확한 표현을 고치면 이후의 모든 번역에 도움이 돼요. 수정으로 인해 이미 번역이 있던 항목이 바뀌면, 예전 번역은 **미연결 항목** 탭에 남아요 — 필요하면 다시 번역하는 옵션과 함께 **재연결**하세요.

## 4. *(Optional)* 용어집 활성화하기

**용어집** 탭에서 프로젝트에 맞는 용어집을 활성화하세요. 자동 적용은 **대소문자를 구분하지 않고 온전한 단어**로 용어를 매칭해요 — 활용형(복수형, 어미 변화)은 잡히지 않아요. **DeepL**로 번역하나요? **DeepL로 보내기**(오른쪽 위)로 용어집을 업로드하고, 편집한 뒤에는 다시 보내세요.

## 5. 배정 설정하기

**배정** 탭을 열고, 처음 열렸을 때 나오는 선택기에서 제공업체를 고르세요 — 그러면 프로젝트의 모든 항목이 그곳으로 가고, 제공업체 하나만 쓰는 구성이라면 이것으로 충분해요. 언어, 카테고리, 항목 길이별로 다른 제공업체를 쓰고 싶다면 **고급**으로 바꿔서 **배정 규칙**을 대신 추가하세요. 어느 쪽이든 선택 내용은 자동으로 저장돼요. 이 단계는 꼭 필요해요: 일치하는 규칙이 없는 항목은 *"배정 대상 없음"* 오류로 번역에 실패해요.

## 6. *(Optional)* 직접 콘텐츠로 용어집 키우기

대량 번역 전에 용어집을 키워 두세요: 용어를 직접 추가하거나, 전체 원문에 **용어집 생성**을 실행하거나 — 더 표적화된 방법으로 — **번역** 탭에서 좋은 후보 항목을 선택하고 **선택한 항목에서 용어집 생성**(기존 번역 포함)을 사용하세요. 여기서는 성능 좋은 모델을 쓰세요. 용어집 품질은 이후 번역되는 모든 것에 누적돼요.

## 7. *(Optional)* 비교 탭에서 먼저 품질을 다듬기

전체 번역 실행 전에, 직접 판단할 수 있는 언어 하나를 **비교** 탭으로 다듬어 보세요.

- 각 항목의 **참고 정보**(캐릭터, 톤, 메모)와 용어집을 번역이 제대로 읽힐 때까지 다듬으세요. 참고 정보는 언어별이 아니라 항목별로 저장되므로, 이 작업은 다른 모든 언어에도 자동으로 이어져요.
- 항목 하나하나 반복 작업하는 단계이므로, 저렴하거나 무료인 모델이면 충분해요 — 예를 들어 무료 Gemini 키(*Google AI (Gemini)* 가이드 참고)를 별도의 **모듈 인스턴스**로 추가하고, 배정을 일시적으로 그쪽으로 돌려 두세요. 무료 등급은 일일 한도가 있으니 요청을 묶어서 보내는 편이 좋아요.
- 결과가 만족스럽나요? 같은 설정으로 전체 배치를 한 번 번역해서 대량으로도 잘 유지되는지 확인하세요.

## 8. 번역하기

실제 번역을 실행하는 방법은 두 가지예요.

- **번역** — 항목을 선택하고 **선택 항목 번역**을 실행하면 모든 대상 언어를 한 번에 처리해요.
- **비교** — 한 번에 한 언어씩, 필요하면 이미 검토를 마친 언어를 **참조** 컨텍스트로 함께 사용해요.

전체 프로젝트라면 보통 검토된 참조 언어와 함께 한 번에 한 언어씩 처리하는 방식이 더 나아요: 이후의 AI 검토가 한 언어에 집중될 수 있거든요. 진행 상황은 **활동** 탭에서 지켜보세요.

배치는 기본적으로 자동이에요. 짧은 항목이 많은 작은 프로젝트라면, 배치 크기를 **0**(언어 전체를 요청 하나로)으로 직접 지정하는 편이 성능 좋은 모델에서 더 잘 맞을 수 있어요.

## 9. 실행 결과 검토하기

하나를 고르세요.

- **활동** 탭에서 완료된 실행에 **AI 검토**를 실행하세요.
- **수동 검토**나 **비교**에서 직접 검토하세요.
- 있는 그대로 모두 승인하고 나중에 검토하세요.
