# 백업 탭

## 개요

**백업** 탭은 프로젝트(설정, 항목, 용어집)를 검증 가능한 `.zip` 아카이브로 묶어요. 모든 파일은 체크섬이 계산되며, 복원 시 무언가를 다시 쓰기 전에 체크섬을 검증해요.

## 백업 만들기

1. 프로젝트를 선택하세요.
2. **백업** 탭을 여세요.
3. **백업 만들기**를 클릭하세요.
4. 새 아카이브가 **저장된 백업**에 나타나며, 여기서 **다운로드**할 수 있어요.

## 자동 백업

앱은 안전을 위한 스냅샷도 자동으로 만들어 주며, 직접 만든 백업과 나란히 표시돼요.

- **CSV 가져오기 전** — 가져오기 직전 시점의 복원 지점이에요.
- **다시 번역 전** — 항목이 덮어써지기 직전 시점의 복원 지점이에요.

글로벌 설정에서 **프로젝트당 최대 백업 수**(기본값 10)를 정할 수 있어요. 이 수를 넘는 오래된 백업은 정리돼요.

## 복원하기

1. **백업에서 복원**에서 `.zip` 파일을 선택하세요(또는 저장된 백업 중 하나를 고르세요).
2. 앱이 체크섬을 검증하고 미리보기(프로젝트, 파일, 생성 시각)를 보여줘요.
3. 확인하세요. 복원하면 프로젝트의 현재 설정, 항목, 용어집을 덮어써요 — 되돌릴 수 없으니, 확신이 서지 않으면 먼저 새 백업을 만드세요.

## 삭제하기

저장된 백업에서 **삭제**를 사용하면 서버에서 해당 아카이브를 영구적으로 제거해요.
