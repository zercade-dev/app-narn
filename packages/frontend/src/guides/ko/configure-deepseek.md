# DeepSeek 모듈

## 개요

**DeepSeek** 모듈은 DeepSeek API로 번역해요. DeepSeek API 키가 필요하며, 자격 증명 보관함에 `DEEPSEEK_API_KEY` 키로 저장해요.

## 자격 증명 보관함에 키 추가

제공업체 자격 증명은 일반 설정이 아니라 암호화된 **자격 증명 보관함**에 저장돼요. 보관함은 세션마다 한 번, 비밀번호로 잠금을 해제해요.

1. 사이드바에서 **글로벌 설정**을 여세요.
2. 아직 보관함을 만들지 않았다면 만드세요: 보관함 비밀번호를 정하고(세션마다 다시 사용해요) 잠금을 해제하세요.
3. **모듈 활성화** 아래에서 **DeepSeek**을 선택하세요. 필요한 키가 없으면 보관함 편집기가 해당 키를 자동으로 열어요. 그렇지 않으면 **자격 증명 보관함 관리**를 클릭하세요.
4. 보관함 편집기에서 자격 증명을 추가하세요: 키로 `DEEPSEEK_API_KEY`를 선택하고, 값으로 발급받은 키를 붙여넣은 다음 **보관함 비밀번호**를 입력하고 **저장**을 클릭하세요.

나중에 카드에 *보관함 잠김*이 표시되면, 번역하기 전에 **보관함 잠금 해제**를 클릭하세요.

## 모델 선택

프로젝트의 **설정** 탭에서 DeepSeek 모델(및 선택적으로 추론 강도)을 고르거나, 글로벌 기본값을 물려받게 두세요. 각 언어를 어떤 모듈이 처리할지는 배정 탭의 **배정 규칙**이 결정해요.

## DeepSeek API 키 발급

1. [platform.deepseek.com](https://platform.deepseek.com)에 방문하세요.
2. 가입하거나 로그인하세요.
3. **API keys** 섹션을 여세요.
4. 새 API 키를 만들고 복사하세요.
5. 보관함 편집기의 `DEEPSEEK_API_KEY` 값 칸에 붙여넣으세요.
