# OpenRouter 모듈

## 개요

**OpenRouter** 모듈은 [OpenRouter](https://openrouter.ai)로 번역해요 — 여러 벤더(Anthropic, OpenAI, Google, Meta 외)의 모델로 연결되는 단일 API예요. OpenRouter API 키가 필요하며, 자격 증명 보관함에 `OPENROUTER_API_KEY` 키로 저장해요.

## 자격 증명 보관함에 키 추가

제공업체 자격 증명은 일반 설정이 아니라 암호화된 **자격 증명 보관함**에 저장돼요. 보관함은 세션마다 한 번, 비밀번호로 잠금을 해제해요.

1. 사이드바에서 **글로벌 설정**을 여세요.
2. 아직 보관함을 만들지 않았다면 만드세요: 보관함 비밀번호를 정하고(세션마다 다시 사용해요) 잠금을 해제하세요.
3. **모듈 활성화** 아래에서 **OpenRouter**를 선택하세요. 필요한 키가 없으면 보관함 편집기가 해당 키를 자동으로 열어요. 그렇지 않으면 **자격 증명 보관함 관리**를 클릭하세요.
4. 보관함 편집기에서 자격 증명을 추가하세요: 키로 `OPENROUTER_API_KEY`를 선택하고, 값으로 발급받은 키를 붙여넣은 다음 **보관함 비밀번호**를 입력하고 **저장**을 클릭하세요.

나중에 카드에 *보관함 잠김*이 표시되면, 번역하기 전에 **보관함 잠금 해제**를 클릭하세요.

## 모델 선택

프로젝트의 **설정** 탭에서 실시간 OpenRouter 카탈로그의 모델을 고르세요 — 각 항목에는 토큰당 가격과 컨텍스트 길이가 표시되며, 텍스트 생성 모델만 목록에 나와요. 모델 ID는 벤더 접두사가 붙어요(예: `anthropic/claude-sonnet-4.5` 또는 `openai/gpt-4o-mini`). 새 슬러그를 직접 입력할 수도 있어요. 각 언어를 어떤 모듈이 처리할지는 배정 탭의 **배정 규칙**이 결정해요.

## OpenRouter API 키 발급

1. [openrouter.ai](https://openrouter.ai)에 방문하세요.
2. 가입하거나 로그인하세요.
3. 계정 메뉴에서 **Keys**를 여세요.
4. 새 API 키를 만들고 복사하세요.
5. 보관함 편집기의 `OPENROUTER_API_KEY` 값 칸에 붙여넣으세요.

참고: 입력한 텍스트는 OpenRouter로 전송된 뒤, 선택한 모델의 벤더로 전달돼요. 이때 OpenRouter의 약관과 해당 벤더의 데이터 정책이 적용돼요.
