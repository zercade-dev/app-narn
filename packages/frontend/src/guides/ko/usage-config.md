# 설정 탭

## 개요

**설정** 탭에는 선택한 프로젝트의 번역 정책이 담겨요: 모듈별 모델 선택, 번역 메모리 재사용, 배치 그룹화, 품질(LQA) 검사, 프로젝트 관리예요. **언어**와 **CSV 가져오기/내보내기**는 이제 별도의 **데이터** 탭에 있어요. 제공업체 자격 증명은 여기서 설정하지 않아요 — **자격 증명 보관함**에 있어요(*모듈 구성* 가이드와 **글로벌 설정**을 참고하세요).

## 언어 (데이터 탭에 있음)

번역할 **원본 언어**와 **대상 언어**는 **데이터** 탭에서 설정해요. 활성화된 대상 언어 집합이 다른 모든 탭을 좌우해요 — 항목 열, 배정 규칙, 품질 검사가 모두 이를 따라가요.

## CSV 가져오기와 내보내기 (데이터 탭에 있음)

CSV 가져오기와 내보내기도 **데이터** 탭에 있어요.

- **CSV 가져오기**는 원문 항목과 기존 번역을 불러와요. 가져오기 직전에 안전 스냅샷이 자동으로 만들어지므로, **백업** 탭에서 롤백할 수 있어요.
- 깔끔하게 해석되지 않는 행(따옴표 바로 뒤에 쉼표가 오는 경우)은 열이 밀린 데이터로 기록되는 대신, 건너뛰고 보고돼요.
- **CSV 내보내기**는 프로젝트를 내려받아요. 언어와 번역 참고 정보 열 포함 여부를 고를 수 있어요.

## 모듈과 모델

제공업체는 **글로벌 설정**에서 한 번만 활성화하면 돼요. 여기 설정 탭에서는 활성화된 모듈마다 프로젝트별로 **모델**과 **추론 강도**를 고르거나, *글로벌 설정에서 상속*으로 그대로 두세요. 특정 항목에 실제로 어떤 모듈이 실행될지는 **배정 규칙**이 결정해요(*배정* 가이드를 참고하세요).

## LQA 검사

**LQA 검사** 패널은 모든 번역에서 실행되는 품질 게이트를 설정해요: 개별 검사(인라인 태그 일치, 길이 제한, 길이 초과, 용어집 준수, 금지 용어, 정규식 어서션 외)를 켜고 끄고, 각각을 **차단**이나 **경고**로 설정하세요. 차단 이슈는 게이트를 통과하지 못하고 자동 재시도를 한 번 유발할 수 있어요. 경고는 보고만 돼요.

## 배치 그룹화

**배치 그룹화**는 관련 항목(카테고리 및/또는 용어집 기준)을 같은 요청에 묶어, 모델이 맥락 속에서 항목을 보게 해요. 프로젝트 기본값을 정하고, 실행마다 재정의할 수 있어요.

## 프로젝트 관리

**위험 구역**에서 프로젝트를 **복제**하거나(설정과 항목은 복제되지만 비밀 정보는 복제되지 않아요) 영구적으로 **삭제**할 수 있어요.
