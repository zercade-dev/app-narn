# 번역 메모리

## 개요

**번역 메모리**(TM)는 이미 알려진 번역을 워크스페이스 전체에서 보관하는 저장소예요. 어떤 문자열의 원문이 메모리에 이미 있는 것과 일치하면, 유료 모듈을 호출하는 대신 저장된 번역이 자동으로 재사용돼요 — 시간과 비용을 아끼고, 프로젝트를 넘나들며 같은 텍스트를 일관되게 유지해요. 사이드바에서 **번역 메모리** 화면을 열면 저장된 세그먼트를 둘러보고 검색할 수 있어요.

> **번역 메모리는 모든 프로젝트에서 기본적으로 꺼져 있어요.** 꺼져 있는 동안에는 프로젝트가 번역한 내용이 메모리에 기록되지 않고, 저장된 번역이 자동으로 적용되지도 않아요. 켜려면 프로젝트의 **설정** 탭을 열어 **번역 메모리** 섹션에서 재사용 정책을 고르세요(*사용 안 함*이 아닌 값이면 돼요).

## 항목이 메모리에 들어가는 방식

- **번역 메모리에 승인** — **번역** 탭에서 번역을 선택하고 승인하면, 신뢰할 수 있는 세그먼트로 기록돼요.
- 완료된 번역도 기록되어, 나중에 같은 원문이 이를 재사용할 수 있어요.

## 재사용 정책

재사용 정책(프로젝트의 **설정** 탭, **번역 메모리** 섹션)은 동일한 원문에 대해 저장된 번역을 *언제, 재사용할지 여부*를 결정해요. 기본값은 **사용 안 함**(TM 꺼짐)이며, 다른 선택지 — 예를 들어 주변 컨텍스트까지 일치할 때만 재사용하는 **엄격(전체 컨텍스트 일치)** — 을 고르면 켜져요. 정책을 엄격하게 조일수록, 한 곳에서는 맞았지만 다른 곳에서는 맞지 않는 번역을 재사용하는 일을 피할 수 있어요.

## 실행별 재사용 제어

**비교** 탭의 *번역…* 대화상자에서 번역을 시작하면, 메모리로 채워질 항목 수를 알려 주는 안내가 나타나요. 이때 **이번 실행에서는 메모리를 사용하지 않기**를 켜면 모든 항목을 강제로 새로 번역하게 할 수 있어요 — 모델이 이전에 기억해 둔 텍스트를 다시 검토하길 원할 때 유용해요.
