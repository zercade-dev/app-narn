# Generic AI 모듈

## 개요

**Generic AI** 모듈은 OpenAI 호환 API라면 어디든 연결돼요 — 호스팅 제공업체든, 로컬에서 실행하는 서버(예: Ollama, LM Studio, vLLM)든 상관없어요. 키는 자격 증명 보관함에 `GENERIC_API_KEY`로 저장해요.

**API 키는 선택 사항이에요.** 인증이 필요한 엔드포인트(대부분의 유료 클라우드 제공업체)에서만 의미가 있어요. Ollama나 LM Studio 같은 로컬 서버는 실제 키가 필요 없지만, 보관함은 `GENERIC_API_KEY` 필드가 비어 있지 않기를 요구하므로 아무 값이나(예: `local`) 넣어 조건을 채우세요.

## 자격 증명 보관함에 키 추가

제공업체 자격 증명은 일반 설정이 아니라 암호화된 **자격 증명 보관함**에 저장돼요. 보관함은 세션마다 한 번, 비밀번호로 잠금을 해제해요.

1. 사이드바에서 **글로벌 설정**을 여세요.
2. 아직 보관함을 만들지 않았다면 만드세요: 보관함 비밀번호를 정하고(세션마다 다시 사용해요) 잠금을 해제하세요.
3. **모듈 활성화** 아래에서 **Generic AI**를 선택하세요. 필요한 키가 없으면 보관함 편집기가 해당 키를 자동으로 열어요. 그렇지 않으면 **자격 증명 보관함 관리**를 클릭하세요.
4. 보관함 편집기에서 자격 증명을 추가하세요: 키로 `GENERIC_API_KEY`를 선택하고, **보관함 비밀번호**를 입력한 다음 **저장**을 클릭하세요. 유료 엔드포인트라면 실제 API 키를 값으로 붙여넣으세요. 인증이 필요 없는 로컬 서버라면 키는 선택 사항이에요 — 비어 있지 않은 아무 값(예: `local`)만 넣어 두세요.

## 인스턴스로 엔드포인트 여러 개 사용하기

Generic AI는 **이름 붙은 인스턴스**를 지원하므로, 여러 엔드포인트(예: 클라우드 제공업체 하나와 로컬 서버 하나)를 나란히 등록할 수 있어요. 글로벌 설정에서 **Generic AI 인스턴스 하나 더 추가…**를 사용하세요. 각 인스턴스는 고유한 파생 보관함 키를 가져요 — 예를 들어 `GENERIC_API_KEY__MY-OLLAMA` — 이 키는 같은 보관함 편집기에서 입력해요.

## 엔드포인트와 모델 선택

모듈(또는 각 인스턴스)의 글로벌 설정에서 기본 URL과 모델을 지정한 다음, **설정** 탭에서 프로젝트별 모델을 고르세요. 각 언어를 어떤 모듈이나 인스턴스가 처리할지는 배정 탭의 **배정 규칙**이 결정해요.

## 자격 증명 얻기

**로컬 서버**(Ollama, LM Studio, vLLM)라면 계정이나 키가 필요 없어요 — 기본 URL(예: `http://localhost:11434/v1`)과 `GENERIC_API_KEY` 필드에 넣을 아무 값만 있으면 돼요.

**유료 제공업체**라면 절차는 업체마다 달라요: 계정을 만들고, API 기본 URL과 키를 발급받은 다음, 엔드포인트가 OpenAI의 chat-completions 형식을 지원하는지 확인하고 보관함에 키를 입력하세요.
