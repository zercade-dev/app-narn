# DeepL 모듈

## 개요

**DeepL** 모듈은 전문 신경망 기계 번역을 제공해요. LLM 모듈과 달리 고전적인 MT 방식이며, 프로젝트 용어집을 DeepL로 보내 일관된 용어를 유지할 수 있어요. 키는 자격 증명 보관함에 `DEEPL_API_KEY`로 저장해요.

## 자격 증명 보관함에 키 추가

제공업체 자격 증명은 일반 설정이 아니라 암호화된 **자격 증명 보관함**에 저장돼요. 보관함은 세션마다 한 번, 비밀번호로 잠금을 해제해요.

1. 사이드바에서 **글로벌 설정**을 여세요.
2. 아직 보관함을 만들지 않았다면 만드세요: 보관함 비밀번호를 정하고(세션마다 다시 사용해요) 잠금을 해제하세요.
3. **모듈 활성화** 아래에서 **DeepL**을 선택하세요. 필요한 키가 없으면 보관함 편집기가 해당 키를 자동으로 열어요. 그렇지 않으면 **자격 증명 보관함 관리**를 클릭하세요.
4. 보관함 편집기에서 자격 증명을 추가하세요: 키로 `DEEPL_API_KEY`를 선택하고, 값으로 발급받은 인증 키를 붙여넣은 다음 **보관함 비밀번호**를 입력하고 **저장**을 클릭하세요.

DeepL은 이름 붙은 인스턴스를 지원하지 않아요 — DeepL 모듈은 하나뿐이에요.

## 용어집 사용

DeepL은 번역할 때 용어집을 적용할 수 있어요. **용어집** 탭에서 용어를 만든 다음 **DeepL로 보내기**로 업로드하세요. 보낸 뒤 용어집이 바뀌면 탭에 *다시 보내야 함*이 표시돼요 — DeepL에 반영하려면 다시 보내세요.

## DeepL API 키 발급

1. [deepl.com/account](https://www.deepl.com/account)에 방문하세요.
2. Free 또는 Pro API 계정에 가입하세요.
3. **Account Settings**를 열고 **API Key** 섹션을 찾으세요.
4. 인증 키를 복사하세요.
5. 보관함 편집기의 `DEEPL_API_KEY` 값 칸에 붙여넣으세요.
