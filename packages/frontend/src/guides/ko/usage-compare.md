# 비교 탭

## 개요

**비교** 탭은 한 번에 한 언어씩 집중해서 번역을 검토하고 채워 넣는 작업 공간이에요. **원문**, 선택적인 **참조** 언어, **대상** 언어를 나란히 보여줘요 — 원문만 보고 번역하는 대신, 이미 신뢰하는 언어를 기준으로 번역할 때 유용해요.

## 화면 준비하기

- 작업할 **대상** 언어를 고르세요.
- 선택적으로 **참조** 언어를 골라 추가 열로 표시하고 번역 컨텍스트로 활용하세요.
- **검색**과 필터를 사용하세요: 미번역만, **LQA** 이슈, **검토 필요**.

## 번역 작업하기

- 대상 셀은 어디든 바로 편집할 수 있어요. 저장 후에는 **되돌리기**가 제공돼요.
- 필요할 때 한 행씩 **다시 번역**하세요.
- **+ 참고 정보**는 항목에 번역 참고 정보(캐릭터, 톤, 상황 메모)를 붙여요. 다음 번역부터 모듈이 이 정보를 받아요.

## 일괄 번역하기

**번역…**을 클릭하면 현재 보기에 대한 일괄 번역 대화상자가 열려요.

- 현재 보기에서 **선택한** 항목이나 **전체** 항목을 번역하세요.
- **번역되지 않은 항목만 채우기**를 하거나, 기존 항목을 **다시 번역**하세요.
- 참조 언어를 골랐다면 **참조 언어를 컨텍스트로 사용하기**를 켤 수 있어요.
- 이번 실행의 **배치 그룹화**를 설정하고, 필요하면 **이번 실행에서는 메모리를 사용하지 않기**를 켜서 모든 항목을 새로 번역하게 하세요.

## 검토 보조 기능

**모두 검토 필요로 표시** 또는 **모두 검토 완료로 표시**를 사용하면 현재 보기 전체를 검토 흐름에 맞춰 한 번에 처리할 수 있어요.
