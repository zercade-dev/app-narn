# 배정 탭

## 개요

**배정** 탭은 각 항목을 어떤 모듈과 모델이 처리할지 결정해요. 처음 열면 단일 제공업체 선택기가 나오는데, 제공업체 하나를 고르면 프로젝트의 모든 항목이 그곳으로 가요. 대부분의 프로젝트는 이것만으로 충분해요.

목적지가 여러 개 필요한가요? 탭을 **고급**으로 바꾸면 전체 규칙 편집기가 나타나요. 여기서는 대상 언어, 카테고리, 항목 길이에 따라 배정을 다르게 할 수 있고, 이름 붙은 규칙 그룹을 여러 개 유지할 수도 있어요. 탭은 마지막으로 사용한 모드를 기억해요. 프로젝트의 배정이 제공업체 하나보다 복잡하면, 어느 모드를 골랐든 항상 편집기가 표시돼요 — 기존 설정이 감춰지는 일은 없어요.

어느 쪽이든 이 탭은 항목이 *어떻게* 배정되는지만 결정해요. 번역 자체는 **번역** 탭이나 **비교** 탭에서 시작해요.

## 배정 규칙

규칙은 **고급** 화면에 있어요. 규칙은 우선순위 순서로 평가되며, 항목과 처음 일치하는 규칙이 적용돼요. 각 규칙은 다음 기준으로 일치시킬 수 있어요.

- **출처** — 가져온 항목의 출처 라벨.
- **항목 길이 제한** — 지정한 글자 수 이하인 항목에만 적용해요.
- **대상 언어**와 **카테고리**.

일치한 항목에는 규칙이 **모듈**(및 선택적인 **모델 재정의**, **추론 강도 재정의**)과 선택적인 프롬프트 힌트(캐릭터, 톤, 성별, 메모)를 지정해요. **규칙 추가**로 규칙을 더하세요. 변경 사항은 만드는 즉시 저장되므로 기억해 둘 **저장** 버튼이 따로 없어요. 이름 붙은 **규칙 그룹**을 여러 개 유지하며 전환할 수 있어요(실행이 진행 중일 때는 전환이 잠겨요).

## 배치 그룹화

배정 탭에도 **배치 그룹화** 컨트롤이 있어요 — 설정 탭에 표시되는 것과 같은 프로젝트 기본값이며, 짝이 되는 **배치 크기 제한 무시** 토글도 있어요. 이 설정은 번역, 심사, 원문 검토 실행 전반에서 관련 항목을 같은 제공업체 요청에 묶어 둬요.

## 번역 시작하기

1. **번역** 탭이나 **비교** 탭에서 항목을 선택하세요.
2. 그곳에서 **번역…** 대화상자를 여세요 — 다시 번역, 메모리, 실행별 그룹화 옵션을 제공한 뒤 실행을 시작해요.
3. 진행 상황, 재시도, 실패는 **활동** 탭에서 지켜보세요.
