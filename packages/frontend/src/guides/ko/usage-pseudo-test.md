# 슈도 테스트

## 개요

**슈도 테스트**는 실제 언어가 아니에요. 원문을 일부러 뒤틀린 형태로 바꾸는 무료 오프라인 QA 언어로, 이를 게임에 불러와서 실제 번역이 하나도 없는 단계부터 어떤 문자열이 인터페이스를 깨뜨리는지 확인할 수 있어요.

비용이 전혀 들지 않고, API 키도 필요 없으며, 어떤 것도 제공업체로 전송하지 않아요.

## 무엇을 만들어 내나

`Save changes`는 `⟦Şàvé çhàñgéş~~~~⟧`처럼 바뀌어요. 세 가지 일이 동시에 일어나며, 각각 서로 다른 종류의 버그를 드러내요.

- **강세 문자.** 모든 글자가 생김새가 비슷한 강세 문자로 바뀌어요. 게임에서 여전히 평범한 영어로 보이는 텍스트가 있다면, 그건 문자열 표로 들어오지 않았다는 뜻이에요 — 하드코딩되어 있어서 어떤 번역가도 손댈 수 없어요.
- **패딩.** 텍스트는 `~` 문자로 늘어나 원래 길이의 약 1.4배가 돼요. 독일어처럼 길어지는 언어를 흉내 낸 거예요. 버튼 밖으로 넘치는 라벨, 줄바꿈이 깨지는 문제, 레이아웃을 밀어내는 문제가 바로 드러나요.
- **괄호.** 결과는 `⟦…⟧`로 감싸져요. 화면에서 어느 쪽 괄호든 빠져 있다면, 그 문자열은 잘려 나가고 있는 거예요.

텍스트 안의 자리 표시자와 마크업 태그는 그대로 손대지 않고 통과해요. 그러니 이 중 하나가 깨진 채로 나온다면, 그건 레이아웃 문제가 아니라 신고할 가치가 있는 버그예요.

## 사용하기

1. **데이터** 탭의 *대상 언어*에서 **슈도 테스트**를 체크하고 저장하세요.
2. 평소처럼 번역을 실행하세요. 슈도 테스트 항목은 항상 내장 슈도 생성기가 처리해요 — 따로 활성화할 것도, 작성할 배정 규칙도, 비용도 없어요. 유료 제공업체가 이 문자열을 보는 일은 절대 없어요.
3. 실제 번역은 안전해요: 슈도 테스트 텍스트는 전용 열에 저장되며 다른 언어를 덮어쓸 수 없어요.

## 게임에 반영하기

내보내기 카드에서 **슈도 텍스트를 내보낼 언어**를 지금 출시하지 않는 언어(예: 독일어)로 설정한 다음, 파일을 내려받아 그 언어를 선택한 상태로 게임에 불러오세요. 선택한 언어의 열은 그 다운로드에서만 슈도 테스트 텍스트로 채워져요. 저장된 데이터는 아무것도 바뀌지 않으며, 다음에 내보낼 때는 실제 번역이 그대로 남아 있어요.

테스트가 끝나면 대체 설정을 다시 **대체 없음**으로 돌려놓고 한 번 더 내보내세요. 일반적인 내보내기에는 슈도 테스트 열이 절대 포함되지 않아요 — 슈도 텍스트가 게임에 닿는 유일한 방법은 위의 대체 기능뿐이에요 — 그러니 슈도 테스트를 켜 둔 채로 두어도 실제로 출시하는 파일에는 영향이 없어요.

## 언제 사용하나

번역을 의뢰하기 전, 이른 단계에서 슈도 테스트를 한 번 돌려 보세요. 여기서 찾은 레이아웃 버그는 각각 한 번만 고치면 되고, 열다섯 개 언어가 도착한 뒤 열다섯 번 고치지 않아도 돼요.
