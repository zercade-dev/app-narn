# Google AI (Gemini) 모듈

## 개요

**Google AI** 모듈은 Google의 Gemini 모델로 번역해요. Google AI Studio API 키가 필요하며, 자격 증명 보관함에 `GOOGLE_API_KEY` 키로 저장해요.

## 자격 증명 보관함에 키 추가

제공업체 자격 증명은 일반 설정이 아니라 암호화된 **자격 증명 보관함**에 저장돼요. 보관함은 세션마다 한 번, 비밀번호로 잠금을 해제해요.

1. 사이드바에서 **글로벌 설정**을 여세요.
2. 아직 보관함을 만들지 않았다면 만드세요: 보관함 비밀번호를 정하고(세션마다 다시 사용해요) 잠금을 해제하세요.
3. **모듈 활성화** 아래에서 **Google AI (Gemini)**를 선택하세요. 필요한 키가 없으면 보관함 편집기가 해당 키를 자동으로 열어요. 그렇지 않으면 **자격 증명 보관함 관리**를 클릭하세요.
4. 보관함 편집기에서 자격 증명을 추가하세요: 키로 `GOOGLE_API_KEY`를 선택하고, 값으로 발급받은 키를 붙여넣은 다음 **보관함 비밀번호**를 입력하고 **저장**을 클릭하세요.

나중에 카드에 *보관함 잠김*이 표시되면, 번역하기 전에 **보관함 잠금 해제**를 클릭하세요.

## 모델 선택

프로젝트의 **설정** 탭에서 Gemini 모델(및 선택적으로 추론 강도)을 고르거나, 글로벌 기본값을 물려받게 두세요. 각 언어를 어떤 모듈이 처리할지는 배정 탭의 **배정 규칙**이 결정해요. 사고(thinking) 모델은 문자 수 대비 토큰 수를 많이 보고하므로, 비용 추정치가 높게 보일 수 있어요.

## Google API 키 발급

1. [ai.google.dev](https://ai.google.dev)에 방문해 **Get API key**를 클릭하거나, [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)로 바로 이동하세요.
2. **Create API key**를 클릭하고 프로젝트를 선택하세요.
3. 생성된 키를 복사하세요.
4. 보관함 편집기의 `GOOGLE_API_KEY` 값 칸에 붙여넣으세요.
