# 카테고리 탭

## 개요

**카테고리**는 관련 있는 문자열을 묶어요(예: UI 라벨, 대사, 아이템 이름). 프로젝트를 정리하고, 문자열 표를 필터링하는 데 도움이 되며 — 무엇보다 **배정 규칙**과 **배치 그룹화**를 움직이므로, 카테고리로 묶인 콘텐츠는 알맞은 모듈로 보내져 맥락에 맞게 함께 번역돼요.

## 카테고리 둘러보기

**카테고리** 탭에는 현재 카테고리와 각각의 항목 수가 나열돼요. 하나를 선택하면 속한 항목을 볼 수 있고, **설명**도 편집할 수 있어요 — 그 카테고리가 무엇을 묶는지 짧게 적는 메모예요.

## 카테고리 지정하기

- **번역** 탭에서 개별 항목에 카테고리를 지정하거나(행을 오른쪽 클릭 → *카테고리 편집*), 여러 행을 선택해 한꺼번에 지정하세요.
- 또는 자동으로 생성하세요(아래 참고).

## AI로 생성하기

**AI로 생성**을 클릭하면 모델이 원문을 읽고 카테고리를 제안한 뒤 항목을 배정해요.

1. **모듈**과 **모델**을 고르세요.
2. 선택적으로 **기존 카테고리에도 항목 배정하기**를 켜세요.
3. **생성**을 클릭하세요 — 백그라운드에서 실행되므로 탭을 떠났다가 돌아와도 괜찮아요.
4. **제안 검토**: 원하지 않는 항목의 체크를 해제한 다음 **선택 항목 적용**을 클릭하세요.

적용하기 전까지는 아무것도 바뀌지 않으므로, AI 제안은 항상 먼저 직접 확인한 뒤 확정할 수 있어요.
