# 번역 탭

## 개요

**번역** 탭은 메인 항목 표예요: 모든 원문 항목이 대상 언어별로 열을 갖고 나열돼요. 항목을 읽고, 편집하고, 필터링하고, 카테고리를 지정하고, 번역할 항목을 **선택**하는 곳이에요. 표는 페이지로 나뉘어요(페이지당 25/50/100/200행).

## 편집하기

번역 셀은 어디든 클릭해서 바로 편집할 수 있고, 확정하면 변경 사항이 저장돼요. 원본 언어 열과 **상태** 열에는 각 항목의 원문과 출처가 카테고리, 용어집, 번역 상태와 함께 표시돼요.

## 필터링하기

툴바로 표를 좁혀 보세요.

- 원문과 번역문 전체에서 **검색**하세요.
- **상태** 필터: 미번역만, LQA 실패만, 길이 초과만, 검토 필요, 원문과 동일, 자리 표시자 불일치.
- **언어**, **출처** 라벨, **카테고리**로 필터링하고, 열을 표시하거나 숨기세요.

## 선택하고 번역하기

체크박스로 행을 선택하세요(또는 필터링된 전체 집합을 선택하세요). 선택한 상태에서는 다음을 할 수 있어요.

- 선택 바에서 **선택 항목 번역**을 실행하세요(배정 규칙이 언어별로 모듈을 골라요).
- 일괄로 **카테고리 추가**나 **카테고리 제거**를 하세요.
- **번역 메모리에 승인** — 현재 번역을 신뢰할 수 있는 것으로 번역 메모리에 기록해요.

## 항목별 카테고리와 용어집

행을 오른쪽 클릭하거나(또는 행의 작업 메뉴로) **카테고리 편집**을 하거나, 해당 항목을 번역할 때 어떤 **용어집**을 활성화할지 고르세요. 카테고리는 **카테고리** 탭에서 일괄 생성할 수도 있어요.
