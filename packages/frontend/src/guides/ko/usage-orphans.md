# 미연결 항목 탭

## 개요

**미연결 항목** 탭은 가장 최근에 가져온 CSV에 더 이상 없는 항목을 나열해요. 보통 다시 가져오기를 하면서 행이 삭제되거나, 이름이 바뀌거나, 원문이 바뀌었을 때 나타나요 — 기존 번역은 작업을 잃지 않도록 여기 보관돼요.

## 할 수 있는 일

- **삭제**로 미연결 항목의 레코드와 번역을 영구적으로 제거하세요(되돌릴 수 없어요).
- **재연결**로 미연결 항목의 번역을 다른 항목으로 옮기세요. 원문으로 대상을 검색하세요. 대상에 이미 있는 번역은 그대로 유지되고, 비어 있는 언어만 채워져요.
- 여러 미연결 항목을 선택해 일괄 **선택 항목 삭제**를 하거나, **새로 고침**으로 목록을 갱신하세요.

## 작업 흐름

1. **데이터** 탭에서 원문 CSV를 다시 가져오세요.
2. **미연결 항목**을 열어 무엇이 빠졌는지 확인하세요.
3. ID나 원문이 바뀌었지만 번역은 여전히 유효한 항목은 **재연결**하세요.
4. 정말로 사라진 항목은 **삭제**하세요.

목록이 비어 있으면 가져온 모든 항목이 현재 프로젝트와 일치한다는 뜻이에요 — 미연결 항목이 없어요.
