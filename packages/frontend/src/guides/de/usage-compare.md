# Tab Vergleich

## Übersicht

Der Tab **Vergleich** ist ein fokussierter Arbeitsbereich für jeweils eine Sprache, zum Prüfen und Vervollständigen von Übersetzungen. Er zeigt **Quelltext**, eine optionale **Referenz**-Sprache und die **Ziel**-Sprache nebeneinander — nützlich, um gegen eine bereits vertraute Sprache zu übersetzen statt nur gegen den Quelltext.

## Die Ansicht einrichten

* Die **Ziel**-Sprache wählen, an der gearbeitet wird.
* Optional eine **Referenz**-Sprache als zusätzliche Spalte anzeigen und als Übersetzungskontext nutzen.
* **Suchen** und filtern: nur unübersetzte Einträge, **LQA**-Beanstandungen oder **Zu prüfen**.

## An Übersetzungen arbeiten

* Jede Zielzelle lässt sich inline bearbeiten; nach dem Speichern wird **Rückgängig** angeboten.
* Eine einzelne Zeile bei Bedarf **neu übersetzen**.
* **+ Kontext** hängt einem Eintrag Übersetzerkontext an (Figur, Tonfall, situative Hinweise), den Module bei der nächsten Übersetzung erhalten.

## In Bulk übersetzen

Auf **Übersetzen…** klicken, um den Dialog für Batch-Übersetzung für die aktuelle Ansicht zu öffnen:

* Die **ausgewählten** Einträge oder **alle** Einträge in der aktuellen Ansicht übersetzen.
* **Nur unübersetzte Einträge füllen** oder vorhandene **neu übersetzen**.
* **Referenzsprache als Kontext verwenden**, wenn eine ausgewählt ist.
* **Batch-Gruppierung** für den Durchlauf festlegen und optional **Translation Memory für diesen Durchlauf deaktivieren**, damit jeder Eintrag frisch übersetzt wird.

## Review-Hilfsmittel

Mit **Alle als zu prüfen markieren** oder **Alle als geprüft markieren** die gesamte aktuelle Ansicht auf einmal durch den eigenen Review-Workflow bewegen.
