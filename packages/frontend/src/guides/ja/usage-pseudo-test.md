# 疑似テスト

## 概要

**疑似テスト**は実在の言語ではありません。原文をわざと崩した形に書き換える、無料のオフラインQA用の言語で、これをゲームに読み込ませることで、実際の翻訳が1つもない段階から、どの文字列がインターフェースを壊すかを確認できます。

費用はかからず、APIキーも不要で、プロバイダーに何かを送信することもありません。

## 何が生成されるか

`Save changes`は`⟦Şàvé çhàñgéş~~~~⟧`のような形になります。同時に3つのことが起きており、それぞれ異なる種類のバグをあぶり出します。

* **アクセント記号付きの文字。** すべての文字が、見た目の似たアクセント付きの文字に置き換わります。ゲーム内でそれでも通常の英語のまま表示されているテキストは、文字列テーブルに取り込まれていません — ハードコードされており、どの翻訳者もそこには手が届きません。
* **パディング。** テキストは`~`の文字で元の長さの約1.4倍に引き伸ばされ、ドイツ語のように長くなる言語を疑似的に再現します。ボタンからはみ出すラベル、崩れた折り返し、レイアウトを押し広げる問題はすぐに見つかります。
* **括弧。** 結果全体は`⟦…⟧`で囲まれます。画面上でどちらかの括弧が欠けていたら、その文字列は途中で切れています。

テキスト内のプレースホルダーやマークアップタグはそのまま変更されずに通過します。そのため、これらのいずれかが崩れて出てきた場合は、レイアウトの問題ではなく報告する価値のあるバグです。

## 使い方

1. **データ**タブの*ターゲット言語*で**疑似テスト**にチェックを入れ、保存します。
2. 通常どおり翻訳を実行します。疑似テストのエントリは、常に内蔵の疑似生成機能で処理されます — 有効化するものも、書くべき振り分けルールもなく、費用もかかりません。有料のプロバイダーがこれらの文字列を目にすることはありません。
3. 本物の翻訳は安全です：疑似テストのテキストは専用の列に保存され、他の言語を上書きすることはありません。

## ゲームへの取り込み

エクスポートのカードで、**疑似テキストの出力先**を、現在出荷していない言語（例えばドイツ語）に設定し、ファイルをダウンロードして、その言語を選んだ状態でゲームに読み込ませます。選んだ言語の列は、そのダウンロード限りで疑似テストのテキストで埋められます。保存されているデータは何も変わらず、次にエクスポートするときには本物の翻訳がそのまま残っています。

テストが終わったら、置き換えを**置き換えなし**に戻して、もう一度エクスポートします。通常のエクスポートに疑似テストの列が含まれることはありません — 疑似テストのテキストがゲームに届くのは、上記の置き換えを使った場合だけです — そのため、疑似テストを有効にしたままにしていても、出荷するファイルには影響しません。

## 使うタイミング

疑似テストは、翻訳を発注する前の早い段階で実行してください。ここで見つかるレイアウトのバグはどれも、15の言語が届いた後に15回直す代わりに、一度直すだけで済みます。
