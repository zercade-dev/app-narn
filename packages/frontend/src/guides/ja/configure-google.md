# Google AI (Gemini)モジュール

## 概要

**Google AI**モジュールは、GoogleのGeminiモデルで翻訳します。Google AI StudioのAPIキーが必要で、認証情報の保管庫にキー`GOOGLE_API_KEY`として保存します。

## 認証情報の保管庫にキーを追加

プロバイダーの認証情報は、プレーンな設定ファイルではなく、暗号化された**認証情報の保管庫**に保存されます。保管庫はセッションごとに一度、パスワードでロックを解除します。

1. サイドバーから**グローバル設定**を開いてください。
2. 保管庫をまだ設定していない場合は作成してください。保管庫のパスワードを決めて（セッションごとに再利用します）、ロックを解除してください。
3. **モジュールを有効化**の下で**Google AI (Gemini)**を選択してください。必要なキーが未設定の場合、保管庫エディターが該当のキーを自動的に開きます。それ以外の場合は**認証情報の保管庫の管理**をクリックしてください。
4. 保管庫エディターで認証情報を追加してください。キー`GOOGLE_API_KEY`を選び、値として取得したキーを貼り付け、**保管庫のパスワード**を入力して**保存**をクリックしてください。

あとでカードに*保管庫がロックされています*と表示された場合は、翻訳する前に**保管庫のロックを解除**をクリックしてください。

## モデルの選択

プロジェクトの**設定**タブで、Geminiのモデル（および任意で推論の強度）を選択するか、グローバルの既定値を継承してください。どのモジュールが各言語を処理するかは、振り分けタブの**振り分けルール**が決めます。思考モデルは文字数に対してトークン数が大きく報告されるため、費用の見積もりが高く見えることがあります。

## Google APIキーの取得

1. [ai.google.dev](https://ai.google.dev)にアクセスして**Get API key**をクリックするか、直接[aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)にアクセスしてください。
2. **Create API key**をクリックし、プロジェクトを選択してください。
3. 生成されたキーをコピーしてください。
4. 保管庫エディターの`GOOGLE_API_KEY`の値欄に貼り付けてください。
