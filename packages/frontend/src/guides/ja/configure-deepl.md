# DeepLモジュール

## 概要

**DeepL**モジュールは、プロ品質のニューラル機械翻訳を提供します。LLMモジュールと違い、これは古典的なMTであり、用語の一貫性のためにプロジェクトの用語集をDeepLに送信できます。キーは認証情報の保管庫に`DEEPL_API_KEY`として保存します。

## 認証情報の保管庫にキーを追加

プロバイダーの認証情報は、プレーンな設定ファイルではなく、暗号化された**認証情報の保管庫**に保存されます。保管庫はセッションごとに一度、パスワードでロックを解除します。

1. サイドバーから**グローバル設定**を開いてください。
2. 保管庫をまだ設定していない場合は作成してください。保管庫のパスワードを決めて（セッションごとに再利用します）、ロックを解除してください。
3. **モジュールを有効化**の下で**DeepL**を選択してください。必要なキーが未設定の場合、保管庫エディターが該当のキーを自動的に開きます。それ以外の場合は**認証情報の保管庫の管理**をクリックしてください。
4. 保管庫エディターで認証情報を追加してください。キー`DEEPL_API_KEY`を選び、値として認証キーを貼り付け、**保管庫のパスワード**を入力して**保存**をクリックしてください。

DeepLは名前付きインスタンスに対応していません — DeepLモジュールは1つだけです。

## 用語集の利用

DeepLは翻訳時に用語集を適用できます。**用語集**タブで用語を作成し、**DeepLに送信**でアップロードしてください。用語集を送信後に変更すると、タブに*再送信が必要*と表示されます — もう一度送信してDeepL側を更新してください。

## DeepL APIキーの取得

1. [deepl.com/account](https://www.deepl.com/account)にアクセスしてください。
2. FreeまたはProのAPIアカウントに登録してください。
3. **Account Settings**を開き、**API Key**セクションを見つけてください。
4. 認証キーをコピーしてください。
5. 保管庫エディターの`DEEPL_API_KEY`の値欄に貼り付けてください。
