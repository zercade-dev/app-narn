# 翻訳メモリ

## 概要

**翻訳メモリ**（TM）は、ワークスペース全体で共有される、既知の翻訳のストアです。ある文字列の原文が、すでにメモリにあるものと一致すると、有料のモジュールを呼び出す代わりに、保存済みの翻訳が自動的に再利用されます — これにより時間と費用を節約し、同一のテキストをプロジェクト横断で一貫させられます。サイドバーから**翻訳メモリ**を開くと、保存済みのセグメントを閲覧・検索できます。

> **翻訳メモリは既定でどのプロジェクトでも無効**です。無効な間は、プロジェクトが翻訳した内容がメモリに書き込まれることも、保存済みの翻訳が自動適用されることもありません。有効にするには、プロジェクトの**設定**タブを開き、**翻訳メモリ**セクションで再利用ポリシーを選んでください（*無効*以外の値を選びます）。

## メモリへの登録方法

* **承認して翻訳メモリに追加** — **翻訳**タブで翻訳を選択して承認すると、信頼できるセグメントとして記録されます。
* 完了した翻訳も記録され、同一の原文が後で再利用できるようになります。

## 再利用ポリシー

再利用ポリシー（プロジェクトの**設定**タブの**翻訳メモリ**セクション）は、同一の原文に対して保存済みの翻訳を再利用する*かどうか*と*いつ*するかを制御します。既定は**無効**（TMオフ）です。他の選択肢 — 例えば、周囲のコンテキストも一致した場合にのみ再利用する**厳格（コンテキストの完全一致）** — を選ぶと有効になります。ポリシーを厳しくすると、ある場所では正しかったが別の場所では正しくない翻訳を再利用してしまうことを避けられます。

## 実行ごとの再利用の制御

**比較**タブの*翻訳…*ダイアログから翻訳を開始すると、メモリから埋められるエントリの件数が通知され、**この実行では翻訳メモリを使用しない**を選んで、すべてのエントリを強制的に新規翻訳させることもできます — 以前メモリに記憶されたテキストを、モデルに改めて考え直させたいときに便利です。
