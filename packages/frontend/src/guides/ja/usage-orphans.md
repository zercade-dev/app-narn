# 孤立エントリタブ

## 概要

**孤立エントリ**タブには、直近でインポートしたCSVに存在しなくなったエントリが一覧表示されます。通常は、再インポートで行が削除・リネームされたり、原文が変更されたりした後に現れます — それまでの翻訳はここに保持されるため、作業が失われることはありません。

## できること

* 孤立エントリを**削除**すると、そのレコードと翻訳が完全に削除されます（この操作は取り消せません）。
* 孤立エントリを**再リンク**すると、その翻訳を別のエントリに移せます。原文でターゲットを検索します。ターゲットに既存の翻訳がある場合はそのまま残り、空の言語だけが埋められます。
* 複数の孤立エントリを選択して**選択範囲を削除**でまとめて削除するか、**更新**で一覧を最新の状態にします。

## 作業の流れ

1. **設定**タブから、原文のCSVを再インポートします。
2. **孤立エントリ**を開き、除外された内容を確認します。
3. IDや原文が変わったものの、翻訳がまだ有効なエントリは**再リンク**します。
4. 本当になくなったエントリは**削除**します。

一覧が空であれば、インポートしたすべてのエントリが現在のプロジェクトと一致しています — 孤立しているものはありません。
