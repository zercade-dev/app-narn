# AIレビュー

## 概要

自動のLQAチェックに加えて、このアプリはAIモデルでコンテンツをレビューすることもできます。AIレビューには2つのタブと、手動のレビューキューがあります。AIレビューを行うには、**グローバル設定**でLLMモジュールを有効にし、認証情報の保管庫のロックを解除しておく必要があります。

## 翻訳AIレビュー

**翻訳AIレビュー**タブでは、AIの判定によって、完了した翻訳を**正確さ・流暢さ・用語・トーン**の観点で採点します。

* **前回の実行をレビュー**をクリックすると、最後に完了した翻訳の実行を評価します（または**アクティビティ**タブから、特定の実行を指定してレビューを開始できます）。
* 指摘された結果を順に確認します。各判定には、原文・翻訳・**スコア**、そして多くの場合**提案**が表示されます。
* 提案を**適用**すると翻訳を置き換えます。**すべての提案を適用**を使うと、一括ですべて適用できます。提案を適用するとタグ・プレースホルダー・改行が失われる場合は、警告が表示されます。

## 原文AIレビュー

**原文AIレビュー**タブは**原文そのもの**をチェックします — 結果は報告のみで、翻訳が変更されることはありません。

1. 実行するチェックを選びます：**誤字**・**文法**・**用語**・**明確さ**・**不適切な表現**。
2. **モジュール**と**モデル**を選び、任意で指摘を書く**回答の言語**を選びます。
3. **レビューを開始**をクリックします。バックグラウンドで実行されるため、進捗は**アクティビティ**タブで確認できます。
4. 各指摘を確認し、**承認**または**無視**します。提案された原文の書き換えはコピーできます。

## 手動レビュー

**手動レビュー**タブは、人によるレビューのキューです。**要レビュー**（または**保留**）とマークされた翻訳がここに表示され、**承認**・**編集**・**保留にする**・**再翻訳**、または参考として**原文への逆翻訳**をリクエストできます。キーボードショートカットで操作を速くできます：`↑`／`↓`で移動、`a`で承認、`e`で編集。
