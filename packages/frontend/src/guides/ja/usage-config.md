# 設定タブ

## 概要

**設定**タブには、選択したプロジェクトの翻訳ポリシーがまとまっています：モジュールごとのモデル選択、翻訳メモリの再利用、バッチのグループ化、品質（LQA）チェック、プロジェクトの管理です。**言語**と**CSVのインポート／エクスポート**は、別の**データ**タブに移動しました。プロバイダーの認証情報はここでは設定しません — **認証情報の保管庫**で管理します（*モジュールの設定*ガイドと**グローバル設定**を参照してください）。

## 言語（データタブ）

**データ**タブで、**ソース言語**と、翻訳先となる**ターゲット言語**を設定します。有効なターゲット言語の組み合わせは他のすべてのタブに影響します — エントリの列、振り分けルール、品質チェックはすべてこれに従います。

## CSVのインポートとエクスポート（データタブ）

CSVのインポートとエクスポートも**データ**タブにあります。

* **CSVをインポート**で、原文のエントリと既存の翻訳を読み込みます。インポートの直前には安全のためのスナップショットが自動で取得されるため、**バックアップ**タブからロールバックできます。
* 正しく解析できない行（引用符の直後にカンマが続く行）は、列がずれたデータとして書き込まれる代わりに、破棄されて報告されます。
* **CSVをエクスポート**でプロジェクトをダウンロードします。言語や、翻訳者コンテキストの列を含めるかどうかを選べます。

## モジュールとモデル

プロバイダーの有効化は**グローバル設定**で一度だけ行います。この設定タブでは、有効にした各モジュールについて、プロジェクトごとに**モデル**と**推論の強度**を選びます — 何も選ばなければ*グローバル設定を継承*のままになります。あるエントリに実際にどのモジュールが使われるかは、**振り分けルール**が決めます（*振り分け*ガイドを参照してください）。

## LQAチェック

**LQAチェック**パネルでは、すべての翻訳に対して実行される品質ゲートを設定します：個々のチェック（インラインタグの一致、長さ制限、オーバーフロー、用語集の遵守、禁止用語、正規表現アサーションなど）を切り替え、それぞれを**ブロッキング**または**警告**に設定します。ブロッキングの問題はゲートを通過できず、1回の自動再試行のきっかけになります。警告は報告のみです。

## バッチのグループ化

**バッチのグループ化**は、関連するエントリ（カテゴリや用語集単位）を同じリクエストにまとめ、モデルが文脈をそろえて参照できるようにします。プロジェクトの既定値を設定でき、実行ごとに上書きすることもできます。

## プロジェクトの管理

**危険な操作**では、**プロジェクトを複製**（設定とエントリのみで、認証情報などの秘密情報は複製されません）したり、**プロジェクトを削除**して完全に削除したりできます。
