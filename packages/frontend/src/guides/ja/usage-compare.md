# 比較タブ

## 概要

**比較**タブは、一度に1つの言語に集中して翻訳のレビューや入力を行うためのワークスペースです。**原文**、任意の**参照**言語、**ターゲット**言語を並べて表示します — 原文だけでなく、すでに信頼できる言語と見比べながら翻訳したいときに役立ちます。

## ビューの設定

* 作業する**ターゲット**言語を選びます。
* 任意で**参照**言語を選ぶと、追加の列として表示され、翻訳のコンテキストとしても使われます。
* **検索**と絞り込み：未翻訳のみ、**LQA**の問題、**要レビュー**。

## 翻訳の作業

* ターゲットのセルはインラインで編集できます。保存後は**元に戻す**を選べます。
* 必要に応じて、1行だけ**再翻訳**します。
* **+コンテキスト**で、エントリに翻訳者コンテキスト（キャラクター、トーン、場面のメモなど）を付加できます。次回の翻訳でモジュールに渡されます。

## 一括翻訳

**翻訳…**をクリックすると、現在のビューの一括翻訳ダイアログが開きます。

* 現在のビューで**選択した**エントリ、または**すべての**エントリを翻訳します。
* **未翻訳のエントリのみ埋める**か、既存の翻訳を**再翻訳する**かを選べます。
* 参照言語を選択している場合は、**参照言語をコンテキストとして使用する**を選べます。
* この実行の**バッチのグループ化**を設定し、任意で**この実行では翻訳メモリを使用しない**を選んで、すべてのエントリを新規に翻訳させることもできます。

## レビューの補助機能

**すべてを要レビューにする**または**すべてをレビュー済みにする**を使うと、現在のビュー全体をまとめてレビューの工程に進められます。
