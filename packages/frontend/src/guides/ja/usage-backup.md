# バックアップタブ

## 概要

**バックアップ**タブは、プロジェクト（設定・エントリ・用語集）を検証可能な`.zip`アーカイブにまとめます。すべてのファイルにチェックサムが付き、復元時にはファイルを書き込む前にチェックサムを検証します。

## バックアップの作成

1. プロジェクトを選択してください。
2. **バックアップ**タブを開いてください。
3. **バックアップを作成**をクリックしてください。
4. 新しいアーカイブが**保存済みのバックアップ**に表示され、そこから**ダウンロード**できます。

## 自動バックアップ

このアプリは、安全のためのスナップショットも自動で取得し、手動のバックアップと並べて一覧に表示します。

* **CSVインポート前** — インポート直前の復元ポイントです。
* **再翻訳前** — エントリが上書きされる直前の復元ポイントです。

グローバル設定の**プロジェクトごとの最大バックアップ数**（既定10）を超えると、古いバックアップから削除されます。

## 復元

1. **バックアップからの復元**で`.zip`を選択するか、保存済みのバックアップから1つを選びます。
2. アプリがチェックサムを検証し、プレビュー（プロジェクト・ファイル・作成日時）を表示します。
3. **はい、復元**をクリックします。復元すると、プロジェクトの現在の設定・エントリ・用語集が上書きされます — この操作は取り消せないため、迷ったら先に新しいバックアップを作成してください。

## 削除

保存済みのバックアップで**削除**を使うと、そのアーカイブをサーバーから完全に削除します。
