# アクティビティタブ

## 概要

**アクティビティ**タブは、バックグラウンドで実行されるジョブの管理センターです。時間のかかる処理はすべてここに表示されます — **翻訳**の実行、**AIレビュー**（翻訳・原文）、**用語集の生成**、**カテゴリの生成**です。実行はプロジェクトごとにキューに入り、順番に処理されるため、複数を並べておいて、順に処理されていく様子を確認できます。

## 実行の確認

各実行には、**種類**、**状態**（待機中・実行中・一時停止中・完了・失敗・キャンセル済み）、進捗、概算の**費用**が表示されます。費用は、各モデルの100万トークンあたりの価格から算出した、モジュール側の見積もりです。そのため、思考モデルでは文字数に対してトークンの合計が大きく表示されることがあります。**詳細を表示**を使うと、その実行が何を翻訳したか、再試行の有無、文字数・トークンの使用量を確認できます。実行のIDは、参照用にコピーできます。

## キューの管理

* 実行を**一時停止**／**再開**するか、**今すぐ開始**で待機中の実行を先に進めます。
* **キューで上に移動**／**キューで下に移動**でキューの順序を変更します。
* 待機中または進行中の実行は、**実行をキャンセル**で中止できます。

## 復旧とレビュー

* 一部の文字列が失敗した場合、**失敗した項目を再試行**で、それらだけを再実行します。
* 完了した翻訳の実行からは、その場で**AIレビュー**を開始できます — モジュールとモデルを選択します（既定では翻訳に使用したものです）。判定は**翻訳AIレビュー**タブで確認できます。
