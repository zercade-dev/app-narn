# 翻訳タブ

## 概要

**翻訳**タブは、メインのエントリ一覧です：すべての原文エントリが、ターゲット言語ごとの列とともに並びます。ここで、エントリの閲覧・編集・絞り込み・カテゴリ分けや、翻訳する対象の**選択**を行います。テーブルはページ分割されています（1ページあたり25／50／100／200行）。

## 編集

翻訳のセルをクリックすると、インラインで編集できます。変更は確定すると保存されます。**ソース**列と**状態**列には、各エントリの原文と出どころが、カテゴリ・用語集・翻訳の状態とともに表示されます。

## 絞り込み

ツールバーを使ってテーブルを絞り込めます。

* 原文と翻訳したテキストを横断して**検索**します。
* **状態**での絞り込み：未翻訳のみ、LQA不合格のみ、オーバーフローのみ、要レビュー、原文と同一、プレースホルダーの不一致。
* **言語**、**ソース**ラベル、**カテゴリ**で絞り込んだり、列の表示・非表示を切り替えたりできます。

## 選択と翻訳

チェックボックスで行を選択します（または絞り込んだ結果全体を選択できます）。選択すると、次のことができます。

* 選択バーから**選択範囲を翻訳**を実行します（各言語のモジュールは振り分けルールが選びます）。
* まとめて**カテゴリを追加**または**削除**します。
* **承認して翻訳メモリに追加** — 現在の翻訳を、信頼できるものとして翻訳メモリに記録します。

## エントリごとのカテゴリと用語集

行を右クリックする（または操作メニューを使う）と、**カテゴリを編集**したり、そのエントリの翻訳時にどの**用語集**を有効にするかを選べたりします。カテゴリは**カテゴリ**タブからまとめて生成することもできます。
