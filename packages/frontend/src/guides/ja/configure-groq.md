# Groqモジュール

## 概要

**Groq**モジュールは、[Groq](https://groq.com)で翻訳します — Llama・Qwen・GPT-OSSなどのオープンモデル向けの高速推論で、日常的な翻訳作業に適した無料枠があります。Groq APIキーが必要で、認証情報の保管庫にキー`GROQ_API_KEY`として保存します。

## 認証情報の保管庫にキーを追加

プロバイダーの認証情報は、プレーンな設定ファイルではなく、暗号化された**認証情報の保管庫**に保存されます。保管庫はセッションごとに一度、パスワードでロックを解除します。

1. サイドバーから**グローバル設定**を開いてください。
2. 保管庫をまだ設定していない場合は作成してください。保管庫のパスワードを決めて（セッションごとに再利用します）、ロックを解除してください。
3. **モジュールを有効化**の下で**Groq**を選択してください。必要なキーが未設定の場合、保管庫エディターが該当のキーを自動的に開きます。それ以外の場合は**認証情報の保管庫の管理**をクリックしてください。
4. 保管庫エディターで認証情報を追加してください。キー`GROQ_API_KEY`を選び、値として取得したキーを貼り付け、**保管庫のパスワード**を入力して**保存**をクリックしてください。

あとでカードに*保管庫がロックされています*と表示された場合は、翻訳する前に**保管庫のロックを解除**をクリックしてください。

## モデルの選択

プロジェクトの**設定**タブで、Groqの最新のカタログからモデルを選択するか、グローバルの既定を継承してください。`llama-3.3-70b-versatile`は翻訳品質の面で堅実な既定モデルです。`llama-3.1-8b-instant`のような小型モデルは、品質を多少犠牲にして速度を優先します。どのモジュールが各言語を処理するかは、振り分けタブの**振り分けルール**が決めます。

## Groq APIキーの取得

1. [console.groq.com](https://console.groq.com)にアクセスしてください。
2. サインアップまたはログインしてください。
3. コンソールメニューから**API Keys**を開いてください。
4. 新しいAPIキーを作成してコピーしてください — `gsk_`で始まります。
5. 保管庫エディターの`GROQ_API_KEY`の値欄に貼り付けてください。

Groqの無料枠はモデルごとに1日あたりの上限を設けています（具体的な数値はここには記載していません — 最新の上限はコンソールで確認してください）。また、Groqの規約により、APIデータはモデルの学習に使用されません。キーを追加すると、**NARN Freeway**は接続済みの各プロバイダーの無料枠に翻訳作業を振り分ける際、Groqの無料プランを自動的に組み込みます — 追加の設定は不要です。
