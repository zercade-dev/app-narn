# NARNについて

**NARN**は**Not A Relevant Name**（重要ではない名前）の略です。

この名前はあえて意味を持たないプレースホルダーです — 大事なのはブランド名ではなく、ツールそのものです。NARNはAIを活用したローカライズ作業用のワークスペースで、文字列をインポートし、選んだ翻訳プロバイダーに振り分け、結果をレビュー・採点し、プロジェクトをまたいで翻訳メモリを保持します。

## 何のために作られたか

NARNは**Miliastra Wonderland**の制作者（Craftspeople）向けに作られています。ゲームが出力するCSV — 一般的な表計算ソフトのインポート機能では崩れてしまう、ゲーム独自の非標準的な引用符処理を含めて — を読み込み、ゲームのキャラクター・元素・反応・ステータス・国家・階級、そしてMiliastra独自の語彙をカバーする読み取り専用の用語集を12件（14言語、332語）同梱しています。これにより、どのプロバイダーで翻訳しても、実行のたびに新しい訳語を作ってしまうことなく、ゲームと同じ言葉でこれらの用語を訳せます。

だからといって縛られるわけではありません。どんなテキストのCSVでもインポートでき、すべての機能を同じように使えます。Miliastraは、NARNが想定しているワークフローの一例にすぎません。

NARNは独立したファンメイドのツールであり、HoYoverse / COGNOSPHERE PTE. LTD.とは提携・公認関係にありません。同梱の用語集も非公式な、ファンによる用語集作成の補助資料です。

そのため、タイトルバーやログインページなどで「NARN」の文字を見かけたら、それは**Not A Relevant Name**（重要ではない名前）です。これで謎が解けました。
