# GitHub Copilotモジュール

## 概要

**Copilot**モジュールは、GitHub Copilotを通じて翻訳します。**Copilotサブスクリプションが有効な**アカウントのGitHubトークンで認証し、認証情報の保管庫にキー`GITHUB_TOKEN`として保存します。

## 認証情報の保管庫にトークンを追加

プロバイダーの認証情報は、プレーンな設定ファイルではなく、暗号化された**認証情報の保管庫**に保存されます。保管庫はセッションごとに一度、パスワードでロックを解除します。

1. サイドバーから**グローバル設定**を開いてください。
2. 保管庫をまだ設定していない場合は作成してください。保管庫のパスワードを決めて（セッションごとに再利用します）、ロックを解除してください。
3. **モジュールを有効化**の下で**GitHub Copilot**を選択してください。必要なキーが未設定の場合、保管庫エディターが該当のキーを自動的に開きます。それ以外の場合は**認証情報の保管庫の管理**をクリックしてください。
4. 保管庫エディターで認証情報を追加してください。キー`GITHUB_TOKEN`を選び、値として取得したトークンを貼り付け、**保管庫のパスワード**を入力して**保存**をクリックしてください。

モデルの一覧に*No models available*と表示された場合は、トークンが未設定か無効であるか、保管庫がロックされています。保管庫のロックを解除するか、GitHubトークンを確認してから、カードを開き直してください。

## GitHubトークンの取得

Copilotへのアクセスだけを許可する**きめ細かい（fine-grained）**個人アクセストークンを使用してください。

1. [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens)にアクセスしてください。
2. **Generate new token**をクリックしてください（きめ細かいトークンが既定です）。
3. 名前を付けて（例：「Translator-Copilot」）、**Expiration**（有効期限）を設定してください。
4. **Permissions → Account permissions**の下にある**Copilot Requests**を見つけ、**Read-only**に設定してください。他の権限は不要です。
5. **Generate token**をクリックし、すぐにコピーしてください — GitHubはこのトークンを一度しか表示しません。
6. 保管庫エディターの`GITHUB_TOKEN`の値欄に貼り付けてください。

トークンの持ち主のアカウントに、有効なCopilotサブスクリプションがなければ翻訳は成功しません。
