# カテゴリタブ

## 概要

**カテゴリ**は、関連する文字列（UIラベル、会話文、アイテム名など）をまとめるものです。プロジェクトの整理や文字列テーブルの絞り込みに役立つだけでなく — 重要な点として —**振り分けルール**と**バッチのグループ化**の判断材料にもなり、カテゴリ分けされたコンテンツを適切なモジュールに送り、文脈をそろえてまとめて翻訳できるようになります。

## カテゴリの一覧

**カテゴリ**タブには、現在のカテゴリがエントリ数とともに一覧表示されます。1つを選択すると、そのエントリを確認したり、**説明**（そのカテゴリがまとめる内容についての短いメモ）を編集したりできます。

## カテゴリの割り当て

* **翻訳**タブから、個々のエントリにカテゴリを割り当てられます（行を右クリック→*カテゴリを編集*）。行を選択すれば、まとめて割り当てることもできます。
* または、以下の方法で自動生成します。

## AIで生成

**AIで生成**をクリックすると、モデルが原文の文字列を読み取り、カテゴリを提案してエントリに割り当てます。

1. **モジュール**と**モデル**を選びます。
2. 任意で、**既存の**カテゴリにもエントリを割り当てさせることができます。
3. **生成**をクリックします — バックグラウンドで実行されるため、タブを離れてもあとで戻ってこられます。
4. **提案をレビュー**：不要なものはチェックを外し、**選択した提案を適用**をクリックします。

適用するまでは何も変更されないため、AIの提案は必ず自分で確認してから反映できます。
