# แท็บหมวดหมู่

## ภาพรวม

**หมวดหมู่**จัดกลุ่มข้อความที่เกี่ยวข้องกัน (เช่น ป้ายกำกับ UI บทสนทนา ชื่อไอเทม) ช่วยจัดระเบียบโปรเจกต์ กรองตารางข้อความ และ — ที่สำคัญ — ขับเคลื่อน**กฎการจ่ายงาน**และ**การจัดกลุ่มแบตช์** ทำให้เนื้อหาที่จัดหมวดหมู่แล้วถูกส่งไปยังโมดูลที่ถูกต้องและแปลรวมกันโดยมีบริบท

## เรียกดูหมวดหมู่

แท็บ **หมวดหมู่** แสดงรายการหมวดหมู่ปัจจุบันของคุณพร้อมจำนวนรายการแต่ละหมวด เลือกหมวดหมู่หนึ่งเพื่อดูรายการในนั้นและแก้ไข**คำอธิบาย** — ข้อความสั้น ๆ อธิบายว่าหมวดหมู่นี้รวมอะไรไว้

## กำหนดหมวดหมู่

* กำหนดหมวดหมู่ให้รายการทีละรายการได้จากแท็บ **คำแปล** (คลิกขวาที่แถว → *แก้ไขหมวดหมู่*) หรือกำหนดเป็นชุดโดยเลือกหลายแถวที่นั่น
* หรือให้ระบบสร้างให้อัตโนมัติ (ดูด้านล่าง)

## สร้างด้วย AI

คลิก **สร้างด้วย AI** เพื่อให้โมเดลอ่านข้อความต้นฉบับของคุณ เสนอหมวดหมู่ และกำหนดรายการเข้าหมวดหมู่เหล่านั้น

1. เลือก**โมดูล**และ**โมเดล**
2. เลือกได้ตามต้องการว่าจะให้กำหนดรายการเข้าหมวดหมู่**ที่มีอยู่แล้ว**ด้วยหรือไม่
3. คลิก **สร้าง** — งานจะรันอยู่เบื้องหลัง คุณจึงออกจากแท็บนี้แล้วกลับมาทีหลังได้
4. **ตรวจทานข้อเสนอแนะ**: ยกเลิกการเลือกรายการที่คุณไม่ต้องการ แล้ว **นำรายการที่เลือกไปใช้**

ไม่มีอะไรเปลี่ยนแปลงจนกว่าคุณจะนำไปใช้ ข้อเสนอแนะของ AI จึงเป็นสิ่งที่คุณยืนยันเองเสมอ
