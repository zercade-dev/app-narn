# โมดูล DeepSeek

## ภาพรวม

โมดูล **DeepSeek** แปลด้วย DeepSeek API ต้องใช้ API key ของ DeepSeek ซึ่งจัดเก็บไว้ในตู้นิรภัยข้อมูลรับรองภายใต้คีย์ `DEEPSEEK_API_KEY`

## เพิ่มคีย์ของคุณลงในตู้นิรภัยข้อมูลรับรอง

ข้อมูลรับรองของผู้ให้บริการจะถูกเก็บไว้ใน **ตู้นิรภัยข้อมูลรับรอง** ที่เข้ารหัสไว้ ไม่ใช่ในไฟล์ตั้งค่าธรรมดา คุณปลดล็อกตู้นิรภัยครั้งเดียวต่อเซสชันด้วยรหัสผ่าน

1. เปิด **การตั้งค่าส่วนกลาง** จากแถบด้านข้าง
2. หากยังไม่ได้ตั้งค่าตู้นิรภัย ให้สร้างขึ้นก่อน: ตั้งรหัสผ่านตู้นิรภัย (คุณจะใช้รหัสผ่านนี้ซ้ำทุกเซสชัน) แล้วปลดล็อก
3. ใต้ **เปิดใช้งานโมดูล** เลือก **DeepSeek** เมื่อคีย์ที่จำเป็นยังไม่มี ตัวแก้ไขตู้นิรภัยจะเปิดที่คีย์ที่ถูกต้องให้อัตโนมัติ — หากไม่เป็นเช่นนั้น ให้คลิก **การจัดการตู้นิรภัยข้อมูลรับรอง**
4. ในตัวแก้ไขตู้นิรภัย เพิ่มข้อมูลรับรอง: เลือกคีย์ `DEEPSEEK_API_KEY` วางคีย์ของคุณเป็นค่า ป้อน **รหัสผ่านตู้นิรภัย** ของคุณ แล้วคลิก **บันทึก**

หากภายหลังการ์ดแสดงว่า *ตู้นิรภัยถูกล็อก* ให้คลิก **ปลดล็อกตู้นิรภัย** ก่อนแปล

## เลือกโมเดล

ในแท็บ **ตั้งค่าโปรเจกต์** ของโปรเจกต์ เลือกโมเดล DeepSeek (และระดับการให้เหตุผลตามต้องการ) หรือสืบทอดค่าเริ่มต้นส่วนกลาง **กฎการจ่ายงาน** ในแท็บการจ่ายงานเป็นตัวตัดสินว่าโมดูลใดดูแลภาษาใด

## รับ API key ของ DeepSeek

1. ไปที่ [platform.deepseek.com](https://platform.deepseek.com)
2. สมัครสมาชิกหรือเข้าสู่ระบบ
3. เปิดส่วน **API keys** ของคุณ
4. สร้าง API key ใหม่แล้วคัดลอก
5. วางคีย์ลงในค่า `DEEPSEEK_API_KEY` ในตัวแก้ไขตู้นิรภัย
