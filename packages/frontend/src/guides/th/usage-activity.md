# แท็บกิจกรรม

## ภาพรวม

แท็บ **กิจกรรม** คือศูนย์ควบคุมของงานที่ทำงานเบื้องหลัง งานที่ใช้เวลานานทุกงานจะปรากฏที่นี่: รอบการทำงาน**แปล** **รีวิวด้วย AI** (คำแปลและต้นฉบับ) การสร้างอภิธานศัพท์ และการสร้างหมวดหมู่ รอบการทำงานจะถูกจัดคิวและทำทีละงานต่อโปรเจกต์ คุณจึงตั้งคิวไว้หลายงานแล้วดูมันทำงานเรียงกันไปได้

## การอ่านรอบการทำงาน

แต่ละรอบการทำงานจะแสดง**ประเภท** **สถานะ** (อยู่ในคิว, กำลังทำงาน, หยุดชั่วคราว, เสร็จสิ้น, ล้มเหลว หรือยกเลิกแล้ว) ความคืบหน้า และ**ค่าใช้จ่าย**โดยประมาณ ค่าใช้จ่ายเป็นค่าประมาณที่โมดูลรายงานมา คำนวณจากราคาต่อโทเค็นล้านหน่วยของแต่ละโมเดล ดังนั้นโมเดลที่คิดก่อนตอบอาจแสดงยอดโทเค็นสูงเมื่อเทียบกับจำนวนอักขระ ใช้ **แสดงรายละเอียด** เพื่อดูว่ารอบการทำงานแปลอะไรไปบ้าง มีการลองใหม่กี่ครั้ง และใช้อักขระ/โทเค็นไปเท่าไร คุณคัดลอกรหัสรอบการทำงานไว้อ้างอิงได้

## การจัดการคิว

* **หยุดชั่วคราว** / **ทำต่อ** รอบการทำงาน หรือ **เริ่มเดี๋ยวนี้** เพื่อให้รอบที่อยู่ในคิวเริ่มก่อน
* **เลื่อนขึ้น** / **เลื่อนลง** เพื่อจัดลำดับคิวใหม่
* **ยกเลิก** รอบการทำงานที่อยู่ในคิวหรือกำลังทำงานอยู่

## การกู้คืนและการรีวิว

* หากข้อความบางส่วนล้มเหลว **ลองใหม่รายการที่ล้มเหลว** จะรันเฉพาะรายการนั้นซ้ำ
* จากรอบการแปลที่เสร็จสมบูรณ์แล้ว เริ่ม **รีวิวด้วย AI** ได้โดยตรงจากรอบนั้น — เลือกโมดูลและโมเดล (ค่าเริ่มต้นคือตัวที่ใช้แปล) แล้วเปิดผลตัดสินในแท็บ **รีวิวคำแปลด้วย AI**
