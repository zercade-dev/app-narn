# แท็บคำแปล

## ภาพรวม

แท็บ **คำแปล** คือตารางรายการหลัก: ทุกรายการต้นฉบับพร้อมคอลัมน์ต่อภาษาปลายทาง ที่นี่คุณอ่าน แก้ไข กรอง จัดหมวดหมู่ และ**เลือก**รายการที่จะแปล ตารางนี้แบ่งหน้า (25/50/100/200 แถวต่อหน้า)

## การแก้ไข

คลิกที่เซลล์คำแปลใดก็ได้เพื่อแก้ไขแบบอินไลน์ การเปลี่ยนแปลงจะบันทึกเมื่อคุณยืนยัน คอลัมน์ต้นฉบับและคอลัมน์ **สถานะ** แสดงข้อความต้นฉบับและที่มาของแต่ละรายการ พร้อมหมวดหมู่ อภิธานศัพท์ และสถานะการแปล

## การกรอง

ใช้แถบเครื่องมือเพื่อจำกัดขอบเขตตาราง:

* **ค้นหา**ทั้งข้อความต้นฉบับและคำแปล
* ตัวกรอง**สถานะ**: เฉพาะที่ยังไม่ได้แปล เฉพาะที่ไม่ผ่าน LQA เฉพาะที่ล้น ต้องตรวจทาน เหมือนต้นฉบับ ตัวแทนค่าไม่ตรงกัน
* กรองตาม**ภาษา** ป้ายกำกับ**แหล่งที่มา** หรือ**หมวดหมู่** และแสดงหรือซ่อนคอลัมน์ได้

## การเลือกและการแปล

เลือกแถวด้วยเช็กบ็อกซ์ (หรือเลือกทั้งชุดที่กรองไว้) เมื่อมีรายการที่เลือกแล้ว คุณสามารถ:

* รัน **แปลรายการที่เลือก** จากแถบการเลือก (กฎการจ่ายงานจะเลือกโมดูลตามภาษา)
* **เพิ่ม**หรือ**ลบหมวดหมู่**เป็นชุด
* **อนุมัติเข้าหน่วยความจำ** — บันทึกคำแปลปัจจุบันลงในหน่วยความจำการแปลในฐานะข้อมูลที่เชื่อถือได้

## หมวดหมู่และอภิธานศัพท์ต่อรายการ

คลิกขวาที่แถว (หรือใช้ปุ่มการดำเนินการของแถว) เพื่อ**แก้ไขหมวดหมู่**หรือเลือกว่า**อภิธานศัพท์**ใดเปิดใช้งานสำหรับรายการนั้นระหว่างการแปล หมวดหมู่ยังสร้างเป็นชุดได้จากแท็บ **หมวดหมู่**
