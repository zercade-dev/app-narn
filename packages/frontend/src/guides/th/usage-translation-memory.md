# หน่วยความจำการแปล

## ภาพรวม

**หน่วยความจำการแปล** (TM) คือคลังคำแปลที่รู้จักแล้วในระดับเวิร์กสเปซ เมื่อข้อความต้นฉบับของรายการหนึ่งตรงกับข้อความที่มีอยู่ในหน่วยความจำแล้ว คำแปลที่เก็บไว้จะถูกนำมาใช้ซ้ำโดยอัตโนมัติแทนการเรียกโมดูลที่เสียเงิน ช่วยประหยัดทั้งเวลาและค่าใช้จ่าย และรักษาความสอดคล้องของข้อความที่เหมือนกันข้ามโปรเจกต์ เปิดมุมมอง **หน่วยความจำการแปล** จากแถบด้านข้างเพื่อเรียกดูและค้นหาส่วนที่จัดเก็บไว้

> **หน่วยความจำการแปลปิดใช้งานโดยค่าเริ่มต้น**สำหรับทุกโปรเจกต์ ขณะที่ปิดใช้งานอยู่ ไม่มีสิ่งที่โปรเจกต์แปลจะถูกเขียนลงหน่วยความจำ และไม่มีคำแปลที่จัดเก็บไว้ถูกนำมาใช้อัตโนมัติ หากต้องการเปิดใช้งาน ให้เปิดแท็บ **ตั้งค่าโปรเจกต์** ของโปรเจกต์ แล้วเลือกนโยบายการใช้ซ้ำในส่วน **หน่วยความจำการแปล** (ค่าใดก็ได้ที่ไม่ใช่ *ปิดใช้งาน*)

## รายการเข้าสู่หน่วยความจำได้อย่างไร

* **อนุมัติเข้าหน่วยความจำ** — ในแท็บ **คำแปล** เลือกคำแปลแล้วอนุมัติ คำแปลเหล่านั้นจะถูกบันทึกเป็นส่วนที่เชื่อถือได้
* รอบการแปลที่เสร็จสมบูรณ์แล้วก็ถูกบันทึกไว้เช่นกัน เพื่อให้ข้อความต้นฉบับที่เหมือนกันนำมาใช้ซ้ำได้ในภายหลัง

## นโยบายการใช้ซ้ำ

นโยบายการใช้ซ้ำ (ในแท็บ **ตั้งค่าโปรเจกต์** ของโปรเจกต์ ส่วน **หน่วยความจำการแปล**) ควบคุมว่า*จะ*และ*เมื่อไร*คำแปลที่จัดเก็บไว้จะถูกนำมาใช้ซ้ำสำหรับข้อความต้นฉบับที่เหมือนกัน ค่าเริ่มต้นคือ **ปิดใช้งาน** (TM ปิด) ตัวเลือกอื่น ๆ — เช่น **เข้มงวด (ตรงกันทั้งบริบท)** ซึ่งใช้ซ้ำเฉพาะเมื่อบริบทโดยรอบตรงกันด้วย — จะเปิดใช้งาน TM การเข้มงวดขึ้นนี้ช่วยหลีกเลี่ยงการใช้ซ้ำคำแปลที่ถูกต้องในที่หนึ่งแต่ไม่ถูกต้องในอีกที่หนึ่ง

## ควบคุมการใช้ซ้ำต่อรอบการทำงาน

เมื่อคุณเริ่มการแปลจากกล่อง *แปล…* ในแท็บ **เปรียบเทียบ** จะมีข้อความแจ้งว่ามีกี่รายการที่จะถูกเติมจากหน่วยความจำ และคุณ**ปิดหน่วยความจำสำหรับรอบนี้**ได้เพื่อบังคับให้ทุกรายการถูกแปลใหม่ทั้งหมด — มีประโยชน์เมื่อคุณต้องการให้โมเดลพิจารณาข้อความที่เคยจดจำไว้ใหม่อีกครั้ง
