# แท็บตั้งค่าโปรเจกต์

## ภาพรวม

แท็บ **ตั้งค่าโปรเจกต์** เก็บนโยบายการแปลของโปรเจกต์ที่เลือกไว้: การเลือกโมเดลต่อโมดูล การใช้หน่วยความจำการแปลซ้ำ การจัดกลุ่มแบตช์ การตรวจสอบคุณภาพ (LQA) และการจัดการโปรเจกต์ **ภาษา**และ**การนำเข้า/ส่งออก CSV** ย้ายไปอยู่ในแท็บ **ข้อมูล** แยกต่างหากแล้ว ข้อมูลรับรองของผู้ให้บริการไม่ได้ตั้งค่าที่นี่ — แต่อยู่ใน**ตู้นิรภัยข้อมูลรับรอง** (ดูคู่มือ *การตั้งค่าโมดูล* และ **การตั้งค่าส่วนกลาง**)

## ภาษา (บนแท็บข้อมูล)

ตั้งค่า**ภาษาต้นทาง**และ**ภาษาปลายทาง**ที่จะแปลไปในแท็บ **ข้อมูล** ชุดภาษาปลายทางที่เปิดใช้งานอยู่จะกำหนดแท็บอื่นทั้งหมด — คอลัมน์ของรายการ กฎการจ่ายงาน และการตรวจสอบคุณภาพล้วนเป็นไปตามนี้

## นำเข้าและส่งออก CSV (บนแท็บข้อมูล)

การนำเข้าและส่งออก CSV ก็อยู่ในแท็บ **ข้อมูล** เช่นกัน:

* **นำเข้า CSV** โหลดรายการต้นฉบับและคำแปลที่มีอยู่แล้ว ระบบจะถ่ายสแนปช็อตเพื่อความปลอดภัยโดยอัตโนมัติก่อนการนำเข้าแต่ละครั้ง คุณจึงย้อนกลับได้จากแท็บ **ข้อมูลสำรอง**
* แถวที่แยกวิเคราะห์ไม่ได้อย่างถูกต้อง (เครื่องหมายคำพูดตามด้วยจุลภาคทันที) จะถูกตัดออกและรายงานให้ทราบ แทนที่จะเขียนเป็นข้อมูลที่คอลัมน์เลื่อน
* **ส่งออก CSV** ดาวน์โหลดโปรเจกต์ คุณเลือกภาษาและเลือกได้ว่าจะรวมคอลัมน์บริบทสำหรับผู้แปลด้วยหรือไม่
* การส่งออกจะเขียนข้อความตามที่บันทึกไว้ โดยไม่เพิ่มอะพอสทรอฟีหน้าเซลล์ที่ขึ้นต้นด้วย = + - หรือ @ ใน **ส่งออกสำหรับ** ค่าเริ่มต้นคือ **ตัวแก้ไขเกม** เลือก **Excel หรือ Sheets** เฉพาะไฟล์ที่จะดูในสเปรดชีต เพราะจะเพิ่มอะพอสทรอฟีซึ่งตัวแก้ไข Miliastra เก็บไว้เป็นข้อความ และตัวเลือกจะรีเซ็ตหลังการส่งออกแต่ละครั้ง ไฟล์สคริปต์ไคลเอนต์ที่ป้องกันแล้วต้องไม่นำเข้าซ้ำหรือส่งไปยังตัวแก้ไข การรันแปลจะข้ามแถวที่ค่า Need translation? เป็น FALSE

### ไฟล์สคริปต์ไคลเอนต์

CSV ที่มีคอลัมน์ **Text Mapping ID** คือไฟล์สคริปต์ไคลเอนต์ ไฟล์นี้จะนำเข้าไปยังคอลเลกชันของตัวเองคือ **ข้อความสคริปต์ไคลเอนต์** แยกจาก **ข้อความหลัก** ของคุณ โดยหน้าต่างนำเข้าจะแจ้งว่าตรวจพบคอลเลกชันใด

* สตริงไคลเอนต์แต่ละรายการระบุด้วย Text Mapping ID ของตัวเอง ข้อความภาษาอังกฤษเดียวกันจึงอยู่ได้ทั้งสองคอลเลกชันและในหลายแถวของไคลเอนต์โดยไม่ถูกรวมกัน
* การนำเข้าไฟล์ไคลเอนต์จะไม่เปลี่ยนข้อความหลัก และการนำเข้าไฟล์หลักจะไม่เปลี่ยนข้อความไคลเอนต์
* เมื่อข้อความภาษาอังกฤษของคีย์เดิมเปลี่ยนไป ไม่ว่าจะใช้โหมดนำเข้าใด แถวเดิมจะย้ายไปที่แท็บ **รายการกำพร้า** และแถวใหม่จะคงคำแปลจากไฟล์ไว้ เฉพาะเซลล์ที่ว่างเท่านั้นที่ยังไม่ได้แปล ใช้ **เชื่อมใหม่** เพื่อย้ายคำแปล โดยระบบจะแนะนำแถวที่มีคีย์เดียวกันก่อน และโหมดการเขียนทับจะกำหนดว่าจะคงหรือแทนที่เซลล์ที่มีข้อมูลแล้ว
* เมื่อโปรเจกต์มีสตริงไคลเอนต์ **ส่งออก CSV** จะให้เลือกคอลเลกชันที่จะดาวน์โหลด และการส่งออกไคลเอนต์จะคงคอลัมน์ Text Mapping ID ไว้

## โมดูลและโมเดล

เปิดใช้งานผู้ให้บริการครั้งเดียวใน **การตั้งค่าส่วนกลาง** ที่นี่ในตั้งค่าโปรเจกต์ คุณเลือก**โมเดล**และ**ระดับการให้เหตุผล**ต่อโปรเจกต์สำหรับแต่ละโมดูลที่เปิดใช้งาน — หรือปล่อยไว้เป็น *สืบทอดจากการตั้งค่าส่วนกลาง* โมดูลใดจะทำงานจริงสำหรับรายการหนึ่ง ๆ นั้นตัดสินโดย**กฎการจ่ายงาน** (ดูคู่มือ *การจ่ายงาน*)

## การตรวจสอบ LQA

พาเนล **การตรวจสอบ LQA** ตั้งค่าเกณฑ์คุณภาพที่รันกับทุกคำแปล: สลับเปิด/ปิดการตรวจสอบแต่ละรายการ (ความเท่ากันของแท็ก ขีดจำกัดความยาว ความยาวล้น การยึดตามอภิธานศัพท์ คำต้องห้าม ข้อยืนยันด้วย regex และอื่น ๆ) และตั้งแต่ละรายการเป็น **ปิดกั้น** หรือ **คำเตือน** ปัญหาระดับปิดกั้นจะทำให้ไม่ผ่านเกณฑ์และอาจกระตุ้นให้ลองใหม่อัตโนมัติหนึ่งครั้ง ส่วนคำเตือนจะรายงานเท่านั้น

## การจัดกลุ่มแบตช์

**การจัดกลุ่มแบตช์**เก็บรายการที่เกี่ยวข้องกัน (ตามหมวดหมู่และ/หรืออภิธานศัพท์) ไว้ในคำขอเดียวกัน เพื่อให้โมเดลเห็นรายการเหล่านั้นพร้อมบริบท คุณตั้งค่าเริ่มต้นของโปรเจกต์ได้ และเขียนทับต่อรอบการทำงานก็ได้

## การจัดการโปรเจกต์

**โซนอันตราย**ให้คุณ**ทำสำเนา**โปรเจกต์ (การตั้งค่าและรายการ ไม่รวมข้อมูลลับ) หรือ**ลบ**โปรเจกต์อย่างถาวร
