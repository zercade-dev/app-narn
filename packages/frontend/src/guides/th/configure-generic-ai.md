# โมดูล Generic AI

## ภาพรวม

โมดูล **Generic AI** เชื่อมต่อกับ API ใด ๆ ที่รองรับรูปแบบของ OpenAI ได้ — ทั้งผู้ให้บริการแบบโฮสต์หรือเซิร์ฟเวอร์ที่รันเองในเครื่อง (เช่น Ollama, LM Studio, vLLM) คีย์ของมันจัดเก็บไว้ในตู้นิรภัยข้อมูลรับรองภายใต้ `GENERIC_API_KEY`

**API key เป็นตัวเลือกไม่บังคับ** มันสำคัญเฉพาะกับปลายทางที่ต้องยืนยันตัวตน (ผู้ให้บริการคลาวด์แบบเสียเงินส่วนใหญ่) เซิร์ฟเวอร์ในเครื่องอย่าง Ollama หรือ LM Studio ไม่ต้องใช้คีย์จริง — แต่ตู้นิรภัยยังคงต้องให้ช่อง `GENERIC_API_KEY` ไม่ว่างเปล่า ดังนั้นให้เก็บค่าตัวแทนใด ๆ ไว้ (เช่น `local`) เพื่อให้ผ่านเงื่อนไขนี้

## เพิ่มคีย์ของคุณลงในตู้นิรภัยข้อมูลรับรอง

ข้อมูลรับรองของผู้ให้บริการจะถูกเก็บไว้ใน **ตู้นิรภัยข้อมูลรับรอง** ที่เข้ารหัสไว้ ไม่ใช่ในไฟล์ตั้งค่าธรรมดา คุณปลดล็อกตู้นิรภัยครั้งเดียวต่อเซสชันด้วยรหัสผ่าน

1. เปิด **การตั้งค่าส่วนกลาง** จากแถบด้านข้าง
2. หากยังไม่ได้ตั้งค่าตู้นิรภัย ให้สร้างขึ้นก่อน: ตั้งรหัสผ่านตู้นิรภัย (คุณจะใช้รหัสผ่านนี้ซ้ำทุกเซสชัน) แล้วปลดล็อก
3. ใต้ **เปิดใช้งานโมดูล** เลือก **Generic AI** เมื่อคีย์ที่จำเป็นยังไม่มี ตัวแก้ไขตู้นิรภัยจะเปิดที่คีย์ที่ถูกต้องให้อัตโนมัติ — หากไม่เป็นเช่นนั้น ให้คลิก **การจัดการตู้นิรภัยข้อมูลรับรอง**
4. ในตัวแก้ไขตู้นิรภัย เพิ่มข้อมูลรับรอง: เลือกคีย์ `GENERIC_API_KEY` ป้อน **รหัสผ่านตู้นิรภัย** ของคุณ แล้วคลิก **บันทึก** สำหรับปลายทางแบบเสียเงิน ให้วาง API key จริงเป็นค่า สำหรับเซิร์ฟเวอร์ในเครื่องที่ไม่ต้องยืนยันตัวตน คีย์นี้เป็นตัวเลือกไม่บังคับ — เพียงเก็บค่าตัวแทนที่ไม่ว่างเปล่า (เช่น `local`)

## รันหลายปลายทางด้วยอินสแตนซ์

Generic AI รองรับ**อินสแตนซ์แบบตั้งชื่อ** จึงลงทะเบียนได้หลายปลายทาง (เช่น ผู้ให้บริการคลาวด์หนึ่งตัวกับเซิร์ฟเวอร์ในเครื่องหนึ่งตัว) ให้ทำงานคู่กัน ใช้ **เพิ่มอินสแตนซ์ Generic AI อีกหนึ่งตัว** ในการตั้งค่าส่วนกลาง แต่ละอินสแตนซ์จะได้คีย์ตู้นิรภัยของตัวเองที่แยกออกมา — เช่น `GENERIC_API_KEY__MY-OLLAMA` — ซึ่งคุณกรอกในตัวแก้ไขตู้นิรภัยเดียวกัน

## เลือกปลายทางและโมเดล

ตั้งค่า base URL และโมเดลของโมดูล (หรือของแต่ละอินสแตนซ์) ในการตั้งค่าส่วนกลางของมัน จากนั้นเลือกโมเดลต่อโปรเจกต์ในแท็บ **ตั้งค่าโปรเจกต์** **กฎการจ่ายงาน** ในแท็บการจ่ายงานเป็นตัวตัดสินว่าโมดูลหรืออินสแตนซ์ใดดูแลภาษาใด

## รับข้อมูลรับรอง

สำหรับ**เซิร์ฟเวอร์ในเครื่อง** (Ollama, LM Studio, vLLM) ไม่ต้องมีบัญชีหรือคีย์ — เพียงแค่ base URL (เช่น `http://localhost:11434/v1`) และค่าตัวแทนในช่อง `GENERIC_API_KEY`

สำหรับ**ผู้ให้บริการแบบเสียเงิน** ขั้นตอนขึ้นกับผู้ให้บริการแต่ละราย: สร้างบัญชี รับ base URL และคีย์ของ API แล้วยืนยันว่าปลายทางนั้นรองรับรูปแบบ chat-completions ของ OpenAI ก่อนกรอกคีย์ลงในตู้นิรภัย
