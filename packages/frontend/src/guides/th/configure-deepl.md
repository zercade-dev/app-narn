# โมดูล DeepL

## ภาพรวม

โมดูล **DeepL** ให้บริการแปลด้วยเครื่องระดับมืออาชีพแบบโครงข่ายประสาทเทียม ต่างจากโมดูล LLM ตรงที่นี่คือ MT แบบดั้งเดิม และสามารถส่งอภิธานศัพท์ของโปรเจกต์ไปยัง DeepL เพื่อให้ศัพท์เฉพาะสอดคล้องกัน คีย์ของมันจัดเก็บไว้ในตู้นิรภัยข้อมูลรับรองภายใต้ `DEEPL_API_KEY`

## เพิ่มคีย์ของคุณลงในตู้นิรภัยข้อมูลรับรอง

ข้อมูลรับรองของผู้ให้บริการจะถูกเก็บไว้ใน **ตู้นิรภัยข้อมูลรับรอง** ที่เข้ารหัสไว้ ไม่ใช่ในไฟล์ตั้งค่าธรรมดา คุณปลดล็อกตู้นิรภัยครั้งเดียวต่อเซสชันด้วยรหัสผ่าน

1. เปิด **การตั้งค่าส่วนกลาง** จากแถบด้านข้าง
2. หากยังไม่ได้ตั้งค่าตู้นิรภัย ให้สร้างขึ้นก่อน: ตั้งรหัสผ่านตู้นิรภัย (คุณจะใช้รหัสผ่านนี้ซ้ำทุกเซสชัน) แล้วปลดล็อก
3. ใต้ **เปิดใช้งานโมดูล** เลือก **DeepL** เมื่อคีย์ที่จำเป็นยังไม่มี ตัวแก้ไขตู้นิรภัยจะเปิดที่คีย์ที่ถูกต้องให้อัตโนมัติ — หากไม่เป็นเช่นนั้น ให้คลิก **การจัดการตู้นิรภัยข้อมูลรับรอง**
4. ในตัวแก้ไขตู้นิรภัย เพิ่มข้อมูลรับรอง: เลือกคีย์ `DEEPL_API_KEY` วางคีย์ยืนยันตัวตนของคุณเป็นค่า ป้อน **รหัสผ่านตู้นิรภัย** ของคุณ แล้วคลิก **บันทึก**

DeepL ไม่รองรับอินสแตนซ์แบบตั้งชื่อ — มีโมดูล DeepL เพียงตัวเดียวเท่านั้น

## การใช้อภิธานศัพท์

DeepL สามารถนำอภิธานศัพท์มาใช้ระหว่างการแปลได้ สร้างคำศัพท์ในแท็บ **อภิธานศัพท์** แล้วใช้ **ส่งไปยัง DeepL** เพื่ออัปโหลด หากอภิธานศัพท์เปลี่ยนแปลงหลังส่งไปแล้ว แท็บจะแสดงว่า *ต้องส่งขึ้นใหม่* — ส่งอีกครั้งเพื่ออัปเดต DeepL

## รับ API key ของ DeepL

1. ไปที่ [deepl.com/account](https://www.deepl.com/account)
2. สมัครบัญชี API แบบ Free หรือ Pro
3. เปิด **Account Settings** แล้วหาส่วน **API Key**
4. คัดลอกคีย์ยืนยันตัวตนของคุณ
5. วางคีย์ลงในค่า `DEEPL_API_KEY` ในตัวแก้ไขตู้นิรภัย
