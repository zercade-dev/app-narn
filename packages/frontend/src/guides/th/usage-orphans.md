# แท็บรายการกำพร้า

## ภาพรวม

แท็บ **รายการกำพร้า** แสดงรายการที่ไม่มีอยู่ใน CSV ที่นำเข้าล่าสุดแล้ว มักปรากฏหลังนำเข้าใหม่ที่มีแถวถูกลบ เปลี่ยนชื่อ หรือเปลี่ยนข้อความต้นฉบับ — คำแปลเดิมยังคงเก็บไว้ที่นี่ คุณจึงไม่เสียงานที่ทำไปแล้ว

## สิ่งที่คุณทำได้

* **ลบ**รายการกำพร้าเพื่อนำระเบียนและคำแปลของมันออกอย่างถาวร (เลิกทำไม่ได้)
* **เชื่อมใหม่**รายการกำพร้าเพื่อย้ายคำแปลของมันไปยังอีกรายการหนึ่ง ค้นหาปลายทางจากข้อความต้นฉบับ คำแปลที่มีอยู่แล้วบนรายการปลายทางจะยังคงอยู่ และเติมเฉพาะภาษาที่ว่างเท่านั้น
* เลือกรายการกำพร้าหลายรายการแล้ว**ลบรายการที่เลือก**เป็นชุด หรือ**รีเฟรช**รายการ

## ขั้นตอนการทำงาน

1. นำเข้าไฟล์ CSV ต้นฉบับของคุณใหม่จากแท็บ **ข้อมูล**
2. เปิด **รายการกำพร้า** และตรวจดูว่าอะไรหลุดออกไปบ้าง
3. **เชื่อมใหม่**รายการที่ id หรือข้อความต้นฉบับเปลี่ยนไปแต่คำแปลยังใช้ได้อยู่
4. **ลบ**รายการที่หายไปจริง ๆ

เมื่อรายการว่างเปล่า แปลว่าทุกรายการที่นำเข้าตรงกับโปรเจกต์ปัจจุบัน — ไม่มีรายการกำพร้าเหลืออยู่
