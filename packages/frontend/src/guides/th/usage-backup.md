# แท็บข้อมูลสำรอง

## ภาพรวม

แท็บ **ข้อมูลสำรอง** รวมโปรเจกต์ทั้งหมด — การตั้งค่า รายการ และอภิธานศัพท์ — เป็นไฟล์ `.zip` ที่ตรวจสอบความถูกต้องได้ ทุกไฟล์มีเช็กซัมกำกับ และเช็กซัมจะถูกตรวจสอบก่อนเขียนอะไรกลับตอนกู้คืน

## สร้างข้อมูลสำรอง

1. เลือกโปรเจกต์
2. เปิดแท็บ **ข้อมูลสำรอง**
3. คลิก **สร้างข้อมูลสำรอง**
4. ไฟล์ใหม่จะปรากฏใน **ข้อมูลสำรองที่บันทึกไว้** ซึ่งคุณ**ดาวน์โหลด**ได้

## ข้อมูลสำรองอัตโนมัติ

แอปยังถ่ายสแนปช็อตเพื่อความปลอดภัยให้คุณโดยอัตโนมัติ แสดงรวมอยู่กับข้อมูลสำรองที่สร้างเอง:

* **ก่อนนำเข้า CSV** — จุดกู้คืนจากก่อนการนำเข้า
* **ก่อนแปลใหม่** — จุดกู้คืนจากก่อนที่รายการจะถูกเขียนทับ

การตั้งค่าส่วนกลางกำหนด **จำนวนข้อมูลสำรองสูงสุดต่อโปรเจกต์** (ค่าเริ่มต้น 10) ข้อมูลสำรองที่เก่ากว่านั้นจะถูกลบทิ้ง

## การกู้คืน

1. ใน **การกู้คืนจากข้อมูลสำรอง** เลือกไฟล์ `.zip` (หรือเลือกจากข้อมูลสำรองที่บันทึกไว้)
2. แอปจะตรวจสอบเช็กซัมและแสดงตัวอย่าง (โปรเจกต์ ไฟล์ เวลาที่สร้าง)
3. ยืนยัน การกู้คืนจะเขียนทับการตั้งค่า รายการ และอภิธานศัพท์ปัจจุบันของโปรเจกต์ — เลิกทำไม่ได้ หากไม่แน่ใจ ให้สร้างข้อมูลสำรองใหม่ไว้ก่อน

## การลบ

ใช้ **ลบ** ที่ข้อมูลสำรองที่บันทึกไว้รายการใดก็ได้ เพื่อนำไฟล์นั้นออกจากเซิร์ฟเวอร์อย่างถาวร
