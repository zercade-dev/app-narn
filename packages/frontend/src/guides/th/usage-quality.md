# แท็บคุณภาพ

## ภาพรวม

แท็บ **คุณภาพ** คือแดชบอร์ดที่รวบรวมผล LQA (Linguistic Quality Assurance) ที่เกิดขึ้นทุกครั้งที่มีการแปลรายการ แสดงอัตราผ่านโดยรวมของคุณและจุดที่ปัญหากระจุกตัว คุณจึงหาพื้นที่ที่มีปัญหาได้อย่างรวดเร็ว มันจะเริ่มมีข้อมูลเมื่อคุณแปลไปเรื่อย ๆ — หากยังว่างอยู่ ให้รันการแปลก่อน

## สิ่งที่แสดง

* **อัตราผ่านโดยรวม** จากผล LQA ทั้งหมดและรายการที่ครอบคลุม
* **อัตราผ่านตามภาษา** — คุณภาพต่อภาษาปลายทาง
* **ปัญหาตามแหล่งที่มา** — จำนวนตามชนิดของปัญหา จัดกลุ่มตามป้ายกำกับแหล่งที่มา
* **คุณภาพตามโมดูล** — อัตราผ่านและปัญหา จัดกลุ่มตามโมดูลที่ผลิตคำแปลแต่ละรายการ

## การดูรายละเอียด

คลิกที่เซลล์ใดก็ได้เพื่อกระโดดไปยังรายการที่ตรงกัน — แดชบอร์ดจะกรองตาราง **คำแปล** ให้เหลือเฉพาะรายการที่ได้รับผลกระทบ เพื่อให้คุณแก้ไขได้

## ที่มาของการตรวจสอบ

คำแปลแต่ละรายการจะผ่านเกณฑ์ LQA ซึ่งรันการตรวจสอบที่คุณเปิดใช้งานไว้ในพาเนล *การตรวจสอบ LQA* ของแท็บ **ตั้งค่าโปรเจกต์** (ความเท่ากันของแท็ก ขีดจำกัดความยาว ความยาวล้น การยึดตามอภิธานศัพท์ คำต้องห้าม ข้อยืนยันด้วย regex และอื่น ๆ) การตรวจสอบระดับ **ปิดกั้น** จะทำให้ไม่ผ่านเกณฑ์และอาจกระตุ้นให้ลองใหม่อัตโนมัติหนึ่งครั้ง ส่วนการตรวจสอบระดับ **คำเตือน** จะรายงานไว้ที่นี่โดยไม่ปิดกั้น ปรับได้ว่าการตรวจสอบใดจะรัน และระดับความรุนแรงของแต่ละอย่าง ที่แท็บตั้งค่าโปรเจกต์
