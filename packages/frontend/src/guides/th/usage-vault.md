# ตู้นิรภัยข้อมูลรับรอง

## ภาพรวม

API key ของผู้ให้บริการจะไม่ถูกเก็บไว้ในไฟล์ตั้งค่าธรรมดาหรือตัวแปรสภาพแวดล้อมเด็ดขาด แต่จะอยู่ใน**ตู้นิรภัยข้อมูลรับรอง** — ที่เก็บข้อมูลแบบเข้ารหัสที่ต้องปลดล็อกก่อนการแปลหรือการรีวิวด้วย AI ใด ๆ จะใช้ข้อมูลรับรองได้ คุณปลดล็อกครั้งเดียวต่อเซสชันเบราว์เซอร์ ข้อมูลรับรองจะถูกถอดรหัสไว้ในหน่วยความจำเท่านั้น

## ตู้นิรภัยแบบใช้รหัสผ่าน (ติดตั้งเอง)

บนการติดตั้งแบบโฮสต์เอง ตู้นิรภัยคือไฟล์ในเครื่องที่เข้ารหัสไว้ การปลดล็อกครั้งแรกจะสร้างมันขึ้นมา: รหัสผ่านที่คุณเลือกจะกลายเป็นรหัสผ่านตู้นิรภัย และทุกข้อมูลรับรองที่คุณบันทึกจะเข้ารหัสไฟล์นี้ใหม่ รหัสผ่านนี้เองจะไม่ถูกจัดเก็บไว้ที่ใดเลย — หากไม่มีมัน ไฟล์นี้จะถอดรหัสไม่ได้ ปลดล็อกได้จาก **การตั้งค่าส่วนกลาง** หรือจากการ์ด *ตู้นิรภัยถูกล็อก* ใด ๆ

## ตู้นิรภัยผูกกับอุปกรณ์ (คลาวด์)

บนเวอร์ชันคลาวด์ ตู้นิรภัยถูกเก็บไว้แบบ**เข้ารหัสบนเซิร์ฟเวอร์** และการถอดรหัสต้องใช้ปัจจัยสองอย่าง:

- **รหัสผ่าน**ของคุณ — ไม่เคยถูกจัดเก็บไว้ที่ใดเลย ไม่ว่าจะบนเซิร์ฟเวอร์หรืออุปกรณ์
- **คีย์เฉพาะอุปกรณ์** — สร้างขึ้นในเบราว์เซอร์ของคุณเมื่อคุณลงทะเบียนอุปกรณ์ และเก็บไว้เฉพาะบนอุปกรณ์นั้นเท่านั้น

เมื่อคุณปลดล็อก ปัจจัยทั้งสองจะเดินทางผ่านการเชื่อมต่อที่เข้ารหัสไว้และถูกรวมเข้าด้วยกันฝั่งเซิร์ฟเวอร์เพื่อสร้างคีย์ถอดรหัส **ไว้ในหน่วยความจำ สำหรับเซสชันของคุณเท่านั้น** ทั้งปัจจัยและคีย์ที่สร้างขึ้นจะไม่ถูกเขียนลงพื้นที่จัดเก็บของเซิร์ฟเวอร์เลย — สิ่งที่จัดเก็บไว้มีเพียงตู้นิรภัยที่เข้ารหัสแล้วเท่านั้น ดังนั้นข้อมูลที่จัดเก็บบนเซิร์ฟเวอร์เพียงลำพังจึงเปิดเผยข้อมูลรับรองของคุณไม่ได้ และรหัสผ่านที่รั่วไหลเพียงอย่างเดียวก็ไม่พอเช่นกัน — การปลดล็อกยังต้องใช้หนึ่งในอุปกรณ์ที่คุณลงทะเบียนไว้ด้วย

หากการตั้งค่าส่วนกลางแสดงปุ่ม **ไปที่หน้าตู้นิรภัย** แทนช่องกรอกรหัสผ่าน แสดงว่าคุณกำลังใช้ตู้นิรภัยผูกกับอุปกรณ์ — หน้าตู้นิรภัยจะจัดการการตั้งค่า การลงทะเบียนอุปกรณ์ การปลดล็อก การแก้ไขข้อมูลรับรอง และการเปลี่ยนรหัสผ่าน

## สิ่งที่ควรรู้

- อุปกรณ์ที่ไม่เคยใช้มาก่อนต้อง**ลงทะเบียน**ที่หน้าตู้นิรภัยก่อนจึงจะปลดล็อกได้
- หากคุณลืมรหัสผ่าน (หรือบนคลาวด์ ลืมทุกอุปกรณ์ที่ลงทะเบียนไว้) เนื้อหาในตู้นิรภัยจะกู้คืนไม่ได้ — คุณต้องตั้งค่าตู้นิรภัยใหม่และป้อนคีย์ผู้ให้บริการของคุณใหม่ทั้งหมด
- สิ่งใดก็ตามที่แอปบันทึกล็อกไว้จะผ่านการปิดบังข้อมูล ค่าของข้อมูลรับรองจึงไม่มีทางปรากฏในล็อก
