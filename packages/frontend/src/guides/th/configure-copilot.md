# โมดูล GitHub Copilot

## ภาพรวม

โมดูล **Copilot** แปลผ่าน GitHub Copilot โดยยืนยันตัวตนด้วยโทเคน GitHub จากบัญชีที่มี **การสมัครสมาชิก Copilot ที่ใช้งานอยู่** ซึ่งจัดเก็บไว้ในตู้นิรภัยข้อมูลรับรองภายใต้คีย์ `GITHUB_TOKEN`

## เพิ่มโทเคนของคุณลงในตู้นิรภัยข้อมูลรับรอง

ข้อมูลรับรองของผู้ให้บริการจะถูกเก็บไว้ใน **ตู้นิรภัยข้อมูลรับรอง** ที่เข้ารหัสไว้ ไม่ใช่ในไฟล์ตั้งค่าธรรมดา คุณปลดล็อกตู้นิรภัยครั้งเดียวต่อเซสชันด้วยรหัสผ่าน

1. เปิด **การตั้งค่าส่วนกลาง** จากแถบด้านข้าง
2. หากยังไม่ได้ตั้งค่าตู้นิรภัย ให้สร้างขึ้นก่อน: ตั้งรหัสผ่านตู้นิรภัย (คุณจะใช้รหัสผ่านนี้ซ้ำทุกเซสชัน) แล้วปลดล็อก
3. ใต้ **เปิดใช้งานโมดูล** เลือก **GitHub Copilot** เมื่อคีย์ที่จำเป็นยังไม่มี ตัวแก้ไขตู้นิรภัยจะเปิดที่คีย์ที่ถูกต้องให้อัตโนมัติ — หากไม่เป็นเช่นนั้น ให้คลิก **การจัดการตู้นิรภัยข้อมูลรับรอง**
4. ในตัวแก้ไขตู้นิรภัย เพิ่มข้อมูลรับรอง: เลือกคีย์ `GITHUB_TOKEN` วางโทเคนของคุณเป็นค่า ป้อน **รหัสผ่านตู้นิรภัย** ของคุณ แล้วคลิก **บันทึก**

หากรายการโมเดลแสดงว่า *No models available* แปลว่าโทเคนยังไม่มี ไม่ถูกต้อง หรือตู้นิรภัยถูกล็อกอยู่ — ปลดล็อกตู้นิรภัยหรือตรวจสอบโทเคน GitHub ของคุณ แล้วเปิดการ์ดนี้ใหม่

## รับโทเคน GitHub

ใช้ personal access token แบบ **fine-grained** เพื่อให้สิทธิ์เฉพาะการเข้าถึง Copilot เท่านั้น ไม่มีอย่างอื่น

1. ไปที่ [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens)
2. คลิก **Generate new token** (fine-grained token เป็นค่าเริ่มต้น)
3. ตั้งชื่อ (เช่น "Translator-Copilot") และกำหนด **Expiration**
4. ใต้ **Permissions → Account permissions** หา **Copilot Requests** แล้วตั้งเป็น **Read-only** ไม่ต้องให้สิทธิ์อื่นเพิ่ม
5. คลิก **Generate token** แล้วคัดลอกทันที — GitHub จะแสดงให้เห็นเพียงครั้งเดียว
6. วางโทเคนลงในค่า `GITHUB_TOKEN` ในตัวแก้ไขตู้นิรภัย

บัญชีที่อยู่เบื้องหลังโทเคนต้องมีการสมัครสมาชิก Copilot ที่ใช้งานอยู่ การแปลจึงจะสำเร็จ
