# โมดูล Groq

## ภาพรวม

โมดูล **Groq** แปลผ่าน [Groq](https://groq.com) — การอนุมานที่รวดเร็วสำหรับโมเดลแบบเปิด เช่น Llama, Qwen และ GPT-OSS พร้อมระดับฟรีที่เหมาะกับงานแปลประจำวัน ต้องใช้ API key ของ Groq ซึ่งจัดเก็บไว้ในตู้นิรภัยข้อมูลรับรองภายใต้คีย์ `GROQ_API_KEY`

## เพิ่มคีย์ของคุณลงในตู้นิรภัยข้อมูลรับรอง

ข้อมูลรับรองของผู้ให้บริการจะถูกเก็บไว้ใน **ตู้นิรภัยข้อมูลรับรอง** ที่เข้ารหัสไว้ ไม่ใช่ในไฟล์ตั้งค่าธรรมดา คุณปลดล็อกตู้นิรภัยครั้งเดียวต่อเซสชันด้วยรหัสผ่าน

1. เปิด **การตั้งค่าส่วนกลาง** จากแถบด้านข้าง
2. หากยังไม่ได้ตั้งค่าตู้นิรภัย ให้สร้างขึ้นก่อน: ตั้งรหัสผ่านตู้นิรภัย (คุณจะใช้รหัสผ่านนี้ซ้ำทุกเซสชัน) แล้วปลดล็อก
3. ใต้ **เปิดใช้งานโมดูล** เลือก **Groq** เมื่อคีย์ที่จำเป็นยังไม่มี ตัวแก้ไขตู้นิรภัยจะเปิดที่คีย์ที่ถูกต้องให้อัตโนมัติ — หากไม่เป็นเช่นนั้น ให้คลิก **การจัดการตู้นิรภัยข้อมูลรับรอง**
4. ในตัวแก้ไขตู้นิรภัย เพิ่มข้อมูลรับรอง: เลือกคีย์ `GROQ_API_KEY` วางคีย์ของคุณเป็นค่า ป้อน **รหัสผ่านตู้นิรภัย** ของคุณ แล้วคลิก **บันทึก**

หากภายหลังการ์ดแสดงว่า *ตู้นิรภัยถูกล็อก* ให้คลิก **ปลดล็อกตู้นิรภัย** ก่อนแปล

## เลือกโมเดล

ในแท็บ **ตั้งค่าโปรเจกต์** ของโปรเจกต์ เลือกโมเดลจากแคตตาล็อกของ Groq แบบสด หรือรับค่าเริ่มต้นส่วนกลางมาใช้ `llama-3.3-70b-versatile` เป็นตัวเลือกเริ่มต้นที่มั่นคงสำหรับคุณภาพงานแปล ส่วนโมเดลขนาดเล็กกว่าอย่าง `llama-3.1-8b-instant` แลกคุณภาพบางส่วนเพื่อความเร็ว **กฎการจ่ายงาน** ในแท็บการจ่ายงานเป็นตัวตัดสินว่าโมดูลใดดูแลภาษาใด

## รับ API key ของ Groq

1. ไปที่ [console.groq.com](https://console.groq.com)
2. สมัครสมาชิกหรือเข้าสู่ระบบ
3. เปิด **API Keys** จากเมนูคอนโซล
4. สร้าง API key ใหม่แล้วคัดลอก — คีย์จะขึ้นต้นด้วย `gsk_`
5. วางคีย์ลงในค่า `GROQ_API_KEY` ในตัวแก้ไขตู้นิรภัย

ระดับฟรีของ Groq กำหนดขีดจำกัดรายวันต่อโมเดล (ไม่มีตัวเลขตายตัวระบุไว้ที่นี่ — ตรวจสอบขีดจำกัดปัจจุบันได้ที่คอนโซลของคุณ) และตามเงื่อนไขของ Groq ข้อมูล API จะไม่ถูกนำไปใช้ฝึกโมเดล เมื่อเพิ่มคีย์ของคุณแล้ว **NARN Freeway** จะรวมแพ็กเกจฟรีของ Groq เข้าไปโดยอัตโนมัติเมื่อกระจายงานแปลไปยังโควตาฟรีของผู้ให้บริการที่เชื่อมต่อไว้ทั้งหมดของคุณ — ไม่ต้องตั้งค่าเพิ่มเติม
