# ทดสอบเทียม

## ภาพรวม

**ทดสอบเทียม** ไม่ใช่ภาษาจริง แต่เป็นภาษา QA แบบออฟไลน์ที่ไม่มีค่าใช้จ่าย ซึ่งเขียนข้อความต้นฉบับของคุณใหม่ให้กลายเป็นเวอร์ชันที่ผิดเพี้ยนโดยตั้งใจ คุณจึงโหลดเข้าเกมแล้วดูได้ว่าข้อความไหนทำให้อินเทอร์เฟซพัง — ก่อนที่จะมีคำแปลจริงแม้แต่คำเดียว

ไม่มีค่าใช้จ่าย ไม่ต้องใช้ API key และไม่ส่งอะไรไปยังผู้ให้บริการเลย

## สิ่งที่มันสร้างขึ้น

`Save changes` จะกลายเป็นอะไรทำนอง `⟦Şàvé çhàñgéş~~~~⟧` มีสามสิ่งเกิดขึ้นพร้อมกัน และแต่ละอย่างเผยบั๊กคนละประเภท:

* **ตัวอักษรมีเครื่องหมายกำกับ** ทุกตัวอักษรถูกแทนที่ด้วยตัวที่หน้าตาคล้ายกันแต่มีเครื่องหมายกำกับ ข้อความใดที่ยังแสดงเป็นภาษาอังกฤษธรรมดาในเกมของคุณ แปลว่าไม่เคยถูกดึงเข้าตารางข้อความเลย — มันถูกฝังไว้ในโค้ด และจะไม่มีผู้แปลคนไหนเข้าถึงมันได้
* **การเติมความยาว** ข้อความถูกยืดด้วยอักขระ `~` จนยาวขึ้นราว 1.4 เท่าของความยาวเดิม จำลองภาษาอย่างเยอรมันที่มักยาวกว่า ป้ายกำกับที่ล้นปุ่ม ขึ้นบรรทัดผิด หรือดันเลย์เอาต์เพี้ยนจะปรากฏให้เห็นทันที
* **วงเล็บ** ผลลัพธ์ถูกครอบด้วย `⟦…⟧` หากวงเล็บด้านใดด้านหนึ่งหายไปจากหน้าจอ แปลว่าข้อความนั้นถูกตัดทอน

ตัวแทนค่าและแท็กมาร์กอัปในข้อความของคุณจะผ่านไปโดยไม่ถูกแตะต้อง หากตัวใดตัวหนึ่งออกมาผิดเพี้ยน นั่นคือบั๊กที่ควรรายงาน ไม่ใช่ปัญหาเลย์เอาต์

## การใช้งาน

1. ในแท็บ **ข้อมูล** ติ๊ก **ทดสอบเทียม** ใต้ *ภาษาปลายทาง* แล้วบันทึก
2. รันการแปลตามปกติ รายการทดสอบเทียมจะถูกจัดการโดยตัวสร้างข้อความเทียมในตัวเสมอ — ไม่มีอะไรต้องเปิดใช้งาน ไม่มีกฎการจ่ายงานต้องเขียน และไม่มีค่าใช้จ่าย ผู้ให้บริการที่เสียเงินของคุณจะไม่เห็นข้อความเหล่านี้เลย
3. คำแปลจริงของคุณปลอดภัย: ข้อความทดสอบเทียมถูกเก็บไว้ในคอลัมน์ของตัวเอง และไม่มีทางเขียนทับภาษาอื่นได้เลย

## การนำเข้าไปในเกมของคุณ

ในการ์ดส่งออก ตั้งค่า **ส่งออกข้อความเทียมเป็น** เป็นภาษาที่คุณยังไม่ได้ใช้งานจริง — เช่น เยอรมัน — แล้วดาวน์โหลดไฟล์และโหลดเข้าเกมโดยเลือกภาษานั้น คอลัมน์ของภาษาที่เลือกจะถูกเติมด้วยข้อความทดสอบเทียมเฉพาะการดาวน์โหลดครั้งนั้นครั้งเดียว ไม่มีอะไรที่จัดเก็บไว้เปลี่ยนแปลง และคำแปลจริงยังคงอยู่ในการส่งออกครั้งถัดไป

เมื่อทดสอบเสร็จแล้ว ให้ส่งออกอีกครั้งโดยตั้งค่าการแทนที่กลับเป็น **ไม่แทนที่** การส่งออกปกติจะไม่มีคอลัมน์ทดสอบเทียมอยู่เลย — ข้อความเทียมจะเข้าถึงเกมของคุณได้ก็ผ่านการแทนที่ด้านบนเท่านั้น การเปิดทดสอบเทียมทิ้งไว้จึงไม่ส่งผลต่อไฟล์ที่คุณส่งจริง

## เมื่อไรควรใช้

รันรอบทดสอบเทียมแต่เนิ่น ๆ ก่อนที่คุณจะสั่งแปลใด ๆ บั๊กเลย์เอาต์ทุกตัวที่มันเจอคือสิ่งที่คุณแก้เพียงครั้งเดียว แทนที่จะต้องแก้สิบห้าครั้งหลังภาษาทั้งสิบห้าภาษามาถึง
